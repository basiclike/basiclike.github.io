8. RAG

소주제 7개 · 강의 28편

Claude Code에게 명령하는 것만으로 내 윈도우 PC 안에서 로컬 AI가 내 문서를 근거로 답하게 만드는 법을 알아봅니다. 모르는 것을 지어내던 모델이 문서를 찾아 근거로 답하게 되는 과정을 직접 따라갑니다. 내 문서에 적용해 보고, 창이 있는 앱으로 만들어 다른 윈도우 PC에서 실행하는 데까지 이어 갑니다.

→ 여기서 시작하세요: 1강부터 차례로 따라가면 됩니다. Claude Code를 쓸 수 있는 요금제(Pro 이상)와 윈도우 11 PC가 필요하고, Python은 몰라도 괜찮습니다.

A로컬 AI 준비하기

Claude Code를 설치하고 승인 화면을 읽는 법을 익힌 뒤, Claude Code에게 Ollama 설치와 모델 내려받기를 시켜 로컬 모델에 첫 요청을 보내 봅니다.

  1. 1강 Code 설치하고 열기Claude Code를 설치하고 VS Code에서 첫 요청을 보내 봅니다. 공개 40분
  2. 2강 승인 화면과 규칙Claude Code가 실행할 명령을 승인 화면에서 읽어 봅니다. 비밀번호 60분
  3. 3강 Ollama 준비하기Claude Code에게 Ollama와 모델 두 개를 준비시켜 봅니다. 비밀번호 50분
  4. 4강 첫 요청 보내기로컬 모델에 첫 요청을 보내고 답을 받아 봅니다. 비밀번호 50분

B한계와 RAG

로컬 모델이 모르는 질문에 지어낸 답을 하는 모습을 보고, 문서를 찾아 붙여 주는 RAG가 답을 만드는 다섯 단계를 알아봅니다.

  1. 5강 모델이 지어내는 답로컬 모델이 출처 없는 답을 지어내는 모습을 직접 확인해 봅니다. 비밀번호 40분
  2. 6강 RAG 다섯 단계재학습과 RAG를 비교하고 RAG의 다섯 단계를 따라갑니다. 비밀번호 40분
  3. 7강 RAG 흐름과 용어다섯 단계가 어떤 강의와 파일이 되는지 보고 용어를 알아봅니다. 비밀번호 30분

C문서를 벡터로 저장

Claude Code에게 질의응답 문서를 만들게 하고, 벡터로 바꿔 chromadb에 저장한 뒤 저장 결과를 확인해 봅니다.

  1. 8강 작업 폴더와 환경Claude Code에게 가상환경과 패키지 설치를 시키고 점검해 봅니다. 비밀번호 40분
  2. 9강 데이터와 설정질의응답 데이터를 두고 설정 파일을 Claude Code에게 만들게 해 봅니다. 비밀번호 40분
  3. 10강 질의응답 문서 만들기질의응답 10건을 검색할 문서로 바꾸는 파일을 만들어 봅니다. 비밀번호 50분
  4. 11강 문서를 벡터로텍스트를 벡터로 바꾸는 요청을 보내고 결과를 확인해 봅니다. 비밀번호 40분
  5. 12강 벡터 저장과 확인벡터를 chromadb에 저장하고 저장 결과를 직접 확인해 봅니다. 비밀번호 60분

D근거로 답하기

질문과 가까운 문서를 찾고, 그 근거를 붙여 로컬 모델이 답하게 하며, 범위 밖 질문을 걸러 내는 기준을 정해 봅니다.

  1. 13강 질문으로 찾기질문을 벡터로 바꿔 가까운 문서를 찾는 프로그램을 만들어 봅니다. 비밀번호 50분
  2. 14강 거리와 유사도거리를 유사도로 바꿔 읽고 기준값으로 관련 여부를 판단해 봅니다. 비밀번호 40분
  3. 15강 근거 붙여 답하기찾은 문서를 근거로 붙여 로컬 모델이 답하게 하고 원문과 대조해 봅니다. 비밀번호 50분
  4. 16강 범위 밖 걸러내기범위 밖 질문은 모델을 부르지 않고 거부하도록 걸러 내 봅니다. 비밀번호 60분

E적용과 공부

내 문서를 같은 RAG에 넣어 보고, 이 대주제가 다루지 않은 것과 더 공부할 길을 알아봅니다.

  1. 17강 내 문서에 적용내 메모를 같은 RAG에 넣고 막히는 점을 알아봅니다. 비밀번호 50분
  2. 18강 다루지 않는 것내 데이터에서 달라지는 것과 RAG가 다루지 않는 것을 알아봅니다. 비밀번호 40분
  3. 19강 더 공부할 길다음에 어디서 무엇을 공부할지 순서를 알아봅니다. 비밀번호 30분

F데스크톱 앱 만들기

Claude Code에게 창이 있는 앱을 만들게 하고, 멈춤 없이 답을 받게 하며, 만든 RAG 답변기를 앱의 질문하기로 붙여 봅니다.

  1. 20강 창에서 답 보기Claude Code로 질문하면 Ollama의 답이 보이는 창을 만들어 봅니다. 비밀번호 60분
  2. 21강 화면 멈춤 막기답을 기다리는 동안 창이 멈추지 않게 바꾸는 과정을 따라갑니다. 비밀번호 50분
  3. 22강 메모 요약 앱메모를 붙여 넣으면 핵심만 요약해 주는 앱을 만들어 봅니다. 비밀번호 40분
  4. 23강 요약 기록 목록요약 결과를 목록에 쌓고 다시 열어 보는 기록 기능을 만들어 봅니다. 비밀번호 40분
  5. 24강 설정과 아이콘제목과 모델 이름을 파일로 빼고 앱 아이콘을 다는 과정을 따라갑니다. 비밀번호 50분
  6. 25강 앱에서 질문하기내 문서를 근거로 답하는 RAG를 앱의 질문하기에 붙여 봅니다. 비밀번호 60분

G윈도우에 배포하기

앱을 폴더로 묶고, 바로가기와 배포 스크립트를 만들어 다른 윈도우 PC에서 실행해 봅니다.

  1. 26강 앱을 폴더로 묶기앱을 실행 파일이 든 폴더 하나로 묶어 실행해 봅니다. 비밀번호 60분
  2. 27강 바로가기 만들기바탕화면과 시작 메뉴에서 눌러 여는 바로가기를 만들어 봅니다. 비밀번호 40분
  3. 28강 배포 스크립트빌드부터 압축까지 스크립트 하나로 묶어 다른 PC에서 실행해 봅니다. 비밀번호 60분
