2. Claude 시작하기

소주제 3개 · 강의 15편

Claude가 다음에 올 그럴듯한 말을 이어 쓰는 모델이라는 데서 출발해, 사람에게 일을 맡기듯 요청하고 받은 답을 출처로 확인하는 습관을 들여 봅니다. 요금제, 모델, effort, 대화 길이가 사용 한도와 비용으로 이어진다는 것을 알아보고, 내 일에 맞게 골라 써 봅니다.

→ 여기서 시작하세요: 1강부터 차례로 따라 하면 됩니다. 가입할 메일 주소와 Windows PC, 휴대전화가 있으면 되고, 강의는 Pro 요금제로 진행합니다.

AClaude 시작하기

Claude를 쓰는 곳과 기능을 알아보고, 가입해 첫 질문을 보내고, 데스크톱 앱과 휴대전화 앱에서 같은 대화를 이어 써 봅니다.

  1. 1강 Claude 개요: LLM 서비스와 Claude 둘러보기LLM 기반 AI 서비스(ChatGPT, Gemini, Meta AI, Grok, Claude)가 무엇인지 알아보고, Claude를 쓰는 다섯 곳과 Claude 안의 주요 기능(검색, Research, Project, Artifacts, Design, Docs)을 이 강의 시리즈의 어느 대주제에서 배우는지 찾아봅니다. 공개 약 35분
  2. 2강 가입하고 로그인하기이메일과 인증 코드로 Claude에 가입하고 로그인과 로그아웃을 한 뒤, Google 계정으로도 가입하고 로그인해 봅니다. 비밀번호 약 25분
  3. 3강 Team 계정과 도메인 메일(선택)Team 계정이 무엇이고 무엇이 필요한지, 도메인과 도메인 메일이 무엇이고 개인에게는 왜 없는지 알아보고, Cloudflare로 도메인을 등록해 메일을 받는 우회 방법도 살펴봅니다. 비밀번호 약 50분
  4. 4강 첫 질문 보내고 화면 살펴보기Claude에 첫 질문을 보내 답을 받고, 사이드바, 입력창, 대화 목록의 자리를 익힌 뒤, 화면 언어와 테마를 바꿔 봅니다. 비밀번호 약 30분
  5. 5강 데스크톱 앱 설치하고 쓰기Claude 데스크톱 앱을 설치해 같은 계정으로 로그인하고, 웹에서 한 대화를 앱에서 이어 간 뒤, 대화에 PC 폴더를 연결하는 자리(Add folder)를 알아봅니다. 비밀번호 약 30분
  6. 6강 휴대전화 앱 설치하고 쓰기Claude 휴대전화 앱을 설치해 로그인하고 화면 구성을 알아본 뒤, PC에서 한 대화를 이어 가고 음성과 사진으로 질문해 봅니다. 비밀번호 약 30분

B질문 잘하기

사람에게 일을 맡기듯 완결된 문장으로 요청하고, 그럴듯하게 틀리는 답을 가려내고, 늘 읽히는 지침과 메모리를 다뤄 봅니다.

  1. 7강 데스크톱 앱 화면과 요청하고 응답받기데스크톱 앱의 화면 구성을 익히고, 역할, 상황, 조건, 출력 형식을 채운 요청과 막연한 요청의 답을 비교한 뒤, 그럴듯하게 틀리는 환각이 무엇인지 알아봅니다. 비밀번호 약 50분
  2. 8강 Instructions for Claude: 늘 읽히는 지침설정한 지침이 모든 대화 앞에 붙어 항상 읽힌다는 것이 무슨 뜻인지 알아보고, Instructions for Claude에 지침을 넣어 새 대화에 적용되는지 확인해 봅니다. 비밀번호 약 40분
  3. 9강 지시를 문장으로 쓰는 법LLM은 앞 문장을 보고 다음 말을 이어 쓰는 구조라서 단답형과 핵심어 나열이 조건과 범위를 잃는다는 것을 알아보고, 사람에게 시키듯 완결 문장으로 지시를 써 봅니다. 비밀번호 약 45분
  4. 10강 메모리와 임시 대화메모리가 무엇이고 Instructions와 어떻게 다른지 알아보고, 메모리를 켜고 끄고, 저장된 기억을 읽고 지운 뒤 Incognito로 대화해 봅니다. 비밀번호 약 30분

C요금제, 모델, 설정

요금제와 사용 한도, 토큰과 컨텍스트를 알고, 모델과 effort를 골라 보고, 공식 자료와 Settings에서 필요한 것을 찾아봅니다.

  1. 11강 요금제와 사용 한도내 요금제를 확인하고, Free, Pro, Max, Team과 API가 어떻게 다른지, 매달 같은 값을 내는 정액제와 쓴 만큼 내는 사용량 요금제가 무엇인지 알아본 뒤, 5시간 한도와 주간 한도를 읽어 봅니다. 비밀번호 약 40분
  2. 12강 토큰과 컨텍스트요청과 응답을 토큰으로 센다는 것과 컨텍스트 창이 무엇인지 알아보고, 긴 대화가 한도를 빨리 쓰는 이유를 확인한 뒤 새 대화로 넘겨 봅니다. 비밀번호 약 35분
  3. 13강 모델과 effort 고르고 성능 비교하기같은 요청을 다른 모델과 effort로 보내 보고, 공식 모델 비교 표와 Artificial Analysis 같은 비교 사이트로 성능, 속도, 비용을 확인해 일에 맞는 모델과 effort를 골라 봅니다. 비밀번호 약 60분
  4. 14강 공식 사이트에서 찾을 것과 Claude가 안 될 때 확인할 곳공식 사이트 다섯 곳이 각각 무엇을 알려 주는지 알아보고 필요한 정보를 찾아본 뒤, Claude가 응답하지 않을 때 상태 페이지부터 차례로 원인을 가려 봅니다. 비밀번호 약 40분
  5. 15강 Settings에서 살펴볼 곳Settings의 탭마다 무엇을 바꾸는지 알아보고, 모델 학습 허용, 데이터 내보내기, 알림, 연결된 기능 같은 꼭 볼 설정을 확인해 봅니다. 비밀번호 약 30분
