2. Claude

소주제 5개 · 강의 28편

Claude에게 일을 맡기는 자리가 대화창에서 내 컴퓨터와 공개 사이트로 넓어지는 흐름을 따라갑니다. 넓어질 때마다 요청에 무엇을 담고 되풀이하는 지시를 어디에 두는지, Claude가 낸 답과 변경을 무엇으로 확인한 뒤 받아들이는지 알아봅니다.

→ 여기서 시작하세요: 1강부터 차례로 따라 하면 됩니다. Claude Pro 이상 요금제와 Ubuntu PC가 필요하고, 터미널에서 Python 파일을 실행해 본 정도면 충분합니다.

AClaude.ai로 일 맡기기

대화창에서 요청을 네 요소로 채우고, 되풀이하는 지시를 설정과 Skill로 옮기며, 받은 답을 검증해 고쳐 받습니다.

  1. 1강 Claude 시작하기claude.ai에 가입해 화면 구성을 익히고, 내 플랜과 사용량, 기록 내보내기, 서비스 상태를 어디서 찾는지 확인합니다. 공개 약 30분
  2. 2강 토큰과 컨텍스트 윈도우정액제로 쓰는 Claude에서도 토큰과 컨텍스트 윈도우가 사용 한도를 정한다는 것을 보고, 대화가 길어질수록 한 번의 질문이 왜 무거워지는지 알아봅니다. 비밀번호 약 40분
  3. 3강 요청을 네 요소로 채우고 Instructions에 옮기기막연한 요청을 역할, 상황, 조건, 출력 형식으로 채워 보고, 매번 같은 내용을 Instructions에 옮겨 새 대화에서 적용되는지 확인합니다. 비밀번호 약 50분
  4. 4강 Claude의 답을 검증하고 고치기Claude가 그럴듯하게 틀리는 곳을 직접 찾아보고, 공식 자료와 실행 결과로 답을 확인한 뒤 같은 대화에서 고쳐 받는 순서를 따라갑니다. 비밀번호 약 40분
  5. 5강 모델과 사고 깊이 고르기같은 요청을 두 모델과 두 사고 깊이로 보내 답을 비교하고, 작업마다 어느 모델과 깊이로 시작할지 정하는 기준을 알아봅니다. 비밀번호 약 40분
  6. 6강 웹 검색과 Research, 첨부 자료로 일 맡기기Web Search와 Research로 최신 자료를 가져와 출처를 확인하고, 같은 대화에서 결과를 이어 쓰거나 파일로 옮겨 새 대화에 올리는 흐름을 따라갑니다. 비밀번호 약 60분
  7. 7강 반복하는 요청을 Skill로 만들기반복하던 요청을 Skill로 만들어 필요할 때만 켜지는지 시험하고, SKILL.md의 description이 그때를 정한다는 것을 확인합니다. 비밀번호 약 55분

BClaude Code로 내 컴퓨터에서 일 맡기기

터미널의 Claude Code에게 재고관리 프로그램을 만들고 고치게 하며, 승인 화면과 CLAUDE.md, 백업, Skill로 맡긴 일을 관리하는 법을 알아봅니다.

  1. 8강 Claude Code 설치하고 첫 파일 만들게 하기Ubuntu 터미널에 Claude Code를 설치하고 로그인한 뒤, 연습 폴더에서 `hello.py`를 만들게 하고 직접 실행해 결과를 확인합니다. 비밀번호 약 50분
  2. 9강 Claude.ai와 Claude Code는 무엇이 다른가8강의 `hello.py`를 다시 보며 Claude.ai와 Claude Code의 흐름이 왜 다른지 알아보고, 프롬프트, 컨텍스트, 하네스 세 층위로 앞으로 이어질 강의의 지도를 그려 봅니다. 비밀번호 약 40분
  3. 10강 기존 파일을 고치는 요청 쓰기재고관리 프로그램의 뼈대를 만든 뒤 같은 기능을 허술한 요청과 구체적인 요청으로 맡겨 보고, 기존 파일을 고치는 요청에 무엇을 담아야 하는지 확인합니다. 비밀번호 약 60분
  4. 11강 승인 화면 읽고 모델 바꾸기승인 화면이 무엇을 묻는지 읽고 누르기 전에 바뀔 것을 예측해 보며, `/status`와 `/model`로 작업에 맞는 모델을 골라 결과를 비교합니다. 비밀번호 약 55분
  5. 12강 CLAUDE.md에 프로젝트 규칙 적기`/init`으로 CLAUDE.md를 만들고 규칙 두 줄을 더한 뒤, 파일 이름 없는 짧은 요청에 규칙이 반영되고 CLAUDE.md는 그대로인지 확인합니다. 비밀번호 약 55분
  6. 13강 폴더를 복사해 되돌릴 자리 만들기작업 전에 프로젝트 폴더를 통째로 복사해 두고, 기능을 더한 뒤 `diff`로 바뀐 곳을 찾아 되돌리는 차례를 따라갑니다. 비밀번호 약 55분
  7. 14강 백업 절차를 Skill로 만들고 프로젝트 정리하기13강의 백업 절차를 Skill로 만들어 필요할 때만 켜지는지 시험하고, README.md로 재고관리 프로젝트의 1차 완성본을 정리합니다. 비밀번호 약 70분

CObsidian과 Claude로 학습 기록하기

학습 기록을 마크다운 노트로 남기는 이유를 알아보고, Obsidian에서 쓴 노트를 Claude에게 주어 검토받습니다.

  1. 15강 Obsidian 설치하고 학습 자료 폴더 열기Obsidian을 설치해 `study-notes` 폴더를 Vault로 열고, Vault가 파일 관리자에서 보는 보통 폴더 하나라는 것을 확인합니다. 비밀번호 약 50분
  2. 16강 학습 기록을 마크다운으로 남기는 이유마크다운 노트가 글자만 담긴 파일이라는 것을 워드 문서와 비교해 확인하고, 학습 기록의 원본을 마크다운으로 두는 이유를 알아봅니다. 비밀번호 약 40분
  3. 17강 마크다운으로 학습 노트 쓰기마크다운 문법으로 학습 노트를 직접 쓰고, 공개될 폴더에 무엇을 남기고 무엇을 뺄지 정해 기록을 시작합니다. 비밀번호 약 70분
  4. 18강 근거를 주고 Claude에게 노트 검토받기Claude에게 노트를 근거로 주어 검토받고, 그 답을 원본과 대조해 맞는 지적만 노트에 고쳐 넣는 차례를 따라갑니다. 비밀번호 약 70분

DGitHub로 학습 기록 공개하기

Claude Code에게 Git 명령을 맡겨 학습 기록 폴더를 GitHub에 올리고, GitHub Pages로 내 주소에서 열리는 학습 노트 사이트를 만듭니다.

  1. 19강 GitHub 가입하고 Git 준비하기GitHub 계정을 만들고 Git과 GitHub CLI를 설치해 로그인한 뒤, Claude Code가 실행한 명령의 출력으로 준비가 끝났는지 확인합니다. 비밀번호 약 50분
  2. 20강 학습 기록 폴더를 Git 저장소로 만들기13강의 폴더 복사와 비교하며, Claude Code에게 학습 기록 폴더를 Git 저장소로 만들고 첫 커밋을 남기게 한 뒤 승인 화면과 출력으로 확인합니다. 비밀번호 약 60분
  3. 21강 GitHub에 학습 기록 올리기Claude Code에게 공개 저장소를 만들어 학습 기록을 올리게 하고, GitHub 화면의 파일 목록과 커밋이 PC와 같은지 확인합니다. 비밀번호 약 45분
  4. 22강 노트를 고쳐 다시 올리기Obsidian에서 고친 노트를 다시 올리고, GitHub 웹에서 만든 커밋 때문에 push가 거부되면 질문 틀로 물어 받은 명령을 거부 메시지와 대조합니다. 비밀번호 약 60분
  5. 23강 GitHub Pages로 학습 노트 사이트 열기GitHub Pages를 켜서 학습 기록이 내 주소의 사이트로 열리게 하고, 같은 노트가 Obsidian, 저장소 화면, 사이트에서 어떻게 보이는지 비교합니다. 비밀번호 약 70분
  6. 24강 사이트 제목과 테마 바꾸고 멈춘 곳 찾기`_config.yml` 두 줄로 사이트 제목과 테마를 바꾸고, 사이트가 바뀌지 않을 때 파일, 커밋 목록, `Actions` 세 곳을 차례로 확인해 멈춘 곳을 찾습니다. 비밀번호 약 70분

EVS Code에서 Claude Code의 변경 검토하기

VS Code에서 Claude Code에게 코드의 문제를 찾아 계획을 세우고 고치게 한 뒤, 계획, 코드 차이, 테스트 결과로 변경을 판단합니다.

  1. 25강 VS Code에 Claude Code 확장 설치하고 재고 프로젝트 준비하기VS Code에 Claude Code 확장을 설치하고 설정을 맞춘 뒤, 재고 프로젝트를 만들어 Claude Code의 설명과 Python 실행 결과를 나란히 확인합니다. 비밀번호 약 50분
  2. 26강 선택한 코드와 @-mention으로 입력 문제 찾기테스트를 통과해도 공백 상품명이 저장되는 문제를 재현하고, 선택한 코드와 @-mention으로 Claude Code에게 원인을 물어 그 설명을 실제 코드와 대조합니다. 비밀번호 약 40분
  3. 27강 Plan 모드로 변경 계획 검토하기코드를 고치기 전에 Plan 모드에서 변경 계획을 받고, 요구사항과 대조해 범위 밖 작업을 뺀 최종 계획을 확정합니다. 비밀번호 약 40분
  4. 28강 코드 차이를 읽고 승인한 뒤 테스트로 확인하기27강에서 확정한 계획대로 Claude Code에게 구현을 맡기고, 코드 차이를 계획과 대조해 승인한 뒤 테스트 결과로 변경을 받아들이는 흐름을 따라갑니다. 비밀번호 약 50분
