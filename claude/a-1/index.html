1강. Claude 시작하기

환경 설정 강의 ⏱ 약 30분

학습 목표

Claude를 처음 여는 사람이 가장 먼저 막히는 것은 질문을 쓰는 법이 아닙니다.
화면 어디에 무엇이 있는지, 내 계정으로 어떤 기능을 쓸 수 있는지 모르는 데서 막힙니다.

  • "Claude"라는 이름 아래 여러 서비스가 있다는 것을 알고, 이 강의를 따라 하려면 어느 서비스와 어떤 플랜이 필요한지 확인해 봅시다.
  • 처음 보는 Claude 화면에서 사이드바, 입력창, 계정 메뉴를 직접 찾아봅시다.
  • 내 플랜과 사용량, 기록 가져오기와 내보내기는 어디에 있을까요? Settings를 열어 내 계정에서 무엇을 쓸 수 있는지 확인해 봅시다.
  • Claude가 갑자기 답하지 않으면 내 쪽 문제일까요, 서비스 문제일까요? 둘을 가르는 곳을 찾아 둡시다.

Claude라는 이름의 여러 서비스

→ "Claude"라는 이름 아래 어떤 서비스들이 있고, 이 강의에서는 그중 무엇을 쓰는지 알아봅니다.

Claude 서비스 모음

Claude라고 하면 대화창 하나를 떠올리기 쉽습니다.
하지만 "Claude"는 서비스 하나의 이름이 아닙니다.
Claude를 만든 회사 Anthropic은 Claude를 쓰임새에 따라 여러 서비스로 나눠 내놓고 있습니다.

  • claude.ai: 웹 브라우저, 모바일 앱, 데스크톱 앱에서 대화로 Claude를 쓰는 서비스입니다. 누구나 대화창에 글을 써서 시작할 수 있어서, Claude를 처음 쓰는 사람이 들어오는 기본 입구입니다.
  • Claude Code: 코딩에 맞춘 도구입니다. 터미널(명령을 글자로 입력하는 창)에서 실행하면 Claude가 내 컴퓨터의 파일을 직접 읽고 만들고 고칩니다.
  • Claude Cowork: PC의 파일과 작업을 맡기는 데스크톱 앱입니다.
  • Claude Platform: 개발자가 자기 프로그램에서 Claude를 불러 쓰는 연결 통로(API)입니다.
  • Claude Design: 디자인 작업에 맞춘 서비스입니다.
  • Claude Security: 코드의 보안 취약점을 찾는 서비스입니다.

⚠ 확인 필요 Claude Security의 이용 대상과 공개 범위

이 강의에서 쓰는 세 가지

이 가운데 이 강의에서 쓰는 것은 셋입니다.

  1. 1강부터 7강까지는 브라우저로 여는 claude.ai를 씁니다.
  2. 8강부터는 Ubuntu(리눅스 운영체제의 하나) 터미널에 설치한 Claude Code를 씁니다. 이때부터 Claude가 내 컴퓨터의 파일을 직접 다룹니다.
  3. 25강부터는 VS Code 안의 Claude Code 확장을 씁니다. 같은 일을 코드 편집기 안에서 합니다.

나머지 서비스는 이름만 알아 두면 나중에 들었을 때 낯설지 않습니다.

이 강의는 claude.ai에서 시작해, 내 컴퓨터의 파일을 다루는 Claude Code로 넘어갑니다.

↓ 이어서 그렇다면 이 세 가지를 모두 쓰려면 어떤 플랜이 있어야 할까요?

준비

→ 이 강의를 끝까지 따라 하려면 어떤 플랜이 필요한지 알아보고, 준비할 것을 확인합니다.

서비스마다 다른 플랜

플랜(요금제)마다 쓸 수 있는 서비스가 다릅니다.
Free 플랜으로도 claude.ai에서 대화는 할 수 있습니다.
하지만 Claude Code와 Cowork는 Pro 이상의 유료 플랜에서만 열립니다.

이 강의는 8강부터 Claude Code로 실습합니다.
그래서 이 강의를 끝까지 따라 하려면 Pro 이상의 플랜이 필요합니다.
내 계정의 플랜은 뒤에서 Settings를 열어 직접 확인합니다.

claude.ai 열기

① 웹 브라우저를 열고 주소창에 claude.ai를 입력한 뒤 Enter 키를 누릅니다.

로그인 화면이 나타나고 주소가 claude.ai/login으로 바뀌면 됩니다.

가입 방법 고르기

가입하는 방법은 두 가지이니 편한 쪽을 고릅니다.

① Google 계정으로 가입하려면 Google로 계속하기를 클릭합니다.

② 쓰고 있는 Google 계정을 고릅니다.

③ 메일 주소로 가입하려면 이메일을 입력하세요 칸에 메일 주소를 입력합니다.

④ 이메일로 계속하기를 클릭합니다.

Google 계정을 쓰면 인증 코드 없이 들어갑니다.

⚠ 확인 필요 Google로 처음 가입할 때도 약관과 이름 화면이 나오는지

==어느 쪽으로 가입했는지 기억해 두세요.==
다음에 로그인할 때도 같은 방법을 씁니다.

메일 주소로 가입하는 차례

메일 주소로 가입하는 방법은 처음 보면 낯섭니다.
비밀번호를 정하는 단계가 없습니다.
메일로 받은 코드 하나를 넣으면 가입과 로그인이 함께 끝납니다.

① 인증 코드가 이메일로 전송되었다는 화면이 나타나면, 그 탭은 그대로 둡니다.

② 메일함을 열어 Anthropic이 보낸 인증 코드 메일에서 6자리 숫자를 확인합니다.

③ Claude 탭으로 돌아와 인증 코드를 입력하세요 칸에 6자리 숫자를 입력합니다.

④ 이메일 주소 확인을 클릭합니다.

⑤ 처음 가입한다면 이용약관에 동의합니다.

⑥ 플랜을 고릅니다.

⑦ 이름을 입력합니다.

⚠ 확인 필요 이 흐름을 그린 그림의 문구와 실제 가입 화면의 문구가 같은지

메인 화면이 열리면 가입이 끝난 것입니다.
플랜 선택 화면에서 무엇을 골랐는지는 뒤에서 Settings의 Billing으로 다시 확인합니다.

이미 계정이 있을 때

이미 계정이 있다면 로그인 화면에서 가입할 때 쓴 방법을 고릅니다.

  • Google로 가입했다면: Google로 계속하기를 클릭하면 바로 들어갑니다.
  • 메일 주소로 가입했다면: 코드를 받아 넣으면 약관, 플랜, 이름 화면 없이 바로 메인 화면이 열립니다.

로그인 뒤 처음 보이는 화면

로그인이 끝나면 주소가 claude.ai/new로 바뀌고, 가운데에 여러분의 이름을 부르는 인사말과 입력창이, 왼쪽에 사이드바가 보입니다. 이 화면이 보이면 가입과 로그인이 끝난 것입니다.

화면 구성 익히기

→ 앞으로 자주 클릭할 사이드바, 입력창, 계정 메뉴를 여러분의 화면에서 하나씩 찾아봅니다.

자주 클릭할 세 곳

이 화면에서 앞으로 자주 클릭할 곳은 세 군데입니다.
왼쪽의 사이드바, 가운데 아래의 입력창, 사이드바 맨 아래의 계정 메뉴입니다.

아래 그림들과 여러분의 화면을 나란히 놓고 하나씩 찾아봅니다.
이름이 다르거나 없는 항목은 여러분 화면의 이름을 따릅니다.

사이드바의 항목

  • 맨 위: Claude 글자를 클릭하면 언제든 처음 화면으로 돌아옵니다. 그 옆의 검색 아이콘으로는 지난 대화와 프로젝트를 찾고, 그 옆의 아이콘으로 사이드바를 접고 폅니다.
  • 메인 메뉴: New chat은 새 대화를 시작하고, Chats는 지금까지 나눈 대화 목록을 보여 줍니다. Projects는 자료와 지시를 한데 묶어 두고 여러 대화에서 함께 쓰는 곳이고, Customize는 Claude를 내게 맞추는 설정이 모인 곳입니다.
  • Products 묶음: 다른 Claude 서비스로 가는 항목이고, 1강부터 7강까지는 쓰지 않습니다.

입력창

질문은 화면 가운데의 입력창에 씁니다.

  • + 버튼: 입력창 왼쪽 아래에 있고, 파일이나 이미지를 첨부할 때 클릭합니다.
  • 모델과 응답 강도: 입력창 오른쪽 아래의 글자로, 그림에서는 Sonnet 4.6 Low입니다. 이 글자를 클릭하면 모델 목록이 열리고, 목록 안의 Effort를 클릭하면 응답 강도와 Thinking 스위치가 나옵니다.
  • 음성 아이콘 두 개: 마이크 아이콘은 음성 입력이고, 그 오른쪽의 막대 모양 아이콘은 음성 대화입니다.

모델과 응답 강도를 무엇에 따라 고르는지는 5강에서 비교해 보고 정합니다.
지금은 위치만 확인하고 바꾸지 않습니다.

계정 메뉴

사이드바 맨 아래에 여러분의 이름이 보이는 곳이 계정 영역입니다. 계정 영역을 클릭하면 위로 메뉴가 열립니다. 맨 위에 로그인한 메일 주소가 보이고, 그 아래에 Settings, Language, Get help, View all plans, Get apps and extensions 같은 항목이 이어지며, 맨 아래가 Log out입니다.

⚠ 확인 필요 Pro 개인 계정의 계정 메뉴에도 Invite users가 보이는지

이 가운데 가장 자주 여는 것이 Settings입니다.
내 플랜, 사용량, 기록 가져오기와 내보내기가 모두 Settings 안에 있기 때문입니다.

① 사이드바 맨 아래의 계정 영역을 클릭해 메뉴를 엽니다.

② 메뉴에서 Settings가 어디 있는지 확인합니다.

첫 질문 보내기

→ Claude에게 첫 질문을 보내고, 답이 오면 화면에서 무엇이 바뀌는지 봅니다.

질문 입력하기

위치를 익혔으니 첫 질문을 보내 봅니다.

① 사이드바에서 New chat을 클릭합니다.

② 입력창에 아래 문장을 그대로 입력합니다.

안녕, 넌 어떤 걸 잘해?

③ 전송 버튼을 클릭하거나 Enter 키를 누릅니다.

질문이 올라가고 Claude가 답을 쓰기 시작하면 됩니다.

Claude의 답

이 질문을 보냈을 때 Claude는 잘하는 일을 이렇게 꼽았습니다.

  • 글쓰기: 이메일, 보고서, 소설 같은 글과 번역
  • 분석과 설명: 복잡한 개념 풀어 설명하기, 자료 분석
  • 코딩: 프로그램 작성, 버그 수정
  • 문서 작업: 워드, 엑셀, PPT, PDF 파일 만들기
  • 학습 도움: 수학, 과학, 언어 공부
  • 브레인스토밍: 아이디어 내기, 기획
  • 일상적인 질문: 요리법, 여행 계획

그리고 구체적으로 하고 싶은 일이 있으면 말해 달라고 끝맺었습니다.

여러분이 받은 답은 문장과 차례가 다를 수 있습니다.
같은 질문도 보낼 때마다 답이 조금씩 달라지기 때문입니다.
답이 화면에 나타났다면 이 단계는 끝난 것입니다.

답과 함께 바뀌는 두 곳

답이 오면 화면에서 두 곳이 더 바뀝니다.

  • Recents: 사이드바의 Recents 아래에 Claude가 제목을 붙인 방금 대화가 생깁니다. 그림에서는 AI 능력과 역할 소개입니다.
  • 입력창 아래: Claude is AI and can make mistakes. Please double-check responses.라는 문장이 보입니다.

==방금 꼽은 잘하는 일은 Claude가 자기에 대해 한 말입니다.==
이 말이 정말 맞는지, Claude가 어디서 틀리는지는 4강에서 직접 확인합니다.
지금은 질문을 보내고 답을 받는 데까지만 해 둡니다.

Settings에서 내 계정 확인하기

→ Settings를 열어 내 플랜과 사용량을 직접 확인합니다.

Settings 창의 메뉴

사이드바 맨 아래의 계정 영역을 클릭하고 Settings를 클릭하면 Settings 창이 열립니다. 왼쪽에 메뉴가 있고, 메뉴를 클릭하면 오른쪽 내용이 바뀝니다.

Settings의 메뉴 구성은 플랜에 따라 조금씩 다릅니다.

⚠ 확인 필요 Pro 개인 계정의 Settings 왼쪽 메뉴 항목과 그 차례

이번 강의에서 열어 볼 메뉴는 그림의 다섯 가운데 General을 뺀 넷입니다.

내 플랜 확인하기

① 사이드바 맨 아래의 계정 영역을 클릭합니다.

② Settings를 클릭합니다.

③ 왼쪽 메뉴에서 Billing을 클릭합니다.

오른쪽 맨 위에 지금 쓰는 플랜 이름이 보입니다. 그림에서는 Pro plan 아래에 Annual이 적혀 있으니, 1년 단위로 결제한 Pro 플랜입니다.

여러분의 화면에 보이는 플랜에 따라 아래처럼 합니다.

보이는 플랜 할 일
Pro, Max 이 강의를 그대로 따라 합니다
Free 8강부터의 Claude Code 실습을 할 수 없습니다. 8강 전에 플랜을 바꿉니다

사용량 확인하기

Settings 창이 이미 열려 있으면 ③부터 합니다.

① 사이드바 맨 아래의 계정 영역을 클릭합니다.

② Settings를 클릭합니다.

③ 왼쪽 메뉴에서 Usage를 클릭합니다.

Usage 화면에는 Your usage limits라는 제목 옆에 플랜 이름이 적혀 있고, 그 아래에 막대가 두 개 있습니다.

  • Current session: 위의 막대입니다. Resets in 28 min처럼 사용량을 다시 0부터 셀 때까지 남은 시간이 함께 보입니다.
  • All models: Weekly limits 아래의 막대입니다. Resets Tue 2:00 AM처럼 다시 0부터 셀 요일과 시각이 보입니다.

막대 오른쪽의 70% used 같은 숫자는 그 한도를 얼마나 썼는지를 뜻합니다. 맨 아래 Last updated에는 숫자가 마지막으로 바뀐 때가 적혀 있습니다.

여러분 화면의 두 숫자를 지금 노트에 적어 둡니다.
방금 질문 하나를 보냈을 뿐이니 숫자가 아주 작을 것입니다.

정액 요금을 내는데 왜 쓸 수 있는 양에 한도가 있는지, 막대는 왜 둘인지 2강에서 알아봅니다. 그때 이 화면을 다시 열어 두 한도를 읽어 봅니다.

다른 AI의 기록 가져오기와 내보내기

→ 다른 AI가 기억하는 내용을 Claude로 가져오는 곳과, Claude에 쌓인 기록을 파일로 내보내는 곳을 찾아 둡니다.

다른 AI에서 넘어올 때

Claude를 처음 쓰는 사람도 많지만, ChatGPT나 Gemini를 쓰다가 Claude로 넘어오는 사람도 많습니다.
이때 가장 걱정되는 것은 다른 AI와 쌓아 둔 대화와 맥락을 처음부터 다시 만들어야 하느냐입니다.

Claude에는 다른 AI가 나에 대해 기억하는 내용을 가져오는 기능과, Claude에 쌓인 내 기록을 파일로 내보내는 기능이 있습니다. 둘 다 Settings 안에 있습니다.

오늘은 두 기능의 위치만 확인하고 실행하지 않습니다.

가져오기 버튼 찾기

① Settings 왼쪽 메뉴에서 Capabilities를 클릭합니다.

② Memory 부분의 Import memory from other AI providers 줄 오른쪽에서 Start import 버튼을 찾습니다. 지금 클릭하지는 않습니다.

이 버튼이 보이면 위치를 찾은 것입니다.

다른 AI를 써 온 사람이 나중에 이 버튼을 클릭하면 아래 차례로 진행됩니다.

프롬프트 복사하기

Start import 버튼을 클릭하면 Import memory to Claude 창이 열립니다. 1단계 칸에는 다른 AI에게 보낼 요청 글(프롬프트)이 미리 쓰여 있고, Copy 버튼을 클릭하면 이 프롬프트가 복사됩니다.

쓰던 AI에 보내기

쓰던 AI의 대화창을 열어 복사한 프롬프트를 붙여 넣고 보냅니다.

쓰던 AI의 답 복사하기

그 AI가 그동안 나에 대해 기억한 지시와 정보를 Instructions, Identity 같은 묶음별로 정리해 답합니다.
그 답을 복사합니다.

Claude에 붙여 넣기

Claude로 돌아와 2단계 칸에 붙여 넣고 Add to memory 버튼을 클릭합니다.

가져온 내용이 반영되기까지

Add to memory 버튼을 클릭하면 Memory updated! 알림이 뜹니다. 공식 안내에 따르면 가져온 내용이 기억에 반영되기까지 하루쯤 걸릴 수 있어, 알림 바로 뒤의 Manage memory 창에는 아직 보이지 않을 수 있습니다. 이 창의 See what Claude learned about you 버튼을 클릭하면 새 대화가 열립니다.

Claude가 기억한 내용 읽기

새 대화에서 Claude가 무엇을 새로 기억했는지 직접 설명합니다.

공식 안내는 이 가져오기 기능을 시험 단계의 기능이라고 소개합니다. 가져온 내용이 다 반영되지 않을 수 있고, 일과 관계없는 개인적인 내용은 남지 않을 수 있다고도 밝힙니다.

==그래서 가져온 뒤에는 이 마지막 화면에서 Claude가 무엇을 기억했는지 꼭 읽어 봅니다.==

내보내기 버튼 찾기

다음은 내보내기입니다.

① Settings 왼쪽 메뉴에서 Privacy를 클릭합니다.

② 화면을 아래로 내려 Your data 부분의 Export data 버튼을 찾습니다. 지금 클릭하지는 않습니다.

Export data 버튼이 보이면 위치를 찾은 것입니다.

내보낸 파일을 다루는 법

내보내기는 대화 기록을 따로 보관해 두고 싶을 때, 쓰던 기기를 바꿀 때, 계정을 정리하기 전에 기록을 남겨 두고 싶을 때 씁니다. 공식 안내에 따르면 Export data 버튼을 클릭하면 잠시 뒤 계정 메일로 다운로드 링크가 오고, 이 링크는 받은 뒤 24시간 동안만 쓸 수 있습니다. 다운로드한 파일에는 그동안 나눈 대화와 계정 정보가 들어 있습니다.

그래서 이 파일은 내 일기장을 통째로 복사한 것처럼 다뤄야 합니다.
남이 열면 내가 무엇을 묻고 무엇을 했는지 그대로 드러나기 때문입니다.

==파일을 다운로드할 위치와 보관할 곳을 신중하게 정하고, 공용 PC나 공유 폴더에 저장하지 않습니다.==
학교나 회사의 공용 PC에서 다운로드했다면 내 저장 장치로 옮긴 뒤 그 PC의 다운로드 폴더에서 지웁니다.

↓ 이어서 그런데 질문을 보냈는데 Claude가 아예 답하지 않으면, 어디부터 봐야 할까요?

서비스 상태 확인하기

→ Claude가 갑자기 답하지 않을 때, 내 쪽 문제인지 서비스 문제인지 가르는 곳을 찾아 둡니다.

답이 오지 않을 때 먼저 의심하는 것

질문을 보냈는데 답이 오지 않으면, 대부분 내 인터넷이 끊겼는지, 내가 설정을 잘못 바꿨는지부터 의심합니다.
하지만 Claude 서비스에 문제가 생겼다면 내 쪽에서 무엇을 해도 고쳐지지 않습니다.

둘을 가장 빨리 가르는 곳이 Anthropic이 공개하는 상태 페이지입니다.

상태 페이지 열기

① Ctrl 키와 T 키를 함께 눌러 브라우저에 새 탭을 엽니다.

② 주소창에 status.claude.com을 입력하고 Enter 키를 누릅니다.

상태 페이지 읽기

[화면 캡처: A-1-23 — status.claude.com 첫 화면. ① 맨 위의 All Systems Operational, ② claude.ai 줄, ③ Claude Code 줄] ▲ Claude 서비스의 상태 페이지

① 페이지 맨 위에 All Systems Operational이 보이는지 봅니다.

② 서비스 목록에서 claude.ai 줄을 찾습니다.

③ 서비스 목록에서 Claude Code 줄을 찾습니다.

All Systems Operational은 모든 서비스가 정상이라는 뜻입니다. 그 아래에는 claude.ai, Claude Console, Claude API, Claude Code, Claude Cowork, Claude for Government 같은 서비스가 하나씩 줄지어 있고, 줄마다 Operational처럼 지금 상태가 적혀 있습니다.

어느 줄에 장애 표시가 있다면 내 인터넷이나 설정의 문제가 아니라 서비스 쪽 문제입니다.
이것저것 바꾸지 말고 복구될 때까지 기다립니다.
맨 위의 Subscribe to Updates 버튼으로 장애 소식을 받아 볼 수도 있습니다.

상태 페이지 북마크하기

이 페이지는 막혔을 때 바로 열 수 있어야 쓸모가 있습니다.

① 상태 페이지가 열린 탭에서 Ctrl 키와 D 키를 함께 눌러 이 페이지를 북마크에 추가합니다.

오류 메시지로 원인 묻기

상태 페이지에도 이상이 없고 내 인터넷도 정상이라면, 그때 다른 원인을 찾습니다. 이 강의를 따라 하다가 화면에 오류 메시지가 나타나며 막히면, 그 메시지를 그대로 복사해 Claude에게 원인을 묻습니다. 이때 고쳐 달라고만 하지 말고, 무엇을 하다가 어떤 메시지를 봤는지를 함께 보냅니다.

예를 들면 이렇게 보냅니다.

claude.ai에서 Settings를 열다가 아래 오류 메시지가 나왔어. status.claude.com에서는 claude.ai가 Operational로 보이고, 인터넷은 다른 사이트가 잘 열려. 원인으로 의심할 것을 확인하기 쉬운 것부터 차례로 알려 줘.

(여기에 오류 메시지를 그대로 붙여 넣는다)

찾아 둔 화면

📌 정리 오늘 여러분은 Claude를 처음 열었을 때 막히는 두 가지를 직접 확인했습니다. 사이드바와 입력창과 계정 메뉴의 위치를 알았고, Settings에서 내 플랜과 사용량, 기록 가져오기와 내보내기가 있는 곳을 찾았으며, 서비스가 멈췄을 때 볼 상태 페이지를 북마크해 두었습니다.

Usage의 막대를 줄이는 것

이 가운데 앞으로 가장 자주 다시 열 화면은 Usage입니다.
같은 Pro 요금을 내는 사람이라도 어떤 사람은 하루 종일 써도 막대가 넉넉하고, 어떤 사람은 몇 시간 만에 한도에 걸립니다.

앞으로는 무거운 작업을 맡기기 전후로 이 화면을 열어, 그 작업이 쓴 만큼의 가치가 있었는지 여러분이 직접 확인하게 됩니다.

❓ 질문 Usage의 막대를 줄이는 것은 무엇일까요? 보낸 질문의 수일까요, 질문의 길이일까요, 대화를 얼마나 길게 이어 갔는지일까요, 아니면 고른 모델일까요? 떠오르는 대로 노트에 적어 보세요.

막혔을 때

→ 가입하거나 화면을 찾다가 막히면 여기서 증상을 찾아봅니다.

증상과 해결

증상 해결
인증 코드 메일이 오지 않는다 먼저 스팸 메일함을 확인합니다. 거기에도 없으면 Claude 화면에서 코드를 다시 보내 달라는 링크를 클릭합니다
인증 코드 메일을 여러 번 받았다 가장 최근에 받은 코드를 넣습니다. 코드는 한 번만 쓸 수 있고, 시간이 지나면 쓸 수 없습니다
Capabilities에 Start import 버튼이 없다 Settings의 Your Claude에서 찾습니다
질문을 보냈는데 답이 오지 않는다 status.claude.com에서 claude.ai 줄의 상태를 봅니다. 장애 표시가 있으면 설정을 바꾸지 말고 복구될 때까지 기다립니다
화면에 오류 메시지가 나타나며 막혔다 상태 페이지와 인터넷을 확인한 뒤, 메시지를 그대로 복사해 무엇을 하다가 봤는지와 함께 Claude에게 원인을 묻습니다

⚠ 확인 필요 실제 화면에서 코드를 다시 보내는 링크의 이름이 "재전송하기"인지 "이메일 재전송"인지

⚠ 확인 필요 인증 코드의 유효 시간이 약 10분인지

✔ 정리 claude.ai 계정으로 첫 질문을 보냈고, Usage의 두 숫자를 노트에 적었으며, 상태 페이지를 북마크했습니다.

→ 다음 강의 2강에서는 Usage의 막대가 왜 줄어드는지 알아보고, 이 화면을 다시 열어 두 한도를 읽습니다.
