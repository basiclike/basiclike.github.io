1강. Claude 둘러보기

실습 강의 ⏱ 약 30분

학습 목표

Claude가 어떤 서비스인지 먼저 둘러봅니다.

  • AI가 답을 어떻게 만드는지 알고, 그 답을 왜 확인해야 하는지 설명할 수 있습니다.
  • ChatGPT, Gemini, Meta AI, Grok, Claude가 모두 LLM으로 만든 서비스라는 것을 말할 수 있습니다.
  • Claude를 쓰는 다섯 가지 방법을 구분하고, 그 가운데 이 과정이 쓰는 방법을 말할 수 있습니다.
  • Claude 안의 기능을 이름만 보고 짐작하면 어디서 틀리는지 알고, 기능마다 하는 일과 배울 부(이 과정을 나눈 큰 묶음)를 짝지을 수 있습니다. 카페 주문 키오스크 프로젝트가 부마다 어떻게 쌓여 가는지도 말할 수 있습니다.

"그거 AI한테 물어봤어"의 AI

→ 사람들이 말하는 AI가 답을 어떻게 만드는지, 그래서 그 답을 어떻게 받아 써야 하는지 생각해 봅니다.

AI가 답을 만드는 방식

[이미지: 1강-02 — 기술 그림.] ▲ 다음 말을 골라 붙이고, 늘어난 문장을 다시 읽어 또 고르는 LLM

ChatGPT, Gemini, Claude 같은 서비스 안에서 답을 만드는 기술을 거대 언어 모델, 줄여서 LLM(Large Language Model)이라고 부릅니다.

LLM은 사람이 쓴 아주 많은 글을 읽으면서, 앞에 나온 말 다음에 어떤 말이 올지 맞히도록 훈련한 프로그램입니다.
질문을 받으면 저장해 둔 답을 꺼내지 않고, 질문 뒤에 이어질 가장 그럴듯한 말을 한 조각 고릅니다.
그 조각을 붙인 문장을 다시 읽어 다음 조각을 또 고르고, 이 일을 수백 번 되풀이하면 문단이 되고 표가 됩니다.

==답은 꺼내 온 것이 아니라 그 자리에서 새로 이어 쓴 글==입니다.

매끄러운 답이 틀릴 수 있는 이유

LLM은 사람이 쓴 글에서 말이 이어지는 방식을 익혔으니 답이 매끄럽습니다.
하지만 사실을 하나하나 찾아보고 쓰는 것이 아니라 그럴듯한 다음 말을 고르므로, 모르는 것도 아는 것처럼 이어 쓸 수 있습니다.
이런 일을 환각(hallucination)이라고 부르고, 7강에서 직접 찾아봅니다.

그래서 이 과정 내내 Claude의 답은 출처와 원본으로 확인한 뒤에 씁니다.
==답을 만든 것은 Claude여도, 그 답을 쓴 책임은 여러분에게 있습니다.==

정리하면 "AI한테 물어봤어"의 AI는 사람이 쓴 많은 글을 읽고 다음 말을 이어 쓰도록 만든 LLM이고, 그 답은 꺼내 온 것이 아니라 새로 이어 쓴 것이라 확인한 뒤에 써야 합니다.

↓ 이어서 그러면 LLM으로 만든 대화 서비스에는 무엇이 있을까요?

이름을 자주 듣는 LLM 서비스 다섯 가지

→ 서비스와 모델이 어떻게 다른지 구분하고, 이름을 자주 듣는 LLM 서비스 다섯 가지를 만든 회사와 함께 알아봅니다.

서비스와 모델

우리가 여는 화면은 서비스이고, 그 안에서 답을 이어 쓰는 것은 모델입니다.
Claude라는 이름은 Anthropic이 만든 서비스의 이름이면서 그 안에서 일하는 LLM의 이름이기도 합니다.
Claude 안에서 쓸 모델을 고르는 법은 13강에서 다룹니다.

다섯 서비스

[이미지: 1강-03 — 기술 그림.] ▲ 이름을 자주 듣는 LLM 서비스 다섯 가지

  • ChatGPT: OpenAI가 만든 서비스입니다.
  • Gemini: Google이 만든 서비스입니다.
  • Meta AI: Facebook과 Instagram을 만든 Meta의 서비스입니다.
  • Grok: xAI가 만든 서비스입니다.
  • Claude: Anthropic이 만든 서비스입니다.

⚠ 확인 필요 Grok을 만든 회사 이름을 지금 공식 문서에 적힌 이름으로 쓸지 xAI로 쓸지

다섯 서비스는 만든 회사가 달라도 모두 LLM으로 만든 대화 서비스입니다.

↓ 이어서 그중 Claude는 어디서 열 수 있을까요?

Claude를 어디서 쓸 수 있는지

→ Claude를 어디서 쓸 수 있는지, 이 과정은 그 가운데 어디를 쓰는지 알아봅니다.

Claude를 쓰는 다섯 가지 방법

Claude를 쓰는 방법은 다섯입니다.

방법마다 하는 일

  • 웹: Chrome 같은 브라우저의 주소창에 claude.ai를 입력하면 열리는 화면입니다.
    설치할 것이 없어 가장 먼저 만나는 방법이고, 2강에서 가입하고 4강에서 첫 질문을 보냅니다.
  • 데스크톱 앱: Windows와 macOS에 설치하는 Claude 프로그램입니다.
    웹과 같은 계정으로 로그인하면 웹에서 나눈 대화가 그대로 보이고, 내 컴퓨터의 폴더에 있는 파일까지 다룰 수 있습니다.
    5강에서 설치하고, 7강부터는 주로 이 앱으로 공부합니다.
  • 휴대전화 앱: iPhone과 Android에 설치합니다.
    PC에서 시작한 대화를 밖에서 이어 가고, 목소리로 묻거나 눈앞의 장면을 사진으로 찍어 물을 수 있습니다.
    6강에서 설치합니다.
  • Claude Code 터미널: 터미널은 글자로 명령을 입력하는 창이고, Claude Code는 이 창에서 Claude에게 파일을 읽고 고치고 명령을 실행하는 일을 시키는 도구입니다.
    주로 프로그램을 만드는 사람이 씁니다.
  • 클라우드: 클라우드는 내 컴퓨터가 아니라 인터넷 너머 다른 회사의 컴퓨터를 빌려 쓰는 것을 말합니다.
    내 컴퓨터에 설치하지 않고 브라우저에서 Claude Code를 실행하면 Anthropic이 관리하는 컴퓨터에서 일하고, 내 노트북을 닫아도 일은 이어집니다.

한 장으로 모아 보기

[이미지: 1강-04 — 기술 그림.] ▲ Claude를 쓰는 다섯 가지 방법과 이 부에서 쓰는 방법

가운데의 계정 하나로 다섯 가지 방법을 모두 오가는 것과, 데스크톱 앱 안에 Code 탭이 있는 것을 보면 됩니다.

Claude Code 공식 문서는 데스크톱 앱 안의 Claude Code를 Code 탭이라고 부릅니다.
터미널에 명령을 치지 않아도 앱의 창과 버튼으로 Claude Code에게 일을 시킬 수 있다는 뜻입니다.
Code 탭은 유료 요금제에서만 쓸 수 있고, 이 과정은 Pro 요금제로 진행하며, 요금제는 11강에서 봅니다.

이 과정에서 쓰는 방법

같은 계정 하나로 다섯 가지 방법을 모두 오갈 수 있지만, 이 부는 웹, 데스크톱 앱, 휴대전화 앱을 씁니다.
Claude Code 다루기 부에서는 데스크톱 앱의 Code 탭으로 결과물을 폴더에 모아 GitHub(프로젝트 파일을 인터넷에 보관하는 서비스)에 올리고 사이트로 공개하고, 터미널에서 직접 쓰는 Claude Code도 그 부가 맡습니다.
클라우드는 이 과정에서 쓰지 않습니다.

정리하면 Claude는 웹 채팅 하나가 아니라 계정 하나로 오가는 다섯 가지 방법으로 쓰고, 이 부는 그 가운데 웹, 데스크톱 앱, 휴대전화 앱을 씁니다.

↓ 이어서 쓰는 방법을 알았으니, 그 안에서는 무엇을 할 수 있을까요?

Claude로 할 수 있는 일

→ Claude 안의 기능이 저마다 무엇을 하는지, 어느 부에서 배우는지 알아봅니다.

입력창 하나 뒤에 있는 기능

Claude에는 답을 받는 방식과 결과물의 모양을 바꾸는 기능이 여럿 있습니다.

이 과정에서 배울 기능은 검색, Research, Project, Artifacts, Design, Docs, Skill, 커넥터입니다.

기능마다 하는 일

검색

검색은 Claude가 모르는 최신 정보가 필요할 때 인터넷을 찾아 답에 넣고 출처를 붙이는 기능입니다.
Claude Work 부에서 검색으로 묻고 답의 출처를 직접 열어 대조합니다.

Research

⚠ 자주 하는 오해 Research는 영어 뜻이 "조사"라서 검색과 같은 기능이라고 생각하기 쉽습니다.
둘 다 인터넷을 찾는 것은 맞지만 하는 일의 크기가 다릅니다.
검색이 질문 하나에 답하는 데 필요한 만큼 찾는다면, Research는 보고서 한 편을 쓰는 데 필요한 만큼 찾습니다.

Research는 한 번 찾고 끝내지 않고, 찾은 결과를 보고 다음 검색을 이어 가며 한 주제를 깊이 조사해 출처가 붙은 보고서를 내는 기능입니다.
Claude Work 부에서 키오스크 조사 보고서를 받습니다.

Artifacts와 그 안의 Docs, Design

Artifacts는 디자인, 발표 자료, 문서, 대시보드(숫자와 현황을 한눈에 모아 보이는 화면), 작은 도구처럼 남에게 내놓을 결과물을 대화 옆에 띄워 보며 고치는 기능입니다.
예를 들어 발표 자료를 만들어 달라고 하면 대화 옆에 발표 자료가 따로 열리고, 그 자리에서 바로 고칩니다.
결과물은 사이드바의 Artifacts 탭에 모입니다.
Claude Work 부에서 배웁니다.

Docs와 Design은 따로 떨어진 기능이 아니라 Artifacts에서 고르는 템플릿입니다.
템플릿은 미리 짜 둔 틀을 말합니다.
Docs는 Claude와 동료와 함께 고쳐 가는 문서를 쓰는 틀입니다.
Claude Work 부에서 Artifacts와 함께 배웁니다.

Design은 대화로 화면 디자인과 클릭해 볼 수 있는 시제품을 만드는 틀입니다.
Claude로 디자인하기 부에서 키오스크 화면을 만듭니다.

Project와 Skill과 커넥터

  • Project: 한 가지 일에 쓰는 파일과 지침과 대화를 한데 모아, 그 안의 모든 대화가 같은 자료를 읽고 일하게 하는 기능입니다.
    Claude Work 부에서 키오스크 Project를 만듭니다.
  • Skill: 되풀이하는 일의 방법을 문장으로 적어 둔 지시 묶음입니다.
    한 번 만들어 두면 그 일이 필요할 때 Claude가 꺼내 씁니다.
    Claude Work 부에서 만들어 씁니다.
  • 커넥터: Google Drive, Gmail, Google Calendar처럼 이미 쓰는 서비스를 Claude에 연결해, Claude가 그 안의 문서와 메일과 일정을 직접 읽고 일하게 하는 기능입니다.
    Claude Work 부에서 연결합니다.

데스크톱 앱의 Code 탭

마지막으로 데스크톱 앱의 Code 탭은 앞의 기능들로 만든 결과물을 내 PC의 폴더 하나에 모아 GitHub에 올려 사이트로 공개하는 데 씁니다.
Claude Code 다루기 부에서 씁니다.

기능을 배우는 차례

[이미지: 1강-05 — 기술 그림.] ▲ 기능마다 배우는 부

기능마다 배우는 부를 이어 놓으면 이 과정이 어디로 이어지는지 보입니다.
이 부(Claude 시작하기)에서는 가입과 설치, 묻는 법, 요금제와 모델을 먼저 익히고, 위의 기능은 부를 옮겨 가며 하나씩 만납니다.

이름만 보고 짐작하면 맞는 것도 있지만, Research처럼 이름은 비슷해 보여도 하는 일의 크기가 다른 것이 있고, Docs와 Design처럼 따로 있는 줄 알기 쉬운데 Artifacts 안에 있는 것도 있습니다.

기능 이름을 지금 외울 필요는 없습니다.
나중에 각 기능을 만났을 때 "1강에서 본 그 기능"이라고 떠올릴 자리를 이 그림이 만들어 둡니다.

Claude를 쓰는 다섯 가지 방법
웹: 브라우저에서 claude.ai로 바로 쓴다. 설치할 것이 없다.
데스크톱 앱: Windows와 macOS에 설치한다. 웹과 같은 계정, 같은 대화.
휴대전화 앱: iPhone과 Android에 설치해 밖에서도 대화를 이어 간다.
Claude Code 터미널: 글자로 명령하는 창에서 파일을 고치고 명령을 실행시킨다. 데스크톱 앱(Code 탭)과 코드 편집기에서도 쓴다.
클라우드: 설치 없이 브라우저에서 Claude Code를 시키면 Anthropic의 컴퓨터에서 일한다.

Claude 안의 기능
검색: 켜는 버튼 없이, 도움이 될 때 Claude가 웹을 찾는다.
Research: 여러 번 이어 찾아 깊이 조사한다. "+" 버튼에서 고르거나 /deep-research.
Project: 일 하나에 쓰는 파일, 지침, 대화를 한데 모은다.
Artifacts: 남에게 내놓을 결과물을 대화 옆에 띄워 고친다. Artifacts 탭에 모인다.
Design: Artifacts의 템플릿. 대화로 화면 디자인과 시제품을 만든다.
Docs: Artifacts의 템플릿. 다른 사람과 함께 고치는 문서를 쓴다.
Skill: 되풀이하는 일의 방법을 적어 두고 필요할 때 다시 쓴다.
커넥터: 이미 쓰는 서비스를 연결해 Claude가 직접 읽고 일하게 한다.

강의마다 두 번의 실습

강의마다 실습은 두 번입니다.
첫째 실습에서는 그 강의의 기능을 누구나 겪는 일반적인 예로 익히고, 둘째 실습에서는 같은 기능을 카페 주문 키오스크 개선 프로젝트에 다시 써서 복습합니다.
앞 강의의 둘째 실습에서 남은 결과물이 뒤 강의의 재료가 되어, 강의를 마칠수록 프로젝트가 한 단계씩 쌓입니다.

키오스크 프로젝트가 하는 일

이 프로젝트는 카페 주문 키오스크를 쓰는 사람이 겪는 불편을 조사하고, 그 조사 결과를 근거로 필요한 기능과 화면을 정하고, 클릭해 볼 수 있는 시제품을 만들어 정한 대로 동작하는지 검증하는 일입니다.
실제 카페에 납품하는 제품이 아니라 공부를 위한 프로젝트입니다.

시제품이 다루는 범위는 메뉴 선택, 옵션 변경, 장바구니, 결제 방식 선택, 모의 주문 완료의 다섯 화면입니다.
실제 결제는 하지 않고, 결제 방식을 고르면 주문 완료 화면을 보여 주는 데서 끝납니다.

가설에서 출발하기

프로젝트는 짐작 하나에서 출발합니다.
"음료 옵션을 잘못 골랐을 때 고치기 어렵다."

그럴듯하게 들리지만, ==조사로 확인하기 전까지는 사실이 아니라 가설==입니다.
Claude에게 물으면 이 가설을 뒷받침하는 그럴듯한 답이 바로 돌아오겠지만, 그 답도 이어 쓴 글이라 조사 결과와 대조해야 합니다.
조사 결과가 다르면 가설을 버리거나 고칩니다.

이 과정의 강의마다 둘째 실습이 결과를 출처나 원본과 대조하며 끝나는 것도 이 칸을 채우기 위해서입니다.

📌 정리

  • "AI한테 물어봤어"의 AI는 다음 말을 이어 쓰는 LLM이라 매끄러운 답도 틀릴 수 있고, 그래서 받은 답은 확인한 뒤에 씁니다.
  • ChatGPT, Gemini, Meta AI, Grok, Claude는 만든 회사와 내세우는 기능이 달라도 모두 LLM 위에 만든 대화 서비스입니다.
  • Claude는 계정 하나로 다섯 가지 방법으로 쓰고, 그 안의 기능은 저마다 배우는 부로 이어집니다.
  • 그 기능을 하나씩 익히며 카페 키오스크 프로젝트를 조사부터 포트폴리오까지 쌓아 가고, Claude를 어떻게 썼는지까지 결과물로 남깁니다.

💡 용어 정리

용어 뜻
LLM(거대 언어 모델) 사람이 쓴 많은 글을 읽고 앞의 말 다음에 올 말을 맞히도록 훈련한 프로그램
서비스와 모델 서비스는 우리가 여는 화면이고, 모델은 그 안에서 답을 이어 쓰는 LLM
환각 LLM이 모르는 것을 아는 것처럼 그럴듯하게 틀리게 이어 쓰는 일
터미널 마우스로 클릭하는 대신 글자로 명령을 입력하는 창
클라우드 내 컴퓨터가 아니라 인터넷 너머 회사의 컴퓨터를 빌려 쓰는 것
