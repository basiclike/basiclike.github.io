AI가 답을 만드는 방식

→ ChatGPT, Gemini, Claude 같은 서비스가 답을 어떻게 만드는지, 그래서 받은 답을 어떻게 써야 하는지 알아봅니다.

ChatGPT, Gemini, Claude 같은 서비스 안에서 답을 만드는 기술을 거대 언어 모델, 줄여서 LLM(Large Language Model)이라고 부릅니다.
LLM은 사람이 쓴 아주 많은 글을 읽고, 앞에 나온 말 다음에 올 말을 맞히도록 훈련한 프로그램입니다.
질문을 받으면 저장해 둔 답을 꺼내지 않고, 가장 그럴듯한 다음 말을 한 조각씩 골라 이어 씁니다.

그래서 답이 매끄러워도 사실과 다를 수 있습니다.
이 과정에서는 Claude의 답을 출처와 원본으로 확인한 뒤 쓰고, ==답을 쓴 책임은 여러분에게 있습니다.==
환각(LLM이 모르는 것을 아는 것처럼 이어 쓰는 일)을 직접 찾아보는 일은 7강에서 합니다.

↓ 이어서 그러면 LLM으로 만든 대화 서비스에는 무엇이 있을까요?

이름을 자주 듣는 LLM 서비스 다섯 가지

→ 서비스와 모델이 어떻게 다른지 구분하고, 이름을 자주 듣는 LLM 서비스 다섯 가지를 만든 회사와 함께 알아봅니다.

서비스와 모델

우리가 여는 화면은 서비스이고, 그 안에서 답을 이어 쓰는 것은 모델입니다.
Claude라는 이름은 Anthropic이 만든 서비스의 이름이면서 그 안에서 일하는 LLM의 이름이기도 합니다.
Claude 안에서 쓸 모델을 고르는 법은 13강에서 다룹니다.

다섯 서비스

[이미지: 1강-03 — 기술 그림.] ▲ 이름을 자주 듣는 LLM 서비스 다섯 가지

  • ChatGPT: OpenAI가 만든 서비스입니다.
  • Gemini: Google이 만든 서비스입니다.
  • Meta AI: Facebook과 Instagram을 만든 Meta의 서비스입니다.
  • Grok: xAI가 만든 서비스입니다.
  • Claude: Anthropic이 만든 서비스이고, 이 과정에서 쓰는 서비스입니다.

다섯 서비스는 만든 회사가 달라도 모두 LLM으로 만든 대화 서비스입니다.

↓ 이어서 그중 Claude는 어디서 열 수 있을까요?

Claude를 쓰는 다섯 가지 방법

→ Claude를 쓰는 다섯 가지 방법을 알아보고, 이 과정에서 쓰는 방법을 확인합니다.

[이미지: 1강-04 — 기술 그림.] ▲ Claude를 쓰는 다섯 가지 방법과 Claude 시작하기에서 쓰는 방법

방법 설명
웹 브라우저에서 claude.ai를 열어 씁니다. 설치할 것이 없습니다.
데스크톱 앱 Windows와 macOS에 설치합니다. 내 컴퓨터의 폴더에 있는 파일도 다룹니다.
휴대전화 앱 iPhone과 Android에 설치합니다. 음성과 사진으로 물을 수 있습니다.
Claude Code 터미널 글자로 명령하는 창(터미널)에서 Claude에게 파일을 고치고 명령을 실행하게 합니다.
클라우드 내 컴퓨터가 아니라 Anthropic의 컴퓨터에서 Claude Code를 실행합니다.

이 과정에서는 웹, 데스크톱 앱, 휴대전화 앱을 쓰고, Code 탭과 터미널은 Claude Code 다루기에서 씁니다. 클라우드는 쓰지 않습니다.

데스크톱 앱 안의 Claude Code를 Code 탭이라고 부릅니다.
Code 탭은 유료 요금제에서만 쓸 수 있고, 이 과정은 Pro 요금제로 진행하며, 요금제는 11강에서 봅니다.

↓ 이어서 쓰는 방법을 알았으니, 그 안에는 어떤 기능이 있을까요?

Claude의 기능

→ Claude 안의 기능이 무엇을 하는지 한 줄씩 보고, 어느 과정에서 배우는지 알아봅니다.

[이미지: 1강-05 — 기술 그림.] ▲ 기능마다 배우는 과정

Claude 시작하기에서는 가입과 설치, 묻는 법, 요금제와 모델을 먼저 익히고, 아래 기능은 Claude Work, Claude로 디자인하기, Claude Code 다루기를 거치며 하나씩 만납니다.

기능 하는 일
검색 최신 정보가 필요할 때 인터넷을 찾아 답에 넣고 출처를 붙입니다.
Research 한 주제를 여러 번 이어 찾아 출처가 붙은 보고서를 냅니다.
Project 한 가지 일에 쓰는 파일과 지침과 대화를 한데 모읍니다.
Artifacts 발표 자료, 문서, 대시보드 같은 결과물을 대화 옆에 띄워 고칩니다.
Docs Artifacts 안에서 동료와 함께 고치는 문서를 씁니다.
Design Artifacts 안에서 화면 디자인과 클릭해 볼 수 있는 시제품을 만듭니다.
Skill 되풀이하는 일의 방법을 적어 두면 필요할 때 Claude가 꺼내 씁니다.
커넥터 Google Drive, Gmail 같은 서비스를 연결해 Claude가 직접 읽고 일하게 합니다.
Code 탭 결과물을 폴더에 모아 GitHub(프로젝트 파일을 인터넷에 보관하는 서비스)에 올려 사이트로 공개합니다.

기능 이름을 지금 외울 필요는 없습니다.
나중에 각 기능을 만났을 때 "1강에서 본 그 기능"이라고 떠올릴 자리를 이 그림이 만들어 둡니다.

↓ 이어서 기능과 요금제가 바뀌면 어디를 확인하면 될까요?

확인할 공식 페이지

→ Claude의 기능과 화면은 자주 바뀌므로, 바뀌었을 때 확인할 공식 페이지를 알아 둡니다.

  • Claude 시작하기 도움말: Claude를 처음 쓰는 사람을 위해 웹, 데스크톱, 휴대전화로 쓰는 방법을 소개합니다.
  • Claude Code 설명서: Claude Code를 쓰는 방법 네 가지를 소개합니다.
  • Claude 제품 소개: Artifacts, Design, 커넥터, Skill 같은 기능을 소개합니다.
  • Cowork와 대화가 하나라는 도움말: 검색과 Research를 쓰는 방법을 알려 줍니다.
  • Claude Docs 도움말: Docs를 소개합니다.
  • 요금제: 요금제마다 쓸 수 있는 기능을 보여 줍니다. 요금제를 고르는 법은 11강에서 다룹니다.

나중에 들은 이야기나 내 화면이 이 강의와 다르면, 위 페이지를 다시 열어 확인하면 됩니다.

↓ 이어서 이 과정을 끝까지 이어 가는 프로젝트는 무엇일까요?

키오스크 프로젝트 미리 보기

→ 이 과정을 끝까지 이어 가는 카페 키오스크 프로젝트로 무엇을 만들어 가는지, 완성 예시를 열어 미리 봅니다.

강의마다 두 번의 실습

강의마다 실습은 두 번입니다.
첫째 실습에서는 그 강의의 기능을 누구나 겪는 일반적인 예로 익히고, 둘째 실습에서는 같은 기능을 카페 주문 키오스크 개선 프로젝트에 다시 써서 복습합니다.
앞 강의의 둘째 실습에서 남은 결과물이 뒤 강의의 재료가 되어, 강의를 마칠수록 프로젝트가 한 단계씩 쌓입니다.

키오스크 프로젝트가 하는 일

이 프로젝트는 카페 주문 키오스크를 쓰는 사람이 겪는 불편을 조사하고, 그 조사 결과를 근거로 필요한 기능과 화면을 정하고, 클릭해 볼 수 있는 시제품을 만들어 정한 대로 동작하는지 검증하는 일입니다.
실제 카페에 납품하는 제품이 아니라 공부를 위한 프로젝트입니다.

시제품이 다루는 범위는 메뉴 선택, 옵션 변경, 장바구니, 결제 방식 선택, 모의 주문 완료의 다섯 화면입니다.
실제 결제는 하지 않고, 결제 방식을 고르면 주문 완료 화면을 보여 주는 데서 끝납니다.

시제품의 다섯 화면

[화면 캡처: 1강-14 — 시제품의 다섯 화면 — kiosk-report-example.pdf의 목업 쪽. 완성 예시 시제품의 다섯 화면을 주문하는 차례로 놓은 그림 (Claude가 찍을 수 있음). ① 메뉴 선택, ② 옵션 변경, ③ 장바구니, ④ 결제 방식, ⑤ 주문 완료] ▲ 완성 예시 시제품의 다섯 화면

왼쪽부터 주문하는 차례대로 놓여 있고, 둘째 화면에서 크기와 온도와 샷을 바꾸면 금액이 함께 바뀌는 것을 보면 됩니다.

프로젝트에서 만드는 네 가지

[이미지: 1강-15 — 기술 그림.] ▲ 키오스크 프로젝트의 결과물이 쌓이는 차례

이 다섯 화면에 닿기까지 만드는 것은 크게 넷입니다.

  • 조사 보고서: Claude Work에서 검색과 Research로 불편 사례를 조사해 출처와 대조하고, Word 보고서와 Excel 사실 정리표(확인한 사실만 모은 표)로 받습니다.
  • 기획과 목업: Claude Work에서 조사를 근거로 문제를 정하고 기획서와 요구사항(만들 기능의 목록), 순서도(화면이 이어지는 차례를 화살표로 그린 그림)를 쓴 뒤, Claude로 디자인하기에서 Design으로 목업(화면 모양을 먼저 그려 본 그림)과 시제품을 만듭니다.
  • 사이트: Claude Code 다루기에서 Code 탭으로 모든 결과물을 C:\kiosk-project 폴더 하나에 모아 GitHub에 올리고, GitHub Pages(GitHub에 올린 파일을 웹사이트로 여는 기능)로 내 주소의 프로젝트 사이트를 엽니다.
  • 포트폴리오: Claude로 디자인하기와 Claude Code 다루기에서 지금까지의 결과물을 개발 완료 보고서나 포트폴리오 한 벌로 묶습니다.

조사 보고서는 기획의 근거가 되고, 기획서와 순서도가 목업과 시제품의 근거가 됩니다.

  • 그 기능을 하나씩 익히며 카페 키오스크 프로젝트를 조사부터 포트폴리오까지 쌓아 가고, Claude를 어떻게 썼는지까지 결과물로 남깁니다.
