대표적인 AI 와 만든 회사

이름을 자주 듣는 AI 서비스는 다섯이고, 회사마다 따로 만듭니다.

서비스 만든 회사 특이사항
ChatGPT OpenAI 2025년 10월에 비영리 재단(OpenAI Foundation)이 영리 법인(OpenAI Group PBC)을 지배하는 구조로 바뀌었습니다.
Gemini Google Google DeepMind가 만든 모델이고, Google 검색과 Gmail, Docs 같은 Google 앱 안에서도 쓰입니다.
Meta AI Meta WhatsApp, Instagram, Facebook, Messenger 안에서 쓰고, Meta는 Llama 모델을 내려받아 쓸 수 있게 공개해 왔습니다.
Grok xAI 2026년 2월에 SpaceX가 xAI를 인수했고, Grok은 X 앱 안에서도 쓸 수 있습니다.
Claude Anthropic 2021년에 OpenAI 출신들이 세웠고, 공익법인(PBC)으로 운영됩니다.

이 강의는 Claude를 사용하고, Pro 유료 요금제로 씁니다.

Claude의 서비스

Claude도 하나의 서비스가 아니라 쓰임새에 따라 나뉩니다.

서비스 한 줄 설명
Claude 앱(claude.ai) 웹, 데스크톱, 휴대전화에서 대화로 Claude를 쓰는 기본 서비스입니다. 채팅과 Cowork가 한 앱으로 합쳐지는 중입니다.
Claude Code 코딩에 쓰는 도구입니다. 터미널, 데스크톱 앱, 웹에서 씁니다.
Claude Cowork 터미널 없이 Claude Code의 방식을 코딩 밖의 업무에 씁니다. Excel과 PowerPoint 파일을 만들고 Chrome을 조작합니다.
Claude Platform 개발자용 API입니다. 만든 프로그램에 Claude를 붙이거나 자동화를 구성할 때 씁니다.
Claude Security 코드의 취약점을 찾고 패치를 제안합니다. 지금은 Claude Enterprise 고객에게 공개 베타로 제공합니다.
Claude Design 대화로 디자인과 프로토타입, 한 장짜리 문서를 만듭니다.

이 과정은 이 가운데 Claude 앱으로 시작하고, 나머지는 앞으로 배울 과정에서 만납니다.

↓ 이어서 그렇다면 Claude는 어디에서 쓸 수 있을까요?

Claude를 쓰는 방법

→ Claude를 쓰는 다섯 가지 방법을 한눈에 봅니다.

Claude는 웹사이트에서만 쓰는 서비스가 아닙니다. 쓰는 방법은 다섯입니다.

  • 웹(claude.ai): 브라우저에서 claude.ai를 열어 씁니다.
  • 데스크톱 앱: Windows와 macOS에 설치해 씁니다.
  • 휴대전화 앱: iPhone과 Android에 Claude by Anthropic 앱을 설치해 씁니다.
  • Claude Code 터미널: 명령을 글자로 입력하는 창인 터미널에서 Claude Code를 씁니다.
  • 클라우드: Anthropic의 컴퓨터에서 Claude Code를 돌립니다. claude.ai/code와 데스크톱 앱의 Cloud 환경에서 쓰고, 앱을 닫아도 세션이 이어집니다.

같은 Claude를 웹, 앱, 터미널, 클라우드에서 골라 쓸 수 있습니다.

↓ 이어서 Claude 안에는 어떤 기능이 있을까요?

업무에 쓰는 기능

→ Claude의 업무 기능을 배울 과정에 따라 나누어 이름만 봅니다.

Claude 안에는 업무에 쓰는 기능이 있습니다. 앞으로 배울 과정에 따라 나누면 셋입니다.

배우는 과정 기능 하는 일
4. CLAUDE WORK Research 웹을 여러 번 이어 검색하며 조사합니다.
  Artifacts 디자인, 슬라이드, 문서, 작은 도구를 만들어 대화 옆에 보여 줍니다.
  Docs Claude와 팀이 함께 쓰는 문서입니다.
  Project 대화 기록과 문서를 따로 모아 두는 작업 공간입니다.
  Skill Claude가 일에 맞게 불러 쓰는 지침과 자료를 담은 폴더입니다.
  Connectors Gmail, Google Calendar 같은 서비스를 Claude에 연결합니다.
5. CLAUDE DESIGN Claude Design 대화로 디자인과 프로토타입을 만듭니다.
6. CLAUDE CODE Claude Code 코딩에 쓰는 도구입니다. 터미널, 데스크톱 앱, 웹에서 씁니다.

이 기능들은 앞으로 배울 때 하나씩 다시 나옵니다. 지금은 이런 기능이 있다는 것만 알면 됩니다.

↓ 이어서 마지막으로, Claude라는 이름과 로고는 어디서 왔을까요?

Claude의 이름과 로고

→ Claude라는 이름이 어디서 왔는지, 로고에 어떤 뜻이 담겨 있는지 봅니다.

이름의 유래

Claude라는 이름은 사람 이름처럼 들립니다. 정보 이론을 세운 수학자 클로드 섀넌(Claude Shannon)의 이름에서 왔다고 합니다.

로고에 담긴 뜻

Claude의 얼굴인 로고에도 설계 의도가 담겨 있습니다. 아이콘 하나에도 의도가 있다고 보고, 요소마다 담긴 뜻을 정리하면 이렇습니다.

요소 의미
별표(asterisk) 형태 타이포그래피에서 별표(*)는 "추가 설명", "더 알아볼 것"을 뜻합니다. Claude가 보완적이고 보조적인 존재라는 성격을 담고 있습니다.
빛이 퍼지는 구조 아이디어와 지식이 사방으로 뻗어 나가는 이미지입니다.
불규칙한 획 딱딱하지 않고 유기적인 느낌을 주어, 차갑고 기계적인 AI 이미지 대신 인간적인 따뜻함을 표현합니다.
테라코타/코랄 계열 색상 친근하고 따뜻한 인상을 주려고 고른 색입니다. 기계적인 파랑이나 회색 계열을 일부러 피했습니다.

이 형태는 공식적으로 asterism(성단)이라고 불리기도 합니다. Anthropic이 로고 제작 철학을 자세히 공개한 자료는 많지 않아서, 위 설명의 일부는 디자인적 해석입니다. 공식 출처가 궁금하면 anthropic.com에서 확인합니다.

이름은 클로드 섀넌에서 왔고, 로고는 보완적이고 따뜻한 Claude의 성격을 담은 표시로 해석됩니다.

정리

→ 이번 강의에서 알아본 것을 모으고 다음 강의로 넘어갑니다.

📌 정리

  • Claude는 Anthropic이 만든 AI 서비스이고, 이 과정은 Pro 요금제로 진행합니다.

  • Research, Artifacts, Docs, Project, Skill, Connectors, Claude Design, Claude Code는 앞으로 배울 업무 기능입니다.
  • Claude는 수학자 클로드 섀넌의 이름에서 왔다고 하고, 로고는 보완적이고 따뜻한 성격을 담은 표시로 해석됩니다.
