Claude와 AI 서비스

→ Claude를 만든 회사와 다른 AI 서비스를 보고, 이 과정에서 쓰는 서비스를 확인합니다.

[이미지: 1강-01 — 기술 그림.] ▲ 이름을 자주 듣는 AI 서비스 다섯과 만든 회사

이름을 자주 듣는 AI 서비스는 다섯이고, 회사마다 따로 만듭니다.

서비스 만든 회사
ChatGPT OpenAI
Gemini Google
Meta AI Meta
Grok xAI
Claude Anthropic

⚠ 확인 필요 Grok을 만든 회사를 xAI로 쓸지 SpaceXSI로 쓸지 정해 주세요. xAI 공식 문서는 Grok을 SpaceXSI의 비서로 적고, 뉴스 페이지에는 SpaceX가 xAI를 인수했다는 문구가 있습니다.

이 과정은 이 가운데 Claude를 Pro 유료 요금제로 씁니다.

↓ 이어서 그렇다면 Claude는 어디에서 쓸 수 있을까요?

Claude를 쓰는 방법

→ Claude를 쓰는 다섯 가지 방법을 한눈에 봅니다.

[이미지: 1강-02 — 기술 그림.] ▲ Claude를 쓰는 다섯 가지 방법

Claude는 웹사이트에서만 쓰는 서비스가 아닙니다. 쓰는 방법은 다섯입니다.

  • 웹(claude.ai): 브라우저에서 claude.ai를 열어 씁니다.
  • 데스크톱 앱: Windows와 macOS에 설치해 씁니다.
  • 휴대전화 앱: iPhone과 Android에 Claude by Anthropic 앱을 설치해 씁니다.
  • Claude Code 터미널: 명령을 글자로 입력하는 창인 터미널에서 Claude Code를 씁니다.
  • 클라우드: Anthropic의 컴퓨터에서 Claude Code를 돌립니다. claude.ai/code와 데스크톱 앱의 Cloud 환경에서 쓰고, 앱을 닫아도 세션이 이어집니다.

같은 Claude를 웹, 앱, 터미널, 클라우드에서 골라 쓸 수 있습니다.

↓ 이어서 Claude 안에는 어떤 기능이 있을까요?

업무에 쓰는 기능

→ Claude의 업무 기능을 배울 과정에 따라 나누어 이름만 봅니다.

[이미지: 1강-03 — 기술 그림.] ▲ Claude의 업무 기능을 배울 과정에 따라 나눈 그림

Claude 안에는 업무에 쓰는 기능이 있습니다. 앞으로 배울 과정에 따라 나누면 셋입니다.

배우는 과정 기능 하는 일
CLAUDE WORK Research 웹을 여러 번 이어 검색하며 조사합니다.
CLAUDE WORK Artifacts 디자인, 슬라이드, 문서, 작은 도구를 만들어 대화 옆에 보여 줍니다.
CLAUDE WORK Docs Claude와 팀이 함께 쓰는 문서입니다.
CLAUDE WORK Project 대화 기록과 문서를 따로 모아 두는 작업 공간입니다.
CLAUDE WORK Skill Claude가 일에 맞게 불러 쓰는 지침과 자료를 담은 폴더입니다.
CLAUDE WORK Connectors Gmail, Google Calendar 같은 서비스를 Claude에 연결합니다.
CLAUDE DESIGN Claude Design 대화로 디자인과 프로토타입을 만듭니다.
CLAUDE CODE Claude Code 코딩에 쓰는 도구입니다. 터미널, 데스크톱 앱, 웹에서 씁니다.

이 기능들은 앞으로 배울 때 하나씩 다시 나옵니다. 지금은 이런 기능이 있다는 것만 알면 됩니다.

↓ 이어서 마지막으로, Claude라는 이름과 로고는 어디서 왔을까요?

Claude의 이름과 로고

→ Claude라는 이름이 어디서 왔는지 봅니다.

[화면 캡처: 1강-04 — claude.ai 첫 화면. ① Claude 로고: claude.ai 화면에서 Claude를 나타내는 표시 (안내 합성)] ▲ claude.ai에서 보이는 Claude 로고

Claude라는 이름은 사람 이름처럼 들립니다. 정보 이론을 세운 수학자 클로드 섀넌(Claude Shannon)의 이름에서 왔다고 합니다.

⚠ 확인 필요 Claude 이름이 클로드 섀넌에서 유래했다는 설명은 Anthropic 공식 문서에서 찾지 못했습니다. 이 문장을 그대로 둘지 정해 주세요.

이름은 Claude Shannon에서, 로고는 claude.ai에서 볼 수 있는 이 표시입니다.
