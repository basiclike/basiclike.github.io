대표적인 AI와 만든 회사

❓ 질문 Claude는 AI 서비스 가운데 무엇일까요?

그림에서 크게 보이는 Claude 카드가 이 과정에서 쓸 서비스입니다.

AI 서비스라고 하면 ChatGPT를 먼저 떠올리는 분이 많습니다.
하지만 ChatGPT는 여러 서비스 가운데 하나이고, 서비스마다 만든 회사가 다릅니다.

서비스 만든 회사 특이사항
ChatGPT OpenAI 글쓰기, 코딩, 이미지와 파일 분석에 쓰는 AI 비서입니다.
Gemini Google 글과 음성과 이미지를 함께 다루는 Google의 AI 앱입니다.
Meta AI Meta meta.ai와 앱뿐 아니라 WhatsApp, Instagram, Messenger, Facebook 안에서도 씁니다.
Grok xAI xAI의 AI 비서입니다.
Claude Anthropic 웹, 데스크톱 앱, 휴대전화 앱, Claude Code로 쓰는 AI 비서이고, 이 과정에서 쓰는 서비스입니다.

다섯 서비스는 모두 대규모 언어 모델(LLM)로 만든 대화 서비스입니다.
이름과 만든 회사는 달라도 말로 물으면 말로 답하는 점이 같습니다.

그러면 Claude라는 이름 아래에는 어떤 서비스가 있을까요?

Claude의 서비스

Claude는 서비스 하나가 아니라, 같은 이름 아래 목적이 다른 서비스가 여럿 모여 있습니다.

서비스 설명
Claude 웹, 데스크톱 앱, 휴대전화 앱에서 대화로 쓰는 기본 서비스입니다. 파일과 Excel, PowerPoint, Chrome 작업을 맡기는 Cowork가 이 대화에 합쳐지는 중입니다.
Claude Code 터미널뿐 아니라 VS Code, JetBrains, 데스크톱 앱의 Code 탭, 웹에서도 쓰는 코딩 도구입니다. 데스크톱 앱에서는 유료 구독이 필요합니다.
Claude Duet 최근 연구 미리보기로 나왔고 Pro와 Max에서 씁니다.
Claude Security 코드의 취약점을 찾고 수정을 추적하며 패치를 제안합니다. 예전 이름은 Claude Code Security이고, Enterprise 고객을 대상으로 공개 베타 중입니다.
Artifacts Claude가 만든 디자인, 슬라이드, 문서, 대시보드, 작은 도구를 대화 옆에 열어 두는 기능입니다. Free부터 모든 요금제에서 씁니다.
Claude Design 대화로 디자인, 시제품, 한 장짜리 문서를 만듭니다. Artifacts의 템플릿 하나이고, 별도 사이트는 닫혀 Claude 안에서 씁니다.

이 과정에서는 Claude를 Pro 유료 요금제로 씁니다.
Pro에서는 Claude Code와 Research를 쓸 수 있습니다.

Claude를 쓰는 방법

→ Claude를 어디에서 쓸 수 있는지, 다섯 가지 방법을 한 줄씩 알아봅니다.

Claude를 처음 열면 어디에 무엇이 있는지부터 막막합니다.
Claude는 웹사이트에서만 쓴다고 생각하기 쉽지만, 같은 Claude를 쓰는 자리가 다섯 가지입니다.

방법 설명
웹 브라우저에서 claude.ai를 열어 씁니다. 설치가 필요 없고 Free부터 쓸 수 있습니다.
데스크톱 앱 Windows와 macOS에 설치해 쓰고, Linux는 베타입니다. 내 컴퓨터의 폴더에 있는 파일도 다룹니다. 앱 안의 Claude Code는 Code 탭이라 부릅니다.
휴대전화 앱 iPhone과 Android에 설치합니다. 앱 이름은 Claude by Anthropic이고, 음성과 사진으로 물을 수 있습니다.
Claude Code 터미널 글자로 명령하는 창(터미널)에서 Claude에게 파일을 고치고 명령을 실행하게 합니다.
클라우드 내 컴퓨터가 아니라 Anthropic의 컴퓨터에서 Claude Code를 실행합니다. 웹(claude.ai/code)과 데스크톱 앱의 Cloud 환경에서 쓰고, 앱을 닫아도 이어집니다.

Claude는 하나이고, 쓰는 방법이 다섯입니다.
설치와 로그인은 2강, 5강, 6강에서 차례로 해 봅니다.

그러면 이 방법들 위에서 Claude는 어떤 일까지 할까요?

업무에 쓰는 기능

→ 앞으로 배울 강의 목차별로 Claude의 기능과 도구가 어떻게 나뉘는지 훑어봅니다.

Claude는 질문에 답하는 데서 끝나지 않고 업무에 쓰는 기능이 여럿 붙어 있습니다.
내 계정에서 어떤 기능을 쓸 수 있는지는 아래 표가 과정 이름별로 답합니다.
표의 첫 칸은 그 기능을 다루는 과정의 이름입니다.

과정 기능과 도구 한 줄 설명
CLAUDE Claude 간단 사용법 가입하고 웹, 데스크톱 앱, 휴대전화 앱에서 첫 질문을 보내 봅니다.
CLAUDE WORK Research 한 주제를 여러 번 이어 검색해 출처가 붙은 보고서를 냅니다. 유료 요금제에서 씁니다.
  Artifacts Claude가 만든 문서와 슬라이드와 작은 도구를 대화 옆에 열어 고칩니다.
  Docs Artifacts의 템플릿 하나로, Claude와 팀이 함께 쓰는 문서입니다.
  Project 한 작업에 쓰는 대화와 문서를 모은 작업 공간입니다.
  Skill Claude가 일에 맞게 불러 쓰는 지침과 스크립트와 자료 폴더입니다.
  Connectors Gmail, Google Calendar 같은 서비스를 연결해 Claude가 직접 읽고 일하게 합니다.
CLAUDE DESIGN Claude Design 대화로 디자인과 시제품을 만듭니다.
CLAUDE CODE Claude Code 터미널과 앱과 웹에서 코딩 작업을 맡깁니다.

이 기능들은 뒤의 과정에서 하나씩 다룹니다.
여기서는 이름과 한 줄 설명만 눈에 담아 두면 됩니다.

서비스와 기능을 다 보았으니, 마지막으로 Claude라는 이름과 로고에 담긴 뜻을 봅니다.

Claude의 이름과 로고

→ Claude라는 이름이 어디에서 왔고 로고가 무엇을 담았는지 알아봅니다.

이름의 유래

Claude라는 이름은 수학자 클로드 섀넌에서 따왔다고 알려져 있습니다.
사람 이름을 서비스 이름으로 쓴 셈이고, 이름을 알면 다른 AI 서비스와 헷갈리지 않고 기억할 수 있습니다.

로고에 담긴 뜻

Claude 로고는 요소마다 뜻을 풀어 볼 수 있습니다.

요소 의미
별표 모양 보충하고 더 알아볼 것을 뜻하는 별표(*)의 이미지로, Claude가 사람을 보조하는 존재라는 성격을 담습니다.
빛이 퍼지는 구조 아이디어와 지식이 사방으로 뻗어 나가는 이미지입니다.
불규칙한 획 차가운 기계 대신 인간적인 따뜻함을 줍니다.
테라코타와 코랄 계열 색 친근하고 따뜻한 인상을 주려고 골랐고, 기계적인 파랑과 회색을 피했습니다.

Anthropic이 로고 제작 철학을 자세히 공개한 자료는 많지 않아서, 위 설명의 일부는 디자인적 해석입니다.
공식 설명은 anthropic.com에서 볼 수 있습니다.

이름은 사람에게서, 로고는 따뜻하게 돕는 이미지에서 왔다고 이해하면 충분합니다.

정리

→ 서비스, 쓰는 방법, 업무 기능, 이름을 한 번에 돌아봅니다.

📌 정리

  • AI 서비스 다섯 가운데 이 과정에서는 Claude를 씁니다.
  • Claude는 웹, 데스크톱 앱, 휴대전화 앱, Claude Code 터미널, 클라우드의 다섯 방법으로 씁니다.
  • 기능은 앞으로 배울 네 과정(CLAUDE, CLAUDE WORK, CLAUDE DESIGN, CLAUDE CODE)으로 나뉩니다.
  • Claude라는 이름은 수학자 클로드 섀넌에서 왔다고 알려져 있습니다.
