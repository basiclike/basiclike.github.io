5강. 데스크톱 앱 설치하고 쓰기

환경 설정 강의 ⏱ 약 30분

학습 목표

2강부터 4강까지 여러분은 Chrome에서 claude.ai를 열어 Claude를 썼습니다.
가입하고, 첫 질문을 보내고, "키오스크 프로젝트"라는 이름의 대화도 만들었습니다.
이번 강의에서는 같은 Claude를 PC에 프로그램으로 설치합니다.

  • 브라우저에서 질문하고 답을 받는 일은 이미 다 되는데도 프로그램을 또 설치하는 이유는 무엇일까요?
    웹 페이지가 내 PC에서 할 수 없는 일을 찾아보며 알아봅시다.
  • 앱에 로그인하면 4강까지 웹에서 나눈 대화가 정말 그대로 나타날까요?
    웹과 앱을 오가며 같은 대화를 이어 써 보고, 그 이유를 알아봅시다.
  • 앱 화면 어디에서 PC 폴더를 연결하고, Code 탭은 어떤 자리인지 확인해 봅시다.
  • 키오스크 프로젝트의 파일을 모을 폴더를 PC에 만들어 대화에 연결하고, Claude가 그 폴더에 파일을 저장하게 해 봅시다.

웹만으로는 부족한 이유

→ 웹에서 Claude를 쓸 때 PC의 파일을 다루기 불편한 이유와, 데스크톱 앱이 그 불편을 어떻게 줄이는지 알아봅니다.

브라우저와 내 PC의 폴더

브라우저에서 질문하고 답을 받는 일이 이미 다 되는데, 왜 프로그램을 또 설치할까요?

Chrome에서 연 웹 페이지는 내 PC의 폴더를 마음대로 열어 볼 수 없습니다.
아무 웹 사이트나 내 문서 폴더를 들여다본다면 위험하기 때문에, 브라우저가 처음부터 막아 둡니다.
그래서 웹에서 Claude에게 파일을 보여 주려면 내가 파일을 하나씩 골라 올려야 하고, Claude가 만든 결과도 하나씩 내려받아 내 손으로 폴더에 옮겨야 합니다.

파일이 한두 개일 때는 불편하지 않습니다.
하지만 이 과정에서 이어 갈 카페 주문 키오스크 개선 프로젝트는 그렇지 않습니다.
조사 보고서, 사실 정리표, 회의록, 기획서, 요구사항, 화면 목업, 시제품, AI 사용 기록까지 파일이 강의마다 늘어납니다.

수강생 A가 이 파일들을 웹에서만 다룬다고 생각해 봅니다.
파일 이름을 하나 바꾸려 해도, 모든 파일의 첫 줄에 날짜를 넣으려 해도, 파일을 하나씩 올리고 결과를 하나씩 내려받아 덮어쓰는 일을 파일 수만큼 되풀이해야 합니다.
서른 개쯤 되면 어느 파일을 고쳤고 어느 파일을 아직 안 고쳤는지부터 헷갈립니다.

↓ 이어서 그렇다면 이 일을 대신 맡길 자리가 어디에 있을까요?

대화에 폴더를 연결하는 기능

데스크톱 앱에는 이 일을 대신 맡길 자리가 있습니다.
대화 입력창의 + 버튼에 든 Add folder입니다.
대화에 내가 고른 PC 폴더를 연결하면, Claude가 그 폴더 안의 파일을 직접 읽고, 만든 결과를 그 폴더에 저장합니다.

파일을 하나씩 올리고 내려받는 대신 "이 폴더의 파일을 이렇게 정리해 줘"라고 한 번에 맡길 수 있습니다.
앱을 설치하는 이유가 여기에 있습니다.

폴더를 연결하는 기능은 Pro, Max, Team, Enterprise 같은 유료 요금제에서 쓰고, 이 강의는 Pro 요금제로 진행합니다.
요금제마다 무엇이 되는지는 11강에서 알아봅니다.

설치해도 처음부터 다시 하지 않습니다

앱을 설치한다고 처음부터 다시 시작하는 것도 아닙니다.
웹에서 쓰던 계정으로 앱에 로그인하면, 4강까지 웹에서 나눈 대화가 앱에도 그대로 나타납니다.

오늘은 앱을 설치해 대화가 그대로 나타나는지 직접 확인합니다.
앱에서 폴더를 연결하는 자리를 찾은 뒤, 키오스크 프로젝트의 파일을 모을 폴더를 내 PC에 만들어 대화에 연결합니다.

==웹은 파일을 하나씩 주고받아야 하지만 데스크톱 앱의 대화는 연결한 PC 폴더의 파일을 직접 다룹니다.==
웹으로도 되는 일을 두고 앱을 설치하는 것은 이 차이 때문입니다.

↓ 이어서 그렇다면 앱을 설치하기 전에 내 PC에서 무엇을 확인해 두어야 할까요?

준비

→ 설치 파일을 고를 수 있도록 내 PC의 칩 종류를 확인하고, 폴더 연결에 필요한 Windows 기능을 켭니다.

내 PC의 칩 종류 확인하기

먼저 설치 파일을 받아야 합니다.
Claude 데스크톱 앱은 Windows 10 이상에서 설치됩니다.
그런데 Windows용 설치 파일은 둘로 나뉘어 있습니다.

Windows PC는 안에 든 칩(프로세서)에 따라 두 종류입니다.
Intel이나 AMD 칩을 쓰는 대부분의 PC가 한 종류이고, Snapdragon 같은 ARM 칩을 쓰는 일부 노트북이 다른 한 종류입니다.
다운로드 페이지에서 칩에 맞는 설치 파일을 골라야 하므로, 내 PC가 어느 쪽인지 먼저 봅니다.

① 키보드의 Windows 키를 누르고 settings를 입력합니다.

② Enter 키를 눌러 Settings(설정)를 엽니다.

③ 왼쪽 목록에서 System(시스템)을 클릭합니다.

④ 오른쪽 목록 맨 아래의 About(정보)을 클릭합니다.

⑤ Device specifications(장치 사양) 아래의 System type(시스템 종류) 줄을 봅니다.

이 줄에 x64-based processor가 적혀 있으면 대부분의 PC와 같은 쪽이고, ARM-based processor가 적혀 있으면 ARM PC입니다.
확인했으면 Settings를 닫습니다.

⚠ 확인 필요 영어판 Windows 11에서 System, About, Device specifications, System type의 이름과 System type 줄에 보이는 글자

[화면 캡처: A-5-01 — Windows 11 Settings의 System > About 화면. ① 왼쪽 목록의 System, ② About, ③ System type 줄]
▲ 칩 종류를 확인하는 About 화면

폴더 연결에 필요한 Windows 기능 켜기

설치 파일을 받기 전에 Windows에서 켜 둘 기능이 하나 더 있습니다.
오늘 마지막에 대화에 PC 폴더를 연결하는데, 공식 Windows 설치 안내는 Windows에서는 Virtual Machine Platform(가상 머신 플랫폼)이라는 Windows 기능이 켜져 있어야 한다고 적습니다.
설치 안내에 따르면 데스크톱 앱은 Claude가 일할 때 다른 프로그램과 떨어진 작은 작업 공간(가상 머신)을 띄우고, 그 작업 공간을 띄우는 데 이 기능을 씁니다.

⚠ 확인 필요 지금 판의 데스크톱 앱에서도 Add folder에 Virtual Machine Platform이 있어야 하는지(다른 공식 도움말은 이 일이 Anthropic의 서버에서 실행된다고 적는다)

① Windows 키를 누르고 Turn Windows features on or off를 입력합니다.

② Enter 키를 누릅니다.

Windows Features(Windows 기능) 창이 열립니다.

③ 목록에서 Virtual Machine Platform 줄을 찾습니다.

줄 앞의 칸에 이미 체크가 있으면 켜져 있는 것이니, Cancel(취소)을 클릭해 창을 닫고 넘어갑니다.
칸이 비어 있으면 아래 ④⑤를 합니다.

④ 칸을 클릭해 체크합니다.

⑤ OK(확인)를 클릭합니다.

이 기능을 켜려면 관리자 권한이 있어야 해서, 허락을 묻는 창이 뜨면 허락합니다.
기능을 켠 Windows가 다시 시작하라고 하면 Restart now(지금 다시 시작)를 클릭합니다.

⚠ 확인 필요 영어판 Windows 11에서 이 검색어로 창이 열리는지와 창 이름, 목록의 줄 이름 ⚠ 확인 필요 기능을 켠 뒤 나오는 창과 다시 시작하는 버튼의 이름

[화면 캡처: A-5-02 — Windows Features 창. ① Virtual Machine Platform 줄의 체크 칸, ② OK 버튼]
▲ Virtual Machine Platform을 켜는 창

다시 시작하는 방법

켠 기능은 PC를 다시 시작해야 적용됩니다.
직접 다시 시작할 때는 시작 메뉴의 전원 버튼에서 Shut down(시스템 종료)이 아니라 Restart(다시 시작)를 고릅니다.
공식 안내는 껐다 켜면 Windows의 빠른 시작 기능 때문에 가상 머신을 띄우는 준비가 덜 된 채 켜질 수 있다고 적습니다.

↓ 이어서 다시 시작한 PC에서 설치 파일은 어디서 어떻게 받을까요?

설치 파일 받아 설치하기

→ 다운로드 페이지에서 내 PC에 맞는 설치 파일을 받고, 관리자 권한을 허락하며 설치합니다.

설치 파일 다운로드

PC가 다시 켜지면 Chrome을 엽니다.
4강까지 쓰던 claude.ai 탭이 없으면 claude.ai를 열어 둡니다.
뒤에서 웹과 앱을 오가며 같은 대화가 보이는지 확인하기 때문입니다.

① 새 탭을 열고 주소창에 claude.com/download를 입력합니다.

② Enter 키를 누릅니다.

1강에서 둘러본 Claude 다운로드 페이지가 열립니다.

③ 페이지를 아래로 내려 Desktop(데스크톱) 아래의 Windows 자리를 찾습니다.

Windows용으로는 Windows, Windows (arm 64), Microsoft Store 세 가지가 있습니다.
Microsoft Store로도 설치할 수 있지만, 이 강의에서는 설치 파일을 직접 받는 길로 갑니다.

④ 앞에서 x64-based processor를 봤으면 Windows 쪽의 Download(다운로드)를, ARM-based processor를 봤으면 Windows (arm 64) 쪽의 Download를 클릭합니다.

[화면 캡처: A-5-03 — claude.com/download의 Desktop 부분. ① Windows의 Download, ② Windows (arm 64)의 Download, ③ Microsoft Store]
▲ 칩에 맞는 Download를 고르는 자리

Chrome이 설치 파일을 받아 Downloads(다운로드) 폴더에 저장하고, 주소창 오른쪽에 받은 파일 목록이 잠깐 열립니다.

⚠ 확인 필요 받은 설치 파일의 이름과 끝에 붙는 형식

⑤ 목록에서 받은 파일의 이름을 클릭해 엽니다.

목록이 닫혔으면 주소창 오른쪽의 다운로드 아이콘을 클릭해 다시 엽니다.

설치와 관리자 권한 허락

파일을 열면 설치가 시작됩니다.
설치하는 동안 Windows가 이 앱이 기기를 바꾸도록 허락할지, 곧 관리자 권한을 줄지 묻는 창이 뜹니다.

① 그 창에 적힌 프로그램 이름이 Claude인지 봅니다.

② 맞으면 허락합니다.

방금 공식 페이지에서 받은 파일이 맞는지 확인하는 자리이기 때문입니다.

⚠ 확인 필요 설치 파일을 연 뒤 나오는 창과 누를 버튼 ⚠ 확인 필요 허락을 묻는 창에 보이는 프로그램 이름과 만든 곳, 허락하는 버튼의 글자

[화면 캡처: A-5-04 — 설치 파일을 연 뒤 나오는 창. ① 누를 버튼]
▲ 설치를 시작하는 창

[화면 캡처: A-5-05 — 관리자 권한을 묻는 Windows 창. ① 프로그램 이름 Claude, ② 허락하는 버튼]
▲ 관리자 권한을 묻는 창

이 허락은 건너뛰지 않습니다.
공식 Windows 설치 안내는 관리자 권한을 허락해야 폴더 연결을 포함한 모든 기능이 설치된다고 적습니다.
허락하지 않으면 설치 프로그램이 Administrator access is required to install Claude with full features라고 알리고, 폴더를 연결하는 기능이 빠진 설치만 할 수 있습니다.

회사 PC처럼 관리자 권한을 받을 수 없게 막혀 있다면, 이 강의는 집이나 개인 PC에서 따라 하기를 권합니다.

설치한 앱 열기

① Windows 키를 누르고 claude를 입력합니다.

시작 메뉴의 검색 결과에 Claude 앱이 나옵니다.

② 검색 결과의 Claude를 클릭합니다.

시작 메뉴에서 Claude가 찾아지면 설치가 끝난 것이고, 다음부터도 앱은 이렇게 시작 메뉴에서 엽니다.

⚠ 확인 필요 설치가 끝난 뒤 앱이 스스로 열리는지

↓ 이어서 앱을 열었다면, 어느 계정으로 로그인해야 4강까지의 대화가 보일까요?

앱에 로그인하기

→ 웹에서 쓰던 메일 주소를 먼저 확인하고, 앱에 로그인해 대화가 보이는지 봅니다.

로그인하기 전에 웹의 메일 주소 확인

로그인하기 전에 한 가지를 꼭 확인합니다.
앱에는 웹과 같은 계정으로 로그인해야 합니다.
Claude는 메일 주소로 계정을 구분합니다.

2강에서 메일 주소로 가입해 두고 앱에서는 무심코 다른 주소의 Google 계정을 고르면, 앱은 처음 보는 주소로 새 계정을 열고 대화 목록은 텅 비어 있게 됩니다.
그래서 웹에서 어느 주소로 들어가 있는지 먼저 봅니다.

① Chrome의 claude.ai 탭으로 갑니다.

② 왼쪽 아래 이름의 첫 글자를 클릭해 계정 메뉴를 엽니다.

③ 메뉴에 보이는 메일 주소를 확인합니다.

④ 메뉴를 닫습니다.

⚠ 확인 필요 계정 메뉴에서 지금 로그인한 메일 주소가 보이는지와 그 자리

앱에서 로그인 방법 고르기

앱으로 돌아오면 로그인 화면이 열려 있습니다.
2강에서 웹으로 본 것처럼 Continue with Google(Google로 계속하기)과 Continue with email(이메일로 계속하기) 두 가지 길이 있습니다.
웹에서 확인한 주소가 Google 계정이면 Continue with Google을, 그 밖의 메일 주소면 Continue with email을 고릅니다.
가입할 때와 같은 길을 고르면 됩니다.

키오스크 프로젝트 폴더 만들기

→ 키오스크 프로젝트의 파일을 모을 폴더를 만들어 시작 자료를 넣고, 대화에 연결해 Claude가 파일을 저장하게 합니다.

폴더를 C 드라이브에 영어 이름으로 만드는 이유

마지막으로 키오스크 프로젝트의 파일을 모을 자리를 내 PC에 만듭니다.
4강에서 만든 "키오스크 프로젝트" 대화는 서버에 있습니다.
하지만 Add folder로 Claude가 열어 다룰 수 있는 것은 내 PC의 폴더입니다.

앞으로 받을 조사 결과, 회의록, 기획서, 시제품 파일을 처음부터 한 폴더에 모아 두어야 나중에 흩어진 파일을 찾아다니지 않습니다.
그 폴더가 C:\kiosk-project입니다.

폴더는 C: 드라이브 바로 아래에 둡니다.
경로가 짧고 누구의 PC에서나 같아서, 뒤의 강의가 이 폴더를 가리킬 때 헷갈리지 않습니다.

이름은 영어 소문자와 하이픈(-)으로 짓고, 띄어쓰기와 한글은 넣지 않습니다.
이 폴더는 Claude Code 대주제에서 GitHub에 올라가고 인터넷 주소를 가진 사이트가 됩니다.
인터넷 주소에서는 띄어쓰기가 %20으로 바뀌고 한글도 %와 숫자, 영문자가 길게 이어진 글자로 바뀌어, 주소를 읽기도 남에게 알려 주기도 어려워집니다.

처음부터 주소에 그대로 쓸 수 있는 이름을 붙여 두면 나중에 이름을 바꿀 일이 없습니다.

File Explorer에서 폴더 만들기

① 키보드의 Windows 키와 E 키를 함께 누릅니다.

File Explorer(파일 탐색기)가 열립니다.

② 왼쪽 목록에서 This PC(내 PC)를 클릭합니다.

③ 오른쪽에 보이는 드라이브 가운데 이름 끝에 (C:)가 붙은 것을 두 번 클릭합니다.

드라이브 이름의 앞부분은 PC마다 다를 수 있으므로 괄호 안의 C:로 찾습니다.

⚠ 확인 필요 Windows 11 File Explorer의 This PC 이름과 C 드라이브의 표시

① C: 드라이브 안의 빈 곳을 마우스 오른쪽 버튼으로 클릭합니다.

② 열린 메뉴에서 New(새로 만들기)를 가리킵니다.

③ Folder(폴더)를 클릭합니다.

New folder(새 폴더)라는 이름의 폴더가 생기고 이름 칸이 선택된 채로 남습니다.

④ 그대로 kiosk-project를 입력합니다.

⑤ Enter 키를 누릅니다.

회사 PC처럼 C: 드라이브에 폴더를 만들 수 없게 막혀 있다면, 이 강의는 집이나 개인 PC에서 따라 하기를 권합니다.

⚠ 확인 필요 Windows 11 File Explorer의 오른쪽 클릭 메뉴에 New와 Folder가 보이는지 ⚠ 확인 필요 일반 사용자 계정의 Windows 11에서 C 드라이브 바로 아래에 폴더를 만들 때 관리자 허락을 묻는지

폴더가 제자리에 생겼는지 경로로 확인합니다.

① File Explorer 위쪽의 주소 칸을 클릭합니다.

② C:\kiosk-project를 입력합니다.

③ Enter 키를 누릅니다.

빈 폴더가 열리면 경로가 맞습니다.

[화면 캡처: A-5-13 — File Explorer에서 연 빈 C:\kiosk-project. ① 주소 칸의 C:\kiosk-project, ② 비어 있는 폴더 안]
▲ 새로 만든 빈 폴더

시작 자료 넣기

이제 시작 자료를 넣습니다.

① 이 강의의 강의 자료에 있는 kiosk-project.md를 클릭해 다운로드합니다.

Chrome은 받은 파일을 Downloads 폴더에 저장합니다.

⚠ 확인 필요 강의 사이트에서 이 파일을 클릭하면 다운로드되는지 Chrome 안에서 글자로 열리는지, 글자로 열리면 다운로드하는 방법

② File Explorer의 왼쪽 목록에서 Downloads를 클릭합니다.

③ kiosk-project 파일을 클릭해 고릅니다.

④ Ctrl 키와 X 키를 함께 눌러 잘라 냅니다.

⑤ 주소 칸에 다시 C:\kiosk-project를 입력하고 Enter 키를 누릅니다.

⑥ Ctrl 키와 V 키를 함께 누릅니다.

잘라 낸 파일이 이 폴더로 옮겨집니다.
File Explorer는 처음 설정에서 파일 이름 끝의 .md를 보여 주지 않을 수 있어, 폴더 안에는 kiosk-project라는 이름의 파일 하나가 보입니다.

⚠ 확인 필요 Windows 11 File Explorer가 처음 설정에서 .md를 감추는지와 이 파일의 종류가 어떻게 표시되는지

[화면 캡처: A-5-14 — File Explorer에서 연 C:\kiosk-project. ① 주소 칸의 C:\kiosk-project, ② 폴더 안의 kiosk-project 파일]
▲ 시작 자료를 넣은 폴더

넣은 파일을 메모장으로 열어 보기

넣은 파일을 한 번 열어 봅니다.

① kiosk-project 파일을 마우스 오른쪽 버튼으로 클릭합니다.

② Open with(연결 프로그램)를 가리킵니다.

③ Notepad(메모장)를 클릭합니다.

메모장에 글자가 그대로 열립니다.
맨 위에 "카페 주문 키오스크 개선 프로젝트"라는 제목이 있고, 프로젝트의 목적, 처음 만들 다섯 화면(메뉴 선택, 옵션 변경, 장바구니, 결제 방식 선택, 모의 주문 완료), 아직 확인하지 않은 가설 하나, 조사에서 검증까지 만들 결과물의 차례가 적혀 있습니다.
맨 아래에는 이 파일을 C:\kiosk-project에 두고 앞으로 만드는 결과도 같은 폴더에 쌓는다고 적혀 있습니다.

읽었으면 아무것도 고치지 말고 메모장을 닫습니다.

⚠ 확인 필요 Windows 11 오른쪽 클릭 메뉴의 Open with와 Notepad 이름

[화면 캡처: A-5-15 — 메모장으로 연 kiosk-project.md. ① 맨 위 제목, ② 첫 제작 범위의 다섯 화면, ③ 교육용 가설]
▲ 메모장에서 본 시작 자료

이 파일을 Word가 아니라 메모장으로 열었다는 것을 기억해 둡니다.
kiosk-project.md는 글자만 담은 파일이라 메모장으로도, 다른 어느 프로그램으로도 그대로 열립니다.
앞으로 키오스크 프로젝트의 결과도 되도록 이런 글자 파일로 이 폴더에 모읍니다.

끝이 .md인 파일이 무엇이고 Word 문서와 무엇이 다른지는 Claude Work 대주제의 10강에서 직접 열어 비교합니다.
그리고 Claude에게 키오스크 일을 시킬 때 이 파일을 함께 주면, Claude는 지금 무슨 프로젝트를 하고 있고 어디까지 만들기로 했는지 알고 답합니다.
이 폴더를 대화에 연결해 바로 해 봅니다.

↓ 이어서 이 폴더를 대화에 연결하면 Claude는 무엇을 할 수 있을까요?

폴더를 대화에 연결하고 일 맡기기

데스크톱 앱으로 갑니다.

① 사이드바의 Recents에서 4강에서 만든 "키오스크 프로젝트" 대화를 클릭합니다.

키오스크 일은 앞으로도 이 대화에 이어 씁니다.

② 입력창의 + 버튼을 클릭합니다.

③ Add folder를 클릭합니다.

폴더를 고르는 창이 열립니다.

④ 위쪽의 주소 칸에 C:\kiosk-project를 입력하고 Enter 키를 누릅니다.

⑤ Select Folder(폴더 선택) 버튼을 클릭합니다.

Claude가 이 폴더의 파일을 고쳐도 되는지 묻는 창이 나오면 허락합니다.
입력창 둘레에 kiosk-project 폴더가 표시되면 연결된 것입니다.

⚠ 확인 필요 Add folder를 누른 뒤 열리는 창과 폴더를 고르는 버튼의 이름 ⚠ 확인 필요 폴더를 고른 뒤 묻는 창이 나오는지와 그 글자, 허락하는 버튼의 이름 ⚠ 확인 필요 연결한 폴더가 화면의 어디에 어떻게 표시되는지

[화면 캡처: A-5-16 — 폴더를 연결한 "키오스크 프로젝트" 대화. ① + 버튼, ② 연결된 kiosk-project 폴더 표시, ③ 입력창]
▲ 폴더를 연결한 대화

① 입력창에 아래 문장을 입력하고 보냅니다.

연결한 폴더에 있는 kiosk-project.md를 읽어 줘. 그 파일에 적힌 처음 만들 다섯 화면을 한 줄에 하나씩 적어서, 같은 폴더에 kiosk-screens.md라는 이름으로 저장해 줘. 폴더의 다른 파일은 고치지 마.

⚠ 확인 필요 데스크톱 앱에서 이 요청을 보내 받은 답으로 채운다(Claude가 kiosk-project.md를 읽고 C:\kiosk-project\kiosk-screens.md를 저장했다고 알리는 답과, 저장한 파일의 다섯 줄)

Claude가 파일을 저장하기 전에 허락을 묻는 창을 띄우면, 창에 적힌 파일 이름이 kiosk-screens.md이고 저장할 곳이 C:\kiosk-project인지 읽은 뒤 허락합니다.
Claude가 폴더에서 하려는 일을 어떻게 읽고 허락할지는 Claude Work 대주제의 1강에서 처음부터 익힙니다.

⚠ 확인 필요 Pro의 기본 승인 방식에서 새 파일을 저장할 때 묻는 창이 뜨는지와 그 버튼 이름

결과는 Claude의 답이 아니라 폴더에서 확인

답이 끝나면 정말 파일이 생겼는지 Claude의 답이 아니라 폴더에서 확인합니다.

① File Explorer의 주소 칸에 C:\kiosk-project를 입력하고 Enter 키를 누릅니다.

폴더 안에 kiosk-project와 함께 kiosk-screens가 보입니다.

② kiosk-screens를 마우스 오른쪽 버튼으로 클릭합니다.

③ Open with에서 Notepad를 클릭해 엽니다.

다섯 줄이 메모장에서 본 kiosk-project.md의 다섯 화면(메뉴 선택, 옵션 변경, 장바구니, 결제 방식 선택, 모의 주문 완료)과 같은지 하나씩 대조합니다.
빠지거나 바뀐 화면이 있으면 같은 대화에 그 화면을 짚어 고쳐 달라고 보냅니다.
대조가 끝났으면 메모장을 닫습니다.

[화면 캡처: A-5-17 — File Explorer에서 연 C:\kiosk-project. ① kiosk-project, ② Claude가 저장한 kiosk-screens]
▲ Claude가 저장한 파일이 보이는 폴더

웹에서였다면 kiosk-project.md를 올리고, 답을 받아 새 파일로 다운로드하고, Downloads에서 이 폴더로 옮겨야 했던 일을 대화 하나가 폴더 안에서 끝냈습니다.
내가 한 일은 폴더를 연결하고, 요청을 보내고, 결과를 원본과 대조한 것뿐입니다.

오늘 만든 폴더의 앞날

→ 이 폴더에 앞으로 무엇이 쌓이는지 보고, 이번 강의에서 한 일을 정리합니다.

이 폴더에 쌓일 것

오늘 만든 폴더는 이 과정이 끝날 때까지 씁니다.
6강에서 휴대전화로 찍은 카페 키오스크 사진이 이 폴더로 들어오고, 7강에서는 Claude를 어떻게 썼는지 적는 AI 사용 기록 ai-log.md가 이 폴더에 생깁니다.

Claude Work 대주제에서 받는 조사 결과, 회의록, 기획서, 시제품이 차례로 쌓이고, 그 대주제의 끝에서 보고서와 포트폴리오의 재료가 됩니다.
Claude Code 대주제에서는 Code 탭이 이 폴더를 열어 Git으로 관리하고, 이 폴더가 GitHub 저장소와 사이트가 됩니다.

[이미지: A-5-18 — 장면 그림. 같은 C:\kiosk-project 폴더에 키오스크 프로젝트의 결과가 과정 내내 차곡차곡 쌓여 가는 것. 예시: 이 강의의 kiosk-project.md와 kiosk-screens.md에서 시작해, 키오스크 사진과 ai-log.md, 조사 결과와 회의록과 기획서와 시제품, 보고서와 포트폴리오, Code 탭과 Git으로의 관리, GitHub 저장소와 사이트까지 폴더가 점점 차 간다. 프롬프트: images/src/A-5-18.prompt.md]
▲ 키오스크 폴더에 결과가 쌓이는 흐름

이번 강의에서 한 일

이번 강의에서 여러분은 데스크톱 앱을 설치해 웹과 같은 계정으로 로그인하고, 웹과 앱이 서버에 있는 같은 대화를 보여 준다는 것을 직접 확인했습니다.
대화 입력창의 + 버튼에서 Add folder를 찾았고, 키오스크 프로젝트의 파일을 모을 C:\kiosk-project를 만들어 첫 파일을 넣은 뒤, 그 폴더를 대화에 연결해 Claude가 파일 하나를 저장하게 했습니다.

대화는 서버의 계정에 쌓이지만, 프로젝트의 결과물은 이 폴더에 어느 프로그램에서나 열리는 글자 파일로 쌓입니다.
그래야 대화와 Code 탭, GitHub, 사이트가 같은 파일을 그대로 다루고, 조사부터 포트폴리오까지 한 프로젝트의 결과가 한곳에 남습니다.

📌 정리 오늘 넣은 파일 하나와 Claude가 저장한 파일 하나가 키오스크 프로젝트 폴더의 출발점입니다.

→ 다음 강의 이번 강의가 PC에 만든 키오스크 폴더와 서버의 대화를 남겼습니다.
6강에서는 휴대전화 앱을 설치해 같은 계정으로 로그인하고, PC에서 연 키오스크 대화를 휴대전화에서 이어 갑니다.
그리고 카페에서 키오스크 화면을 찍어 Claude에게 묻고, 그 사진을 오늘 만든 폴더로 옮깁니다.
