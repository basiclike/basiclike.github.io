# 참고 화면: 파란돌 베이커리 카페 주문 화면 (가상의 카페)

이 파일은 잘 만든 키오스크 주문 화면의 예로 지어낸 "파란돌 베이커리 카페"의 화면 설명입니다. 실제 가게나 회사의 화면이 아닙니다. Claude Design에 이 화면을 베끼게 하지 않고, 색, 글꼴, 간격 같은 디자인 요소만 가져와 하루커피에 맞게 다시 해석하게 할 때 씁니다.

## 화면 배치 (가로 1080, 세로 1920 세로형 키오스크)

- 맨 위 120px 높이의 머리말에 왼쪽은 가게 로고, 오른쪽은 "처음으로" 버튼과 글자 크기 버튼(가, 가+)이 있습니다.
- 머리말 아래 왼쪽에 폭 200px의 세로 분류 탭(커피, 음료, 빵, 디저트)이 있고, 고른 탭은 주색 바탕에 흰 글자입니다.
- 가운데에 메뉴 카드가 3열로 놓입니다. 카드에는 위에 사진, 아래에 메뉴 이름과 가격이 있고, 품절 메뉴는 카드 전체가 흐려지고 사진 위에 "품절" 띠가 붙습니다.
- 맨 아래 160px 높이의 장바구니 막대가 늘 보입니다. 왼쪽에 담은 개수와 총액, 오른쪽에 큰 "결제하기" 버튼이 있습니다.

| 결제하기 버튼 | 주색 바탕, 흰 글자 36px, 폭 360px |

## 가져올 것과 가져오지 않을 것

- 가져올 것: 간격 규칙, 카드 모양, 늘 보이는 장바구니 막대, 버튼 크기, 품절 표시 방식.
- 가져오지 않을 것: 파란돌의 로고, 가게 이름, 주색과 강조색, 메뉴 사진. 색은 하루커피의 색(`cafe-logo-and-colors.md`)을 씁니다.
- 제목 글꼴은 유료 글꼴이라 쓸 수 없으므로, Claude에게 무료로 쓸 수 있는 비슷한 글꼴로 바꾸게 합니다.
