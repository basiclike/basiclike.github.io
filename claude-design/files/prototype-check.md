# 시제품 눌러 보기 기록표

이 파일은 3강에서 클릭되는 주문 시제품을 Play로 눌러 보며 요구사항과 대조할 때 쓰는 기록표입니다. 요구사항 ID는 Claude Work에서 기획서와 함께 만든 `kiosk-requirements.md`의 ID로 바꿔 적습니다.

## 1. 눌러 보며 생기는 메모

- 어디서 막혔는지 한 줄로 적습니다: ______________________
- 막힌 이유로 보이는 것을 한 줄로 적습니다: ______________________

## 2. 주문 흐름 눌러 보기

아래 차례대로 누르고, 요구사항대로 되면 "된다", 아니면 "안 된다"와 무엇이 달랐는지 적습니다. 금액은 1강의 하루커피 메뉴 파일(`haru-menu.md`)(아메리카노 레귤러 3,800원, 라지 4,300원, 카페라테 레귤러 4,500원, 샷 추가 500원)로 계산한 값입니다.

| 차례 | 할 일 | 볼 화면 | 요구사항 ID | 된다 / 안 된다 | 다른 점 |
|---|---|---|---|---|---|
| 1 | 커피 탭에서 아메리카노를 누른다 | 메뉴 선택 | | | |
| 2 | 라지, 차갑게, 1샷 추가를 고른다 | 옵션 변경 | | | 금액이 4,800원으로 바뀌는가 |
| 3 | 장바구니에 담는다 | 장바구니 | | | 개수 1, 총액 4,800원인가 |
| 4 | 장바구니에서 옵션을 레귤러로 고친다 | 장바구니 | | | 처음 화면으로 돌아가지 않고 고쳐지는가, 4,300원이 되는가 |
| 5 | 바닐라 라테를 누른다 | 메뉴 선택 | | | 품절이라 담기지 않는가 |
| 6 | 카드를 고른다 | 결제 방식 선택 | | | |
| 7 | 주문 완료 화면을 본다 | 모의 주문 완료 | | | 주문 번호와 주문 내용이 보이는가 |

## 3. 더할 상태

상태를 더하는 장에서 아래 상태를 더하게 한 뒤 다시 눌러 봅니다.

| 상태 | 확인할 것 | 된다 / 안 된다 |
|---|---|---|
| 옵션 바꾸기 | 옵션을 바꾸면 설명과 금액이 함께 바뀐다(아메리카노 라지, 차갑게, 1샷 추가는 4,800원) | |
| 장바구니에서 빼기 | 아메리카노(라지, 차갑게, 1샷 추가, 4,800원)에 카페라테 레귤러(4,500원)를 더 담으면 개수 2, 총액 9,300원이고, 카페라테를 빼면 개수 1, 총액 4,800원이 된다. 다 빼면 "담은 메뉴가 없습니다"가 보인다(빈 상태) | |
| 품절 | 품절 메뉴는 흐리게 보이고 눌러도 담기지 않는다 | |
| 결제 취소 | 결제 방식 화면에서 취소하면 장바구니로 돌아가고 담은 것이 남는다 | |
| 결제 오류 | 결제가 되지 않았다는 안내와 다시 고르기 버튼이 보인다(오류 상태) | |
| 결제 기다림 | 결제를 기다리는 동안 기다림 표시가 보인다(불러오는 상태) | |
