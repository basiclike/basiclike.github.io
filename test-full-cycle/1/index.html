1강. 모듈과 import

이론 강의 ⏱ 약 30분

학습 목표

  • 내가 만든 .py 파일을 모듈로 보고 다른 파일에서 불러 보기
  • import, as, from 세 꼴로 같은 함수 불러 보기
  • 꼴마다 함수를 부르는 이름 비교해 보기

💡 사용 환경 파이썬 3이 설치된 PC와 터미널(Windows는 PowerShell, macOS와 Linux는 기본 터미널)을 씁니다. 코드는 메모장이나 VS Code 같은 편집기로 .py 파일에 저장하고, 터미널에서 python 파일이름.py로 실행합니다. macOS와 Linux에서 python이 없다고 나오면 python3으로 바꿔 입력합니다.

코드를 묶는 단위

→ 남이 만든 코드는 어떤 단위로 묶여 있을까?

만들어 둔 코드를 가져다 쓰기

두 수를 더하는 함수를 하나 만들었다고 해 봅시다. 처음에는 이 함수를 쓰는 파일이 하나뿐이어서 그 파일 안에 함수를 적어 두면 됩니다. 그런데 프로그램이 커지면 계산하는 파일, 화면에 보여 주는 파일, 결과를 저장하는 파일처럼 파일이 여러 개로 나뉘고, 같은 더하기 함수가 여러 파일에서 필요해집니다.

이때 파일마다 같은 함수를 복사해 붙이면 처음에는 편해 보입니다. 하지만 함수에서 잘못된 곳을 찾아 고치려면 복사해 둔 파일을 모두 찾아 똑같이 고쳐야 하고, 한 곳이라도 빠뜨리면 파일마다 다르게 동작합니다.

그래서 함수는 한 파일에 한 번만 적어 두고, 필요한 파일에서 그 파일을 불러 씁니다. 고칠 일이 생기면 그 한 파일만 고치면 되고, 불러 쓰는 파일은 모두 고친 함수를 씁니다.

[이미지: 1-1-0 — 장면 그림. 같은 더하기 함수를 여러 파일에 복사하던 학생이 함수를 한 파일에 두고 여러 파일에서 불러 쓰는 장면] ▲ 함수를 한 파일에 두면 여러 파일이 그 함수를 불러 씁니다

이 방법은 내가 만든 코드에만 쓰는 것이 아닙니다. 파이썬을 설치하면 함께 들어오는 코드, 다른 사람이 만들어 인터넷에 올린 코드도 같은 방법으로 불러 씁니다. 여러분이 지금까지 쓴 print()처럼 파이썬에 처음부터 들어 있는 함수 밖의 기능은 대부분 이렇게 불러와서 씁니다.

함수를 다시 쓰지 않고 이미 만든 코드를 ==불러 쓰면==, 한 곳만 고쳐도 그 코드를 쓰는 모든 파일에 반영됩니다.

라이브러리, 모듈, 패키지

남이 만들어 둔 코드를 불러 쓰려면 그 코드가 어떤 단위로 묶여 있는지 알아야 합니다. 이 단위를 부르는 이름이 셋 있습니다.

이름 뜻
라이브러리 다른 사람이 만들어 둔 코드를 묶어 둔 것을 두루 부르는 이름
모듈 서로 관련 있는 함수와 변수를 모아 둔 코드의 묶음
패키지 서로 관련 있는 모듈을 모아 둔 묶음

세 이름은 모두 ==코드를 정리하는 단위==입니다. 다른 언어에서는 "라이브러리"라는 이름을 많이 쓰지만, 파이썬은 코드를 정리하는 단위를 ==모듈==과 ==패키지==라는 이름으로 나눠 부릅니다. 파이썬 문서와 오류 메시지에도 이 두 이름이 나오므로, 이 과정에서도 두 이름을 씁니다.

이 강의는 모듈을 다룹니다. 모듈을 모은 패키지는 2강에서 다룹니다.

남이 만든 코드는 라이브러리, 모듈, 패키지라는 단위로 묶여 있고, 파이썬에서는 이 단위를 ==모듈==과 ==패키지==로 나눠 부릅니다.

모듈

→ 파이썬에서 모듈은 무엇일까?

모듈은 .py 파일 하나

모듈이라는 이름이 낯설어도, 여러분은 이미 모듈을 만들어 보았습니다. 파이썬 공식 문서는 모듈을 이렇게 설명합니다.

💡 용어 정리 모듈은 파이썬의 정의(함수, 변수 등)와 문장을 담은 파일입니다. 파일 이름은 모듈 이름.py이고, 파일 이름에서 .py를 뺀 것이 모듈 이름입니다.

여러분이 함수를 적어 저장한 .py 파일 하나가 곧 모듈입니다. 모듈을 위한 특별한 문법이 따로 있지 않습니다. 같은 파일이라도 그 파일을 직접 실행하면 프로그램이고, 다른 파일에서 불러오면 모듈로 쓰입니다.

예를 들어 module3.py라는 파일에 더하기 함수 sum과 변수 message를 적어 두면, 이 파일은 module3이라는 이름의 모듈입니다. 다른 파일은 module3이라는 이름으로 이 파일을 불러와 sum과 message를 씁니다.

파이썬에서 모듈은 함수와 변수를 모아 둔 ==.py 파일 하나==이고, 파일 이름에서 .py를 뺀 것이 모듈 이름입니다.

모듈 파일 만들기

이제 모듈 파일을 직접 만들고, 그 모듈을 불러 쓸 파일을 같은 폴더에 둘 준비를 합니다.

단계: 연습할 폴더 만들기

터미널을 열고 연습할 폴더를 만든 뒤 그 폴더로 들어갑니다. 이 강의에서 만드는 파일은 모두 이 폴더에 둡니다.

mkdir import_practice
cd import_practice

단계: 모듈 파일 저장하기

편집기에서 아래 코드를 import_practice 폴더에 module3.py라는 이름으로 저장합니다. 첫 행의 주석은 파일 이름을 알려 주는 것이어서 그대로 두어도 됩니다.

# 파일: module3.py
def sum(a, b):
    return a + b


message = "module3의 변수입니다"

sum은 두 수 a와 b를 받아 더한 값을 돌려주는 함수이고, message는 글자를 담은 변수입니다. 이 파일은 직접 실행하지 않습니다. 실행해도 함수와 변수를 만들기만 해서 화면에 아무것도 나오지 않습니다.

단계: 같은 폴더에 둔다는 것 확인하기

모듈을 불러 쓸 파일은 module3.py와 같은 폴더에 만듭니다. 파이썬은 import module3을 만나면 먼저 실행한 파일이 있는 폴더에서 module3.py를 찾습니다. 다른 폴더에 둔 파일을 불러오는 방법은 2강에서 다룹니다.

이 강의를 마치면 import_practice 폴더는 아래처럼 됩니다.

import_practice/
├── module3.py
├── use_import.py
├── use_as.py
├── use_from.py
└── use_plus.py

💡 참고 모듈을 한 번 불러오고 나면 폴더에 __pycache__라는 폴더가 생깁니다. 파이썬이 모듈을 다음에 더 빨리 불러오려고 만들어 두는 것이어서 지우거나 고치지 않아도 됩니다.

파이썬에서 모듈은 함수와 변수를 적어 저장한 ==.py 파일 하나==이고, 그 모듈을 불러 쓸 파일은 ==같은 폴더==에 둡니다.

import로 모듈 불러오기

→ 모듈 안의 함수는 어떻게 부를까?

import 모듈 이름

모듈을 불러오는 가장 기본 꼴은 import 뒤에 모듈 이름을 적는 것입니다. 모듈 이름에는 .py를 붙이지 않습니다.

import 모듈 이름

이렇게 불러오면 그 파일 안에서 모듈 이름이 하나 생깁니다. 모듈 안의 함수와 변수는 ==모듈 이름 뒤에 점(.)==을 찍고 그 이름을 적어 부릅니다. "module3 안의 sum"을 module3.sum으로 적는다고 생각하면 됩니다.

단계: import로 불러오는 파일 만들기

import_practice 폴더에 아래 코드를 use_import.py로 저장합니다.

# 파일: use_import.py
import module3

print(module3.sum(1, 2))
print(module3.message)

실행하기 전에 두 print가 무엇을 보여 줄지 먼저 적어 보십시오.

단계: 실행해 결과 확인하기

터미널에서 실행합니다.

python use_import.py

3
module3의 변수입니다

module3.sum(1, 2)는 module3.py의 sum 함수에 1과 2를 넘겨 3을 돌려받았고, module3.message는 module3.py에 적은 글자를 그대로 가져왔습니다. use_import.py에는 sum이나 message를 만든 코드가 한 줄도 없지만, module3 모듈을 거쳐 둘 다 쓸 수 있습니다.

import 모듈 이름으로 불러오면 모듈 안의 함수를 ==모듈 이름.함수 이름==으로 부릅니다.

as로 짧은 이름 붙이기

모듈 이름이 길면 함수를 부를 때마다 긴 이름을 적어야 합니다. 이때 as로 모듈에 짧은 이름을 붙여 불러옵니다.

import 모듈 이름 as 줄인 이름

import module3 as mod3라고 쓰면, 이 파일에서는 module3 모듈을 mod3라는 이름으로 부릅니다. 모듈은 같고 부르는 이름만 바뀝니다.

단계: as로 불러오는 파일 만들기

아래 코드를 use_as.py로 저장합니다.

# 파일: use_as.py
import module3 as mod3

print(mod3.sum(1, 2))
print(mod3.message)

단계: 실행해 결과 확인하기

python use_as.py

3
module3의 변수입니다

결과는 use_import.py와 똑같습니다. 같은 모듈의 같은 함수를 이름만 바꿔 불렀기 때문입니다.

⚠ 주의 as로 이름을 붙이면 이 파일에서는 붙인 이름만 쓸 수 있습니다. import module3 as mod3 다음에 module3.sum(1, 2)라고 쓰면, 이 파일에는 module3이라는 이름이 없어서 NameError 오류가 납니다.

모듈 안의 함수는 import로 생긴 모듈의 이름(as를 붙이면 그 이름) 뒤에 점을 찍어 ==모듈 이름.함수 이름==으로 부릅니다.

from으로 함수만 불러오기

→ 모듈 이름 없이 함수를 부르려면 어떻게 할까?

from 모듈 import 함수

함수 하나를 여러 번 쓰는데 그때마다 module3.을 앞에 붙이기 번거롭다면, 모듈에서 그 함수만 꺼내 올 수 있습니다.

from 모듈 이름 import 함수 이름

"module3에서(from) sum을 불러온다(import)"라고 읽습니다. 이렇게 불러오면 이 파일에 sum이라는 이름이 바로 생겨서, 모듈 이름 없이 함수 이름만으로 부릅니다.

단계: from으로 불러오는 파일 만들기

아래 코드를 use_from.py로 저장합니다.

# 파일: use_from.py
from module3 import sum

print(sum(1, 2))

단계: 실행해 결과 확인하기

python use_from.py

3

module3.을 붙이지 않고 sum(1, 2)만 적었는데도 module3.py의 sum이 불렸습니다. 이 꼴로는 적은 함수만 불러오므로, 이 파일에서 message를 쓰려면 from module3 import sum, message처럼 쉼표로 이어 함께 불러와야 합니다.

⚠ 주의 파이썬에는 리스트 같은 묶음의 합을 구하는 sum이라는 함수가 처음부터 들어 있습니다. from module3 import sum으로 불러오면 이 파일의 sum은 module3의 sum으로 바뀌어, 파이썬에 들어 있던 sum은 가려집니다.

from 모듈 이름 import 함수 이름으로 불러오면 모듈 이름 없이 ==함수 이름만으로== 부릅니다.

함수에 다른 이름 붙이기

함수를 꺼내 올 때도 as로 다른 이름을 붙일 수 있습니다. 함수 이름이 이미 쓰는 이름과 겹칠 때 쓰기 좋습니다.

from 모듈 이름 import 함수 이름 as 새 이름

from module3 import sum as plus라고 쓰면 module3의 sum을 이 파일에서는 plus라는 이름으로 부릅니다. sum이라는 이름은 이 파일에 새로 생기지 않으므로, 파이썬에 들어 있던 sum도 그대로 쓸 수 있습니다.

단계: 함수에 이름을 붙여 불러오는 파일 만들기

아래 코드를 use_plus.py로 저장합니다. 둘째 print의 sum은 module3의 것이 아니라 파이썬에 들어 있는 sum입니다.

# 파일: use_plus.py
from module3 import sum as plus

print(plus(1, 2))
print(sum([1, 2, 3]))

실행하기 전에 둘째 줄의 결과를 먼저 생각해 보십시오. [1, 2, 3]은 세 수를 담은 리스트입니다.

단계: 실행해 결과 확인하기

python use_plus.py

3
6

plus(1, 2)는 module3의 더하기 함수여서 3이 나왔고, sum([1, 2, 3])은 파이썬에 들어 있는 sum이 리스트의 세 수를 더해 6이 나왔습니다. 함수에 다른 이름을 붙였기 때문에 두 sum이 한 파일에서 부딪히지 않았습니다.

from 모듈 이름 import 함수 이름 as 새 이름으로 불러오면 그 함수를 ==새 이름==으로 부르고, 원래 이름은 이 파일에 생기지 않습니다.

세 꼴 나란히 보기

지금까지 같은 module3.py의 같은 sum 함수를 네 파일에서 불러왔습니다. 불러온 함수는 모두 같고, 달라진 것은 코드에서 그 함수를 ==부르는 이름==뿐입니다.

불러오는 코드 함수를 부르는 코드 이 파일에 생기는 이름
import module3 module3.sum(1, 2) module3
import module3 as mod3 mod3.sum(1, 2) mod3
from module3 import sum sum(1, 2) sum
from module3 import sum as plus plus(1, 2) plus

표를 읽는 방법은 하나입니다. import 뒤(또는 as 뒤)에 적은 이름이 이 파일에 생기고, 그 이름으로 부릅니다.

  • import로 모듈을 불러오면 모듈의 이름이 생기므로, 함수는 점을 찍어 모듈 이름 뒤에 붙여 부릅니다.
  • from ... import로 함수를 불러오면 함수의 이름이 생기므로, 모듈 이름 없이 부릅니다.
  • as를 붙이면 원래 이름 대신 as 뒤의 이름이 생깁니다.

어느 꼴을 쓸지는 읽기 쉬운 쪽으로 고릅니다. 모듈의 함수를 여러 개 쓰면 import로 모듈을 불러와 module3.sum처럼 어느 모듈의 함수인지 드러나게 쓰고, 함수 하나만 자주 쓰면 from으로 그 함수만 꺼내 씁니다.

모듈 이름 없이 함수를 부르려면 ==from 모듈 이름 import 함수 이름==으로 함수만 불러오고, 이름이 겹치면 as로 새 이름을 붙여 부릅니다.

📌 정리 모듈은 함수와 변수를 모아 둔 .py 파일 하나이고, 파일 이름에서 .py를 뺀 것이 모듈 이름입니다. import 모듈로 불러오면 모듈.함수로, import 모듈 as 줄인 이름으로 불러오면 줄인 이름.함수로, from 모듈 import 함수로 불러오면 함수로 부릅니다. import 문에 적은 모듈 이름은 같은 폴더의 .py 파일을 가리킵니다.

❓ 질문 from module3 import sum 다음 줄에서 module3.sum(1, 2)라고 쓰면 어떻게 될까요? 이 파일에 어떤 이름이 생겼는지 표에서 찾아보십시오.

→ 다음 강의 모듈 파일이 많아지면 폴더에 나눠 담습니다. 2강에서는 모듈을 담은 폴더인 패키지를 만들고, 폴더 안의 모듈을 점으로 이은 경로로 불러옵니다.
