6. 딥러닝 기초

소주제 2개 · 강의 7편

콘솔, 터미널, 셸이 각각 무엇을 맡는지 구분하고 내 컴퓨터의 화면에서 셋을 가려낼 수 있습니다. 파이썬의 모듈과 패키지를 구분하고, 직접 만든 패키지를 여러 import 문으로 불러올 수 있습니다.

→ 여기서 시작하세요: 파이썬 3이 설치된 Windows, macOS, Linux 컴퓨터가 있으면 됩니다. 파이썬 문법은 함수를 정의하고 부를 수 있을 만큼 알고 오면 됩니다.

A콘솔, 터미널, 셸

명령이 사용자에게서 커널까지 가는 흐름에서 콘솔, 터미널, 셸이 맡는 몫을 구분합니다.

  1. 1강 세 이름의 관계콘솔, 터미널, 셸이 왜 섞여 불리는지 흐름으로 설명합니다. 공개 약 20분
  2. 2강 콘솔과 터미널콘솔과 터미널이 각각 무엇인지 과거와 지금으로 구분합니다. 비밀번호 약 30분
  3. 3강 명령을 읽는 셸셸이 무엇을 하는지 알고 터미널과 구분합니다. 비밀번호 약 30분
  4. 4강 내 화면에서 구분하기내 컴퓨터에서 터미널과 셸을 직접 확인합니다. 비밀번호 약 20분

B모듈과 패키지

모듈과 패키지를 구분하고, 직접 만든 패키지를 import 문으로 불러옵니다.

  1. 5강 모듈과 패키지모듈, 패키지, 라이브러리가 각각 무엇인지 구분합니다. 비밀번호 약 30분
  2. 6강 import 문 쓰기모듈과 패키지를 불러오는 import 문의 꼴을 골라 씁니다. 비밀번호 약 30분
  3. 7강 패키지 만들어 불러오기패키지 폴더를 직접 만들고 import 문으로 불러 실행합니다. 비밀번호 약 40분
