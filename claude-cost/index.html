4. Claude 비용의 구조와 줄이는 법

소주제 3개 · 강의 7편

Claude를 책상 앞에서 종이를 읽고 답하는 사람으로 보고, 대답할 때마다 책상 위 종이를 모두 다시 읽어 장 수만큼 돈과 시간이 든다는 것을 알아봅니다. 사용량이 생각보다 빨리 닳는 이유와 덜 쓰는 방법을 이 사람이 일하는 모습 하나로 풀고, 마지막에는 내 책상과 근무 한도를 화면에서 직접 보는 법까지 따라갑니다.

→ 여기서 시작하세요: Claude 시작하기 과정을 마친 뒤 1강부터 차례로 읽으면 됩니다. 7강은 Claude 데스크톱 앱의 Code 탭에서 따라 하므로, Pro 요금제와 Code 탭을 쓰는 Windows PC가 있으면 됩니다.

A사람처럼 일하는 도구

Claude를 100장 책상 앞의 사람으로 보고, 대답마다 다시 읽는 종이와 한 번 읽은 종이를 기억하는 구조를 알아봅니다.

  1. 1강 책상에서 답하는 사람대답마다 책상 위 종이를 다시 읽어 장 수만큼 값이 드는 구조를 알아봅니다. 공개 약 20분
  2. 2강 읽은 종이는 기억한다한 번 읽은 종이를 기억해 값이 줄어드는 구조와 그 한계를 알아봅니다. 비밀번호 약 20분

B종이를 다른 책상으로

종이가 쌓일 때 다른 사람에게 넘기거나 요약본으로 바꿔 끼우는 법과, 그때 남는 것과 잊히는 것을 알아봅니다.

  1. 3강 다른 책상에 넘기기새 세션, subagent, fork에 일을 넘길 때 내 책상에 남는 것을 알아봅니다. 비밀번호 약 25분
  2. 4강 100장에 가까울 때압축과 /clear로 책상을 비울 때 남는 것과 잊히는 것을 알아봅니다. 비밀번호 약 25분

C계약, 시급, 시간

구독과 API, 모델과 effort를 계약과 시급과 작업 시간으로 보고, 내 책상과 근무 한도를 화면에서 보는 법까지 따라갑니다.

  1. 5강 고용 방식과 근무 한도구독과 API를 월급제와 시급제로 보고, 근무 한도 두 가지를 알아봅니다. 비밀번호 약 20분
  2. 6강 시급과 작업 시간모델은 시급, effort는 작업 시간으로 보고 일에 맞게 고르는 법을 알아봅니다. 비밀번호 약 25분
  3. 7강 책상과 근무 한도 보기/context와 Usage 화면으로 내 책상과 근무 한도를 보는 법을 따라갑니다. 비밀번호 약 30분
