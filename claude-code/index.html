6. Claude Code

소주제 8개 · 강의 32편

Claude Code를 데스크톱 앱, 터미널, VS Code에서 써 보며, 대화와 달리 내 PC의 파일을 고치고 명령을 실행하는 틀이 어떻게 일하는지 알아봅니다. Claude Code에게 Git을 시키면서 승인 화면의 명령을 읽어 커밋, 비교, 되돌리기, 브랜치의 뜻을 함께 익히고, 키오스크 프로젝트를 GitHub로 함께 쓰고 GitHub Pages로 공개해 봅니다. 되풀이하는 일은 Skill과 CLAUDE.md로 남기고, 캐시를 지켜 같은 사용량으로 더 오래 일하는 법까지 알아봅니다.

→ 여기서 시작하세요: Claude로 디자인하기를 마친 뒤 1강부터 차례로 따라 하면 됩니다. Pro 요금제와 Claude 데스크톱 앱이 깔린 Windows PC가 있어야 하고, 셸과 Git은 처음이어도 괜찮습니다.
