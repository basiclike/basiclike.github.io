9. Python

소주제 6개 · 강의 26편

Claude가 만들어 준 코드를 읽고 고칠 수 있도록, 내 컴퓨터에 Python이 실행될 환경을 만들고 기초 문법을 직접 짜 봅니다. 문제를 순서도로 이해하고 분석, 설계, 구현의 차례로 풀어 작은 키오스크를 내 손으로 다시 만들고, Claude Code가 고친 코드를 내 코드와 비교해 판단해 봅니다. 끝으로 만든 프로그램이 팀원의 컴퓨터에서도 같은 환경으로 실행되게 넘겨 봅니다.

→ 여기서 시작하세요: Claude Code 과정을 마친 뒤 1강부터 차례로 따라 하면 됩니다. Windows 11 PC와 Claude 유료 요금제 계정이 필요하고, 앞 과정의 결과물이 없으면 강의 자료로 시작합니다.

A첫 코드 실행하기

Claude가 만든 코드를 직접 짜 보는 이유와 환경이 필요한 이유를 알아보고, Python과 VS Code를 갖춰 첫 코드를 실행하고 오류를 읽어 봅니다.

  1. 1강 직접 짜 보는 이유Claude가 만든 코드를 읽을 줄 알아야 하는 이유를 알아봅니다. 공개 약 20분
  2. 2강 환경이 필요한 이유같은 코드가 어떤 PC에서는 멈추는 이유를 알아봅니다. 비밀번호 약 35분
  3. 3강 설치와 첫 실행Python을 설치하고 터미널에서 첫 코드를 실행해 봅니다. 비밀번호 약 40분
  4. 4강 가상환경 만들기프로젝트 폴더에 가상환경을 만들고 켜기 전후의 경로를 비교해 봅니다. 비밀번호 약 30분
  5. 5강 VS Code와 연결VS Code에 가상환경을 연결해 코드를 쓰고 실행해 봅니다. 비밀번호 약 45분
  6. 6강 오류 읽기와 묻기오류 메시지를 읽고 Plan 모드로 원인을 물어 직접 고쳐 봅니다. 비밀번호 약 45분

B데이터 다루기

프로그램을 데이터와 로직으로 보고 변수, 입력과 출력, 숫자, 문자열을 짜 본 뒤, 순서도로 순차 흐름을 읽어 봅니다.

  1. 7강 변수와 데이터프로그램을 데이터와 로직으로 보고 메뉴를 변수에 담아 봅니다. 비밀번호 약 35분
  2. 8강 입력과 출력input이 돌려주는 값을 확인하고 f-string으로 출력을 만들어 봅니다. 비밀번호 약 35분
  3. 9강 숫자와 연산자나눗셈 세 가지의 결과를 예측하고 실행해 맞춰 봅니다. 비밀번호 약 35분
  4. 10강 문자열과 인덱싱글자를 0부터 센 번호로 꺼내고 잘라 써 봅니다. 비밀번호 약 35분
  5. 11강 순서도와 순차주문 순서도를 읽고 순차 문제를 순서도에서 코드로 옮겨 봅니다. 비밀번호 약 55분
