9. Python

소주제 5개 · 강의 25편

코드가 실행되려면 코드에 맞는 환경이 함께 있어야 한다는 것에서 출발해, 내 컴퓨터에 개발 환경을 만들고 VS Code에서 기초 문법을 직접 짜 봅니다. 문제를 순서도로 이해하고 분석, 설계, 구현의 차례로 풀어 작은 키오스크 프로그램을 만들고, Claude Code에 묻고 검토받으며 기능을 하나 더해 봅니다.

→ 여기서 시작하세요: 1강부터 차례로 따라오면 됩니다. Windows 11 PC 한 대와 Claude 유료 요금제 계정이 필요하고, 프로그래밍이 처음이어도 괜찮습니다.

A개발 환경 만들기

같은 코드가 어떤 컴퓨터에서는 돌고 어떤 컴퓨터에서는 멈추는 이유를 알아보고, 프로젝트마다 가상환경을 만들어 패키지 목록을 파일로 옮겨 봅니다.

  1. 1강 환경이 필요한 이유같은 코드가 어떤 PC에서는 멈추는 이유를 알아봅니다. 공개 약 35분
  2. 2강 설치와 PATHPython을 설치하고 python이 어느 파일을 실행하는지 따라갑니다. 비밀번호 약 30분
  3. 3강 가상환경 만들기프로젝트 폴더에 가상환경을 만들고 켜고 끄며 경로를 봅니다. 비밀번호 약 30분
  4. 4강 패키지 설치가상환경에 패키지를 설치하고 그 안에만 있는지 확인합니다. 비밀번호 약 35분
  5. 5강 환경 공유하기패키지 목록을 파일로 남기고 새 폴더에서 같은 환경을 만듭니다. 비밀번호 약 40분

BVS Code로 개발

VS Code에 Python 확장과 가상환경을 연결해 코드를 쓰고 실행하고, Claude Code에 Plan 모드로 줄을 물어보고, 디버거로 값이 바뀌는 순서를 따라가 봅니다.

  1. 6강 VS Code 설치VS Code를 설치하고 Python 확장으로 오타 표시를 켭니다. 비밀번호 약 30분
  2. 7강 가상환경 연결VS Code가 쓸 Python을 정해 상태 표시줄로 확인합니다. 비밀번호 약 30분
  3. 8강 Claude CodeClaude Code와 순서도 Skill을 설치하고 Plan 모드로 물어봅니다. 비밀번호 약 45분
  4. 9강 디버거로 값 따라가기중단점에서 멈춰 반복마다 바뀌는 값을 따라가며 버그를 찾습니다. 비밀번호 약 40분

C기초 문법

변수, 입력과 출력, 연산, 문자열, 조건문, 반복문, 리스트, 함수, 클래스를 직접 짜 보며 프로그램을 데이터와 로직으로 만드는 기초를 익힙니다.

  1. 10강 변수와 데이터프로그램을 데이터와 로직으로 보고 변수에 값이 남는 모습을 예측합니다. 비밀번호 약 40분
  2. 11강 입력과 출력input이 돌려주는 값의 종류를 보고 f-string으로 출력을 만듭니다. 비밀번호 약 40분
  3. 12강 숫자와 연산자정수와 실수, 나눗셈 세 가지를 결과를 예측하며 구분합니다. 비밀번호 약 40분
  4. 13강 문자열과 인덱싱글자를 0부터 센 번호로 꺼내고 슬라이싱의 끝 번호가 빠지는 것을 확인합니다. 비밀번호 약 40분
  5. 14강 조건문참과 거짓으로 갈리는 조건과 elif 조건의 차례를 확인합니다. 비밀번호 약 45분
  6. 15강 반복문while과 for로 같은 일을 되풀이하고 range의 끝이 빠지는 이유를 봅니다. 비밀번호 약 45분
  7. 16강 리스트여러 값을 한 이름에 담고 대입한 리스트가 함께 바뀌는 이유를 알아봅니다. 비밀번호 약 45분
  8. 17강 함수코드를 이름 붙인 묶음으로 만들고 return과 print의 차이를 알아봅니다. 비밀번호 약 45분
  9. 18강 클래스데이터와 함수를 묶은 클래스로 객체가 값을 따로 가지는 것을 봅니다. 비밀번호 약 45분

  3. 21강 반복 흐름 문제되돌아가는 화살표를 보며 합계와 약수를 반복문으로 구합니다. 비밀번호 약 45분
