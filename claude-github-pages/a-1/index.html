A-1강. Code 탭에서 Claude에게 파일 만들게 하기

A. Code 탭으로 Claude에게 일 시키기 구현 중심 ⏱ 약 40분

학습 목표

이 강의를 마치면 할 수 있게 되는 일입니다.

  • Code 탭에서 학습 기록 폴더를 열고, Claude가 만들 파일을 승인 화면에서 읽은 뒤 승인할 수 있습니다.
  • 승인 화면에서 파일을 지우는 명령을 알아보고 거절할 수 있습니다.
  • Claude가 만든 파일을 메모장으로 열어 승인 화면에서 읽은 내용과 비교할 수 있습니다.

시작하기 전에

→ 시작 자료를 풀어 이번 강의에서 쓸 학습 기록 폴더를 준비합니다.

이번 강의에서 할 일

제공된 시작 자료를 C:\study-notes에 풀고 Claude 데스크톱 앱을 엽니다.

이번 강의에서는 이 폴더를 Code 탭에서 열고, 폴더 안내 파일 README.md를 Claude에게 만들게 합니다. 이 폴더는 B 소주제에서 GitHub에 올리고, C 소주제에서 사이트로 만듭니다.

💡 사용 환경

항목 값
Claude 데스크톱 앱 Code 탭, Environment Local, 권한 모드 Manual
요금제 Claude Pro
작업 폴더 C:\study-notes
확인용 편집기 메모장

탐색기 주소 칸에 C:\study-notes를 입력해 파일 아홉 개가 보이면 됩니다. 이 탐색기 창은 강의 끝까지 열어 둡니다.

Code 탭과 승인 화면

→ 이 대주제가 Code 탭을 쓰는 이유와 승인 화면이 하는 일을 알아봅니다.

Code 탭을 쓰는 이유

Code 탭은 Claude 데스크톱 앱 안의 Claude Code입니다. 채팅과 달리 내 PC 폴더의 파일을 직접 만들고 명령도 실행합니다. B 소주제의 Git도 내 PC 폴더에서 실행해야 하므로 이 대주제는 Code 탭을 씁니다.

승인 화면이 하는 일

Code 탭은 파일을 만들거나 명령을 실행하기 전에 승인 화면으로 묻습니다. 승인 화면을 읽지 않고 승인하면 원하지 않는 변경도 그대로 실행되므로, 이 강의에서는 승인 화면을 읽는 법을 연습합니다.

폴더 열기

→ Code 탭에서 새 세션을 열고 학습 기록 폴더를 고릅니다.

Code 탭에서 새 세션 열기

[화면 캡처: img_04 — Claude 데스크톱 앱 왼쪽 위. ① </> 아이콘, ② 사이드바의 New] ▲ Code 탭과 새 세션

① </> 아이콘을 클릭해 Code 탭으로 갑니다.

② New를 클릭합니다.

첫 요청 전에 고르는 세 가지

[화면 캡처: img_05 — 첫 요청을 보내기 전의 입력창. ① Local 칩, ② 폴더 칩 study-notes, ③ 권한 모드 Manual] ▲ 첫 요청 전에 고르는 세 가지

① 첫째 칩을 Local로 고릅니다.

② 둘째 칩을 클릭하고 C:\study-notes 폴더를 고릅니다.

③ 권한 모드를 클릭하고 Manual을 고릅니다.

Manual은 Claude가 일하기 전에 매번 묻는 모드입니다. 새 세션의 기본값 Auto는 묻지 않고 진행하므로, 새 세션을 열 때마다 첫 요청 전에 Manual로 바꿉니다.

파일 만들게 하기

→ Claude에게 README.md를 만들게 하고, 승인 화면을 읽은 뒤 승인합니다.

README.md를 만드는 요청 보내기

README.md는 폴더를 처음 여는 사람이 먼저 읽는 설명 파일입니다. 아래 요청을 입력창에 붙여 넣고 Enter 키를 누릅니다.

이 폴더의 파일 목록을 읽고, 파일마다 무엇이 들었는지 한 줄씩 적은 README.md를 만들어 줘. 맨 위 줄은 # 학습 기록.
워드 파일(.docx)이 있으면 열지 말고, 이름이 같은 .md 파일을 워드 문서로 만든 것이라고만 적어 줘.

승인 화면을 읽고 승인하기

[화면 캡처: img_06 — README.md를 만드는 승인 화면. ① 경로, ② 맨 위 줄, ③ 파일 이름 줄, ④ Allow once] ▲ 파일을 만들기 전에 보이는 승인 화면

① 경로가 C:\study-notes\README.md인지 봅니다.

② 맨 위 줄이 # 학습 기록인지 봅니다.

③ 적힌 파일 이름이 탐색기 목록과 같은지 비교합니다.

④ 모두 맞으면 Allow once를 클릭합니다.

승인과 거절을 가르는 기준

파일 승인 화면보다 명령 승인 화면이 먼저 나올 수 있습니다. 두 승인 화면 모두 아래 표로 판단합니다.

승인 화면 승인 거절
파일 승인 Allow Claude to write …? 경로, 맨 위 줄, 파일 이름이 모두 맞을 때 하나라도 다를 때. 거절한 뒤 다른 점을 한 줄로 보냅니다
명령 승인 Allow Claude to run …? 파일 목록이나 내용을 보는 명령일 때 명령 줄에 지우기, 옮기기, 이름 바꾸기 낱말(rm, del, Remove-Item, DeleteFile, mv, move, Move-Item, ren, Rename-Item)이 있거나, 무슨 명령인지 모를 때

Always allow와 Allow and switch to Auto는 고르지 않습니다. 고르면 그다음부터 묻지 않습니다.

메모장으로 확인하기

→ Claude가 만든 README.md를 메모장으로 열어 승인 화면에서 읽은 내용과 비교합니다.

메모장으로 열기

[화면 캡처: img_07 — 탐색기에서 README.md를 오른쪽 클릭해 Open with > Notepad가 보이는 메뉴] ▲ README.md를 메모장으로 열기

① 탐색기에서 F5 키를 눌러 README.md가 생겼는지 봅니다.

② README.md를 오른쪽 클릭하고 Open with > Notepad를 클릭합니다.

승인 화면에서 읽은 내용과 비교하기

[화면 캡처: img_08 — 메모장으로 연 README.md. ① 맨 위 줄, ② 파일 이름 줄] ▲ 메모장으로 연 README.md

① 맨 위 줄이 # 학습 기록인지 봅니다.

② 파일 이름 줄이 승인 화면에서 읽은 것과 같은지 봅니다.

설명이 틀린 줄이 있으면 Claude에게 그 줄만 고치게 하고, 승인 화면에서 그 줄 하나만 바뀌는지 본 뒤 승인합니다.

승인 화면에서 거절하기

→ 파일을 지우는 요청을 보내고, 승인 화면에서 거절합니다.

파일을 지우는 요청 보내기

아래 요청을 보냅니다. Claude가 정말 지울지 되물으면 응, 지워 줘.라고 보냅니다.

README.md를 지워 줘.

지우는 명령 거절하기

[화면 캡처: img_09 — README.md를 지우는 명령 승인 화면. ① 제목 줄, ② 명령 줄, ③ Deny] ▲ 파일을 지우는 명령의 승인 화면

① 제목 줄에서 지우기를 뜻하는 낱말(Delete, Remove, Recycle Bin)을 찾습니다.

② 명령 줄에 README.md와 지우기 낱말이 함께 있는지 봅니다.

③ Deny를 클릭합니다.

Claude가 어떻게 할지 물으면 지우지 말고 그대로 둬.라고 보냅니다. 탐색기에서 F5 키를 누르고 README.md가 그대로 있으면 됩니다.

혼자 해 보기

→ README.md 맨 아래에 만든 날짜 한 줄을 추가하는 요청을 내 말로 씁니다.

만든 날짜 한 줄 추가하기

추가할 줄은 만든 날짜: 와 오늘 날짜(예: 2026-10-07)입니다. 승인 화면에서 맨 아래 한 줄만 추가되는지 보고 승인한 뒤, 메모장에서 README.md를 다시 열어 확인합니다.

막혔을 때

→ 이 강의에서 자주 막히는 자리와 해결 방법입니다.

증상과 해결

증상 해결
C:\에 study-notes 폴더가 이미 있다 있던 폴더의 이름을 study-notes-old로 바꾸고 다시 풉니다
Code 탭을 클릭하면 요금제를 올리라는 안내가 나온다 Code 탭은 Pro 이상 요금제에서 씁니다. Pro 요금제 계정으로 로그인합니다
승인 화면 없이 파일이 생긴다 권한 모드가 Manual이 아닙니다. New로 새 세션을 열고 첫 요청 전에 Manual을 고릅니다
승인했는데 탐색기에 README.md가 없다 세션 폴더가 C:\study-notes가 아닙니다. 새 세션을 열고 폴더 칩에서 C:\study-notes를 다시 고릅니다
지우기를 실수로 승인했다 파일 만들게 하기의 요청을 다시 보내 README.md를 새로 만들게 합니다

✔ 정리 C:\study-notes에 README.md를 만들었고, 지우기 명령은 거절해 파일이 그대로 남았습니다.
