2. Claude로 GitHub Pages 학습 노트 만들기

소주제 4개 · 강의 11편

ACode 탭으로 Claude에게 일 시키기

Code 탭으로 연 C:\study-notes와 Claude가 만든 README.md

  1. A-1 Code 탭에서 Claude에게 파일 만들게 하기Code 탭에서 학습 기록 폴더를 열고, Claude가 만들 파일을 승인 화면에서 읽은 뒤 승인할 수 있습니다. 공개 약 40분

BGit과 GitHub 시작하기

GitHub 계정, Git이 설치된 PC, GitHub에 올라간 study-notes 저장소와 커밋 기록

  1. B-1 GitHub 가입하고 Git 설치하기GitHub 계정을 만들고 Git과 GitHub CLI를 설치한 뒤, 이 PC에서 GitHub CLI로 로그인하고 Claude에게 로그인 상태를 확인시킬 수 있습니다. 비밀번호 약 60분
  2. B-2 학습 기록 폴더를 Git 저장소로 만들기Claude에게 시켜 학습 기록 폴더를 Git 저장소로 만들고 지금 파일 전부를 첫 커밋으로 남긴 뒤, 커밋 메시지, 커밋한 파일 수, 숨겨진 기록 폴더로 확인할 수 있습니다. 비밀번호 약 45분
  3. B-3 GitHub에 학습 기록 올리기Claude에게 시켜 GitHub에 공개 저장소를 만들어 PC의 저장소를 올린 뒤, GitHub 화면의 파일 목록, README, 커밋 메시지, 공개 표시가 PC와 같은지 확인할 수 있습니다. 비밀번호 약 40분
  4. B-4 노트를 고쳐 다시 올리기노트를 고쳐 다시 올리고, push가 거부되면 오류 문장을 그대로 붙인 질문으로 Claude에게 원인과 해결을 물은 뒤, 제안된 명령을 거부 메시지와 대조해 승인하거나 거절할 수 있습니다. 비밀번호 약 60분

CGitHub Pages로 사이트 만들기

https://<사용자 이름>.github.io/study-notes/에서 열리는 학습 노트 사이트

  1. C-1 GitHub Pages로 사이트 열기GitHub Pages를 켜서 저장소의 마크다운 파일을 내 주소에서 열리는 사이트 첫 화면으로 게시할 수 있습니다. 비밀번호 약 40분
  2. C-2 첫 화면에 노트 링크 걸기학습 기록 노트를 사이트 첫 화면의 링크로 이어 사이트 안에서 노트 페이지를 열 수 있습니다. 비밀번호 약 30분
  3. C-3 사이트 제목과 테마 바꾸기설정 파일 하나로 사이트 제목과 GitHub Pages 지원 테마를 바꿀 수 있습니다. 비밀번호 약 45분
  4. C-4 새 노트 혼자 올리기새 주제의 마크다운 노트를 강의 단계 없이 써서 GitHub에 올리고 사이트 첫 화면에서 열리게 할 수 있습니다. 비밀번호 약 40분

D(추가) 사이트를 블로그로 바꾸기

카테고리·글 목록·검색이 있고 강의 자료 글이 강의 모양 그대로 보이는 블로그 모양 학습 노트 사이트

  1. D-1 블로그 템플릿 적용하기제공된 블로그 템플릿을 학습 기록 폴더에 넣고 노트를 블로그 글로 옮겨, 카테고리 사이드바와 글 카드가 있는 블로그 사이트를 만들 수 있습니다. 비밀번호 약 50분
  2. D-2 강의 자료 HTML을 블로그 글로 올리기강의 자료 HTML 파일을 블로그 글로 올려, 사이트에서 강의와 같은 배지, 번호 제목, 접히는 더보기, 코드 상자로 볼 수 있습니다. 비밀번호 약 40분

강의 안내

Claude로 GitHub Pages 학습 노트 만들기
이 대주제를 마치면 Claude에게 시켜 학습 기록 폴더를 GitHub에 올리고, 공부한 내용을 내 주소(https://<사용자 이름>.github.io/study-notes/)에서 열리는 학습 노트 사이트로 보여 줄 수 있습니다.

Claude 데스크톱 앱의 Code 탭으로 내 학습 기록 폴더에서 Claude에게 일을 시키는 것부터 시작합니다. GitHub에 가입해 한 번 로그인한 뒤 같은 방법으로 Claude에게 저장소를 만들고 올리게 하고, GitHub Pages로 사이트를 만듭니다. Git 명령은 직접 입력하지 않고 Claude가 실행하려는 명령을 읽고 승인합니다. 마지막 추가 강의에서 제공된 블로그 템플릿으로 사이트를 카테고리와 글 목록이 있는 블로그로 바꾸고, 강의 자료를 강의와 같은 모양의 글로 올립니다.
