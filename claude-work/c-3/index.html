12강. Obsidian으로 기록 폴더 만들기

환경 설정 강의 ⏱ 약 40분

학습 목표

11강까지 메모장으로 마크다운 파일을 열고 고쳐 보았습니다.
이번 강의에서는 그 파일들이 쌓인 키오스크 폴더를 한 화면에서 볼 프로그램을 설치하고, 앞으로의 기록을 담을 노트 두 개를 만듭니다.

  • 메모장으로도 충분했던 일을 왜 폴더째로 보고 싶어지는지 알아봅시다.
  • Obsidian으로 만드는 노트가 왜 다른 프로그램에서도 그대로 열리는지 확인해 봅시다.
  • 파일 탐색기와 나란히 놓고 보면, 폴더를 Obsidian으로 열었을 때 무엇이 보이고 무엇이 보이지 않는지 알아봅시다.
  • 설정 하나를 켜 두면 나중에 노트의 링크가 어떻게 되는지 알아봅시다.
  • 포트폴리오가 될 기록에는 무엇을 남기고 무엇을 적지 않아야 할까요?

폴더째로 보고 싶어지는 이유

→ 메모장으로 충분했던 일이 파일이 쌓이면서 왜 불편해지는지, 그 불편을 Obsidian이 어떻게 덜어 주는지 알아봅니다.

파일을 하나씩 여는 불편

❓ 질문
10강에서 보고서의 원본은 마크다운 파일로 정했습니다.
이 파일을 더 보기 좋게, 폴더째로 볼 방법은 없을까요?

메모장으로 지금까지 충분히 해 왔습니다.
10강에서 마크다운 파일을 열어 기호까지 글자로 읽었고, 11강에서는 줄글 메모를 기호와 빈 줄로 고쳐 서식 보기로 확인했습니다.
그런데 키오스크 폴더에는 파일이 꽤 쌓였습니다.

C:\kiosk-project에는 이제 마크다운 파일만 해도 조사 요약, 사실 정리, 용어 노트, 고친 메모가 있습니다.
Word와 HWPX 파일, 받은 자료를 모아 둔 source-files 폴더도 있습니다.
메모장은 파일을 하나씩 엽니다.
용어 노트를 보다가 조사 요약을 다시 보려면 파일 탐색기로 돌아가 폴더를 찾고 파일을 골라 새로 열어야 합니다.
열 번이면 열 번 그 길을 되밟습니다.

지원자 A의 경우를 보겠습니다.
지원자 A는 석 달 동안 공부한 내용을 메모장 파일 마흔 개에 나눠 적었습니다.
면접에서 키오스크 설문을 그때 어떻게 확인했느냐는 질문을 받고 노트북을 열었지만, 그 내용이 어느 파일에 있었는지 기억나지 않았습니다.
파일을 하나씩 열다가 시간을 다 썼습니다.
기록이 없어서가 아니라, 기록이 서로 이어져 있지 않고 한눈에 보이지 않아서 생긴 일입니다.

↓ 이어서 파일을 한눈에 보고 서로 이어 주는 프로그램이 있다면 무엇이 달라질까요?

Obsidian이 해 주는 일

Obsidian은 이 불편을 덜어 주는 프로그램입니다.
저장 방식이 달라서가 아닙니다.
Obsidian으로 만드는 노트도 10강에서 메모장으로 열어 본 것과 똑같은 글자 파일입니다.
다른 점은 몇 가지 일을 한 화면에서 할 수 있다는 것입니다.

  • 폴더 목록: 폴더 전체를 왼쪽에 목록으로 펼쳐 두고, 누르는 즉시 다른 노트로 넘어갑니다.
    노트와 노트를 링크로 이어 두면 링크를 눌러 건너갈 수도 있습니다.
  • 보기 전환: 같은 노트를 기호가 보이는 화면과 기호가 적용된 화면으로 단축키 하나로 오갑니다.
  • Claude 답과 대조: 13강에서 이 폴더를 Claude 대화에 연결한 뒤, Claude가 근거로 든 노트를 Obsidian에서 바로 찾아 열어 답과 대조합니다.
  • 같은 폴더 하나: 이 폴더는 대주제 4에서 Git과 GitHub로 기록을 남기고 공개하는 폴더가 됩니다.
    노트를 쓰는 폴더와 나중에 올리는 폴더가 같은 폴더라서 옮기는 일이 없습니다.

여기에 조건이 하나 붙습니다.
편한 화면을 쓰더라도 파일이 그 프로그램에서만 열리는 상태가 되면 안 됩니다.
Obsidian의 노트는 메모장으로도, Claude로도, 다른 어느 편집기로도 그대로 열립니다.
10강에서 원본을 마크다운으로 두기로 한 이유가 이것이었고, Obsidian은 그 원칙을 깨지 않는 프로그램이라서 고릅니다.

오늘 할 일을 먼저 적어 둡니다.
Obsidian을 설치하고, 새 폴더를 만드는 대신 지금까지 쓰던 C:\kiosk-project를 그대로 Obsidian으로 엽니다.
그 폴더에 앞으로 무엇을 남길지 정한 기록 계획 노트와, 강의마다 한 일을 적는 프로젝트 일지 노트를 만듭니다.
이 두 노트가 대주제 끝까지 키오스크 프로젝트의 기록이 됩니다.

준비: Obsidian 설치

→ Obsidian을 내 컴퓨터에 설치하고, 가입이나 결제가 필요한지 확인합니다.

① 브라우저에서 obsidian.md/download를 엽니다.
② 운영체제 목록에서 Windows를 찾습니다.
③ 그 아래의 Universal을 클릭해 설치 파일을 다운로드합니다.

▲ 설치 프로그램이 진행되는 화면

설치가 끝나면 시작 메뉴에서 Obsidian을 찾아 다른 앱처럼 실행합니다.

가입도 결제도 필요 없습니다

설치하는 동안 회원 가입이나 로그인 화면은 나오지 않습니다.
Obsidian은 개인이 쓰든 업무에 쓰든 무료이고, 쓰는 데 계정이 필요 없습니다.
돈을 내는 것은 따로 고르는 항목뿐입니다.

  • Sync: 여러 기기 사이에 노트를 저절로 맞춰 줍니다.
  • Publish: 노트를 웹에 게시합니다.
  • Commercial license: 회사가 냅니다.

이 대주제에서는 셋 다 쓰지 않습니다.
노트를 다른 곳에 남기고 공개하는 일은 대주제 4에서 GitHub로 합니다.

설치가 막혔을 때

설치가 막히면 화면에 뜬 오류 문장을 그대로 복사해 Claude에게 원인을 물어봅니다.
설치 방법 자체를 Claude에게 받아 따라 하지는 않습니다.
Claude의 안내는 물을 때마다 달라지고, 화면의 버튼 이름을 짐작으로 쓸 때가 있기 때문입니다.
오류를 물을 때는 이렇게 보냅니다.

Windows 11에 Obsidian을 설치하다가 아래 오류 창이 떴어. 오류 문장은 그대로 붙여 넣을게. 원인이 무엇일 수 있는지 설명하고, 내가 화면에서 확인할 것을 순서대로 알려 줘.

(오류 창의 문장을 여기에 붙여 넣기)

키오스크 폴더를 볼트로 열기

→ 새 폴더를 만드는 대신 지금 쓰는 키오스크 폴더를 열어, Obsidian이 보여 주는 파일이 파일 탐색기와 어떻게 같고 다른지 대조해 봅니다.

폴더를 볼트로 열기

Obsidian은 노트를 모아 두는 폴더를 볼트(vault)라고 부릅니다.
새 볼트를 만드는 대신, 지금까지 결과를 모아 온 C:\kiosk-project를 그대로 볼트로 엽니다.

① Obsidian을 처음 실행하면 볼트를 만들거나 여는 화면이 나옵니다.
② Open folder as vault 오른쪽의 Open을 클릭합니다.
③ 폴더를 고르는 창이 열리면 C:\kiosk-project를 골라 확인 버튼을 클릭합니다.

⚠ 확인 필요 1.14.5를 처음 실행한 화면에 Open folder as vault와 Open 버튼이 바로 보이는지

⚠ 확인 필요 폴더 고르는 창의 확인 버튼 이름

[화면 캡처: C-3-03 — 폴더를 볼트로 열기: Obsidian을 처음 실행한 화면. ① Open folder as vault 줄의 Open 버튼, ② Create new vault 줄]
▲ Obsidian을 처음 실행한 화면

이 화면이 나오지 않고 다른 볼트가 열려 있다면, 왼쪽 아래의 볼트 이름을 클릭해 Manage Vaults...를 고르면 같은 화면이 열립니다.

파일 탐색기와 나란히 놓고 대조하기

Obsidian 본 화면이 열리면 왼쪽에 파일 목록이 보입니다.
이제 파일 탐색기로 C:\kiosk-project를 열어 두 창을 나란히 놓습니다.

① Obsidian 창을 클릭합니다.
② Windows 키와 왼쪽 화살표를 함께 누릅니다.
③ 파일 탐색기 창을 클릭합니다.
④ Windows 키와 오른쪽 화살표를 함께 누릅니다.

화면이 반씩 나뉘어 두 목록이 나란히 보이면 됩니다.

[화면 캡처: C-3-04 — 파일 탐색기와 나란히 놓고 대조하기: 왼쪽 절반에 Obsidian 파일 목록, 오른쪽 절반에 파일 탐색기로 연 C:\kiosk-project. ① 양쪽의 kiosk-terms, ② 양쪽의 source-files 폴더, ③ 파일 탐색기에만 있는 kiosk-research-report.docx]
▲ 같은 폴더를 두 창으로 본 모습

두 목록을 위에서부터 하나씩 짚어 가며 대조합니다.
파일 탐색기의 kiosk-terms.md는 Obsidian 목록에 확장명 없이 kiosk-terms로 보입니다.
kiosk-research-summary.md, kiosk-memo.md도 마찬가지입니다.
이름 끝의 .md만 감춰 보여 줄 뿐 같은 파일입니다.
source-files, notes-inbox 같은 폴더도 양쪽에 같은 이름으로 있고, Obsidian에서 폴더를 클릭하면 펼쳐집니다.

다른 점도 보입니다.
Word 파일(kiosk-research-report.docx), Excel 파일(kiosk-facts-table.xlsx), 8강과 9강에서 받은 HWPX 파일은 파일 탐색기에는 있지만 Obsidian 목록에는 없습니다.

⚠ 확인 필요 1.14.5에서 .docx, .xlsx, .hwpx가 목록에 보이지 않는지

Obsidian이 직접 여는 형식은 마크다운과 그림, 소리, 영상, PDF이고, 열지 못하는 형식은 기본으로 목록에 보여 주지 않기 때문입니다.
그래서 source-files 안의 PDF와 그림은 보이고, notes-inbox 안의 .txt 메모는 보이지 않을 것입니다.

⚠ 확인 필요 notes-inbox의 .txt 파일과 source-files의 .html 파일이 목록에 보이는지

Settings의 Files and links에는 이런 파일도 목록에 보이게 하는 설정(Show all file types)이 있지만 이 강의에서는 켜지 않습니다.

⚠ 확인 필요 1.14.5에서 Show all file types 설정의 이름과 기본값

Word와 HWPX는 Obsidian에서 고칠 수 없으니, 그 파일은 지금처럼 파일 탐색기에서 Word나 한글 프로그램으로 엽니다.

목록이 비어 있거나 처음 보는 파일만 있다면 다른 폴더를 연 것입니다.
왼쪽 아래의 볼트 이름을 클릭해 Manage Vaults...에서 C:\kiosk-project를 다시 엽니다.

대조를 마쳤으면 파일 탐색기 쪽을 다시 봅니다.
C:\kiosk-project에 .obsidian이라는 폴더가 새로 생겼습니다.

⚠ 확인 필요 Windows 파일 탐색기에서 .obsidian 폴더가 보이는지

Obsidian이 이 볼트의 설정을 적어 두는 폴더입니다.
이름이 점으로 시작하는 폴더라 숨긴 폴더로 다루는 운영체제가 많고, Obsidian 목록에도 나오지 않습니다.
이 폴더 안은 고치지 않습니다.
잠시 뒤 바꿀 설정도 모두 여기에 저장됩니다.

볼트는 내 컴퓨터의 폴더 하나입니다

[이미지: C-3-05 — 기술 그림.]
▲ 볼트는 폴더 하나이고, Obsidian과 파일 탐색기가 같은 폴더를 본다

방금 대조한 것을 Obsidian 공식 도움말은 한 문장으로 적습니다.

A vault is a folder on your local file system, including any subfolders.

볼트는 내 컴퓨터에 있는 폴더 하나이고, 그 안의 하위 폴더를 모두 포함한다는 뜻입니다.

▲ 기준을 적는 record-plan과 강의마다 줄이 쌓이는 project-log

이제 두 노트의 역할을 다시 정리합니다.
record-plan에는 무엇을 남기고 무엇을 적지 않을지라는 기준을 적고, 그 기준을 바꿀 때만 고칩니다.
project-log에는 강의마다 실제로 한 일과 대조 결과를 적고, 강의마다 줄이 늘어납니다.
기준을 일지에 다시 옮겨 적지 않습니다.
같은 내용이 두 노트에 나뉘어 있으면 나중에 어느 쪽이 최신인지 따져야 하기 때문입니다.
