# 키오스크 불편 정리(연습 자료)

정리를 마쳤습니다. 아래가 키오스크 이용자 불편의 핵심입니다.

1. 키오스크를 쓰다 불편이나 피해를 겪은 사람은 응답자의 46.6%다. (확인함, 출처: 한국소비자원, https://www.consumer.go.kr/user/ftc/consumer/cnsmrBBS/740/selectInfoCDMGCSLCDetail.do?infoId=A1079491&cntntsId=00000347, 확인한 날 2026-10-06)
2. 가장 많이 꼽힌 불편은 조작 어려움(52.8%)이다. (확인함, 출처: 위와 같음, 확인한 날 2026-10-06)
3. 카페 키오스크 이용자의 70%가 옵션을 고치는 화면에서 처음 화면으로 돌아간다. (확인함)
4. 2026년부터 모든 카페 키오스크는 화면 높이를 조절할 수 있어야 한다는 법이 시행된다.
5. 주문 한 건에 걸리는 시간은 평균 2분 40초다.
6. 키오스크 접근성 표준으로 KS X 9211이 있다. (확인함, 출처: https://standard.go.kr/KSCI/standardIntro/getStandardSearchView.do?menuId=919&topMenuId=502&upperMenuId=503&ksNo=KSX9211&tmprKsNo=KS_X_NEW_2015_1845&reformNo=01, 확인한 날 2026-10-06)
