## 넣을지 정하기

- 위 9번의 답은 README가 아니라 Claude 공식 문서(https://claude.com/docs/plugins/overview)의 "Before you add a plugin" 부분에서 찾습니다.

- 넣기로 했으면 정한 이유를 한 문장으로 적습니다.
