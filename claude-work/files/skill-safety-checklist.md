# 공개 Skill 올리기 전 점검표

Skill 폴더를 올리기 전에 칸마다 실제 파일을 열어 보고 적습니다. Claude가 요약한 표가 있으면 그 표의 칸과 실제 파일을 한 칸씩 대조합니다.

| 점검할 것 | 볼 파일 | 내가 본 것 | 판단(괜찮음, 신중히, 올리지 않음) |
|---|---|---|---|
| 누가 만들었고 어디서 받았는가 | 저장소 첫 화면, README, 라이선스 | | |
| Skill이 하는 일과 켜질 때 | SKILL.md의 name, description | | |
| 실행될 스크립트가 있는가, 무엇을 하는가 | scripts 폴더의 파일 | | |
| 다른 패키지나 프로그램을 설치하게 하는가 | SKILL.md, references의 안내 | | |
| 밖의 주소에 연결하거나 파일을 보내게 하는가 | SKILL.md, scripts, assets | | |
| 함께 든 그림, 템플릿 파일 | assets 폴더 | | |
| 내 파일이나 개인정보를 다루게 하는가 | SKILL.md 본문 | | |

Pro에는 Skill 자동 검사가 없으므로, 이 점검표를 사람이 직접 채웁니다.
