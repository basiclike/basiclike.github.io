# 매장 주문 키오스크 이용자 불편 사전 조사

조사일: 2026-10-06

## 핵심 요약

1. 한국소비자원 조사에서 응답자의 46.6%가 키오스크를 쓰다 불편이나 피해를 겪었다고 답했다.
2. 가장 많이 꼽힌 불편은 주문이 늦어져 뒷사람 눈치가 보임(52.8%), 조작 어려움(46.8%), 기기 오류(39.1%)다.
3. 옵션을 잘못 골랐을 때 수정하기 어렵다는 교육용 가설은 이 보고서가 읽은 두 자료만으로는 확인되지 않았다.

| 단계 | 문제 | 사례 수 | 출처 |
|---|---|---|---|
| 메뉴 선택 | 읽은 자료에서 확인한 문제 없음 | 0 | - |
| 옵션 변경 | 잘못 고른 옵션을 고치기 어렵다(가설) | 0 | - |
| 장바구니 | 읽은 자료에서 확인한 문제 없음 | 0 | - |
| 결제 방식 선택 | 읽은 자료에서 확인한 문제 없음 | 0 | - |
| 전체(단계를 가르지 않음) | 주문이 늦어져 뒷사람 눈치가 보임(52.8%), 조작 어려움(46.8%), 기기 오류(39.1%) | 통계 1건 | 출처 1 |
