14강. Project에 자료와 지시 모으기

실습 강의 ⏱ 약 45분

학습 목표

13강까지 키오스크 폴더에 조사 보고서와 기록을 모았습니다.
이번 강의에서는 그 폴더와 규칙을 대화마다 다시 붙이지 않고, 한 번만 해 두는 자리를 만듭니다.

  • 새 대화를 열 때마다 같은 보고서를 올리고 같은 지시를 다시 쓰지 않아도 되는 방법이 있는지 알아봅시다.
  • 내 PC의 키오스크 폴더로 Project를 만들고, 프로젝트 지침을 내 손으로 써 봅시다.
  • 같은 문장이 Instructions에 있을 때와 프로젝트 지침에 있을 때 무엇이 달라지는지 알아봅시다.
  • 새 대화는 앞 대화의 기록 없이도 같은 결론에 이르는데, 다른 Project의 메모리는 왜 보이지 않는지 확인해 봅시다.

Use account memory가 나누는 것

"Use account memory"는 무엇을 나누는 스위치인지 도움말을 정리하면 이렇습니다.

메모리를 켜 두거나 끄는 때

키오스크 Project에서는 "Use account memory"를 켠 그대로 둡니다.
계정 메모리에 있는 여러분의 역할과 답의 모양을 키오스크 대화에서도 쓰는 편이 낫기 때문입니다.
어떤 Project의 대화가 다른 대화에서 쌓인 메모에 휘둘리면 안 될 때, 예를 들어 남의 자료를 다루는 Project라면 그 Project 페이지에서 이 스위치를 끕니다.

대화 하나에서만 메모리를 쓰지 않으려면 첫 메시지를 보내기 전에 입력창의 + 메뉴에서 Memory를 끕니다.
그렇게 시작한 Project 안의 대화는 Project 메모리를 쓰지도, 추가하지도 않습니다.

오늘 쓰지 않은 시작 방법

오늘 처음 본 이름 가운데 이 강의 범위 밖의 것은 이름과 뜻만 적어 두고 넘어갑니다.
Import from project는 대화 화면에서 예전에 만든 Project 하나를 골라 그 파일과 지침을 새 Project로 옮겨 오는 방법입니다.

연습 Project 지우기

[화면 캡처: D-1-07 — 연습 Project 지우기: 연습 Project 페이지에서 연 지우기 메뉴와 확인 창. ① Project 이름 "연습", ② Delete, ③ 확인 창의 지우기 버튼] ▲ 연습 Project 페이지의 지우기 메뉴와 확인 창

끝으로 연습 Project를 지웁니다.
연습 Project는 키오스크 Project의 메모리가 다른 Project로 넘어가는지 보려고 만든 자리라 이 강의 뒤로는 쓰지 않습니다.
남겨 두면 왼쪽 Projects 목록에 키오스크 Project와 나란히 남아, 키오스크 일을 연습 Project에서 잘못 시작할 수 있습니다.

① 왼쪽 Projects 목록에서 연습을 클릭해 Project 페이지를 엽니다.

② 페이지의 메뉴에서 Delete를 클릭합니다.

③ 확인 창에서 한 번 더 지우기 버튼을 클릭합니다.

⚠ 확인 필요 연습 Project를 지우는 메뉴의 자리와 이름, 확인 창의 문장, Start from scratch로 만든 폴더가 지운 뒤에도 PC에 남는지

지운 뒤 키오스크 Project 확인하기

연습 Project를 지워도 키오스크 Project는 그대로입니다.
앞에서 연습 Project의 대화가 키오스크 Project의 지침도, 폴더도, 메모리도 보지 못했듯이, Project마다 지침, 대화, 메모리가 따로 있기 때문입니다.
지워지는 것은 연습 Project와 그 안의 대화, 그 Project의 메모리입니다.

⚠ 확인 필요 Project를 지우면 그 안의 대화와 Project 메모리가 함께 지워지는지

키오스크 폴더 C:\kiosk-project는 연습 Project와 이어진 적이 없으니 손대지 않은 채 남습니다.

① 왼쪽 Projects 목록에 카페 키오스크 개선이 남아 있는지 봅니다.

② 카페 키오스크 개선을 클릭해 엽니다.

③ Set project instructions에 앞에서 고쳐 쓴 지침이 그대로 있는지 확인합니다.

증상과 해결

증상 해결
노트에 추가한 새 줄이 Project 새 대화의 답에 없다 첫째, Obsidian에서 연 볼트가 C:\kiosk-project이고 그 안의 notes/project-log.md에 줄을 추가했는지 봅니다. 다른 볼트에 같은 이름의 파일이 있으면 그쪽을 고쳤을 수 있습니다. 둘째, 질문을 Project 안의 새 대화에서 보냈는지 봅니다. 셋째, 데스크톱 앱이 켜 있는 PC에서 보냈는지 봅니다.
고쳐 쓴 프로젝트 지침을 넣었는데 답이 달라지지 않는다 지침의 문장이 무엇을, 언제 하라는 것인지 분명한지 다시 읽고 고칩니다.
받은 답이 강의에 실린 답과 다르다 강의에 실린 답으로 이어 갑니다. 파일 목록은 폴더에 무엇이 있느냐에 따라 길이가 달라집니다.
