학습 목표

💡 사용 환경 파이썬 3이 설치된 PC와 코드 편집기 하나, 그리고 명령을 입력할 터미널(Windows는 PowerShell, macOS는 터미널)을 씁니다. 이 강의의 명령은 python으로 적었습니다. 여러분 PC에서 python이 실행되지 않으면 python3이나 py로 바꿔 입력합니다.

코드를 묶는 단위

→ 남이 만든 코드는 어떤 단위로 정리되어 있을까요?

함수가 많아지면 생기는 문제

지금까지 여러분은 파일 하나에 함수를 정의하고, 같은 파일 안에서 그 함수를 불러 썼습니다. 프로그램이 작을 때는 이것으로 충분합니다. 그런데 함수가 수십 개로 늘어나면 파일 하나가 너무 길어지고, 다른 프로그램에서 같은 함수를 쓰려면 코드를 복사해 붙여야 합니다. 복사한 코드는 한쪽을 고쳐도 다른 쪽이 그대로 남습니다.

그래서 파이썬은 코드를 파일과 폴더 단위로 나누어 두고, 필요한 위치에서 불러 쓰게 합니다. 여러분이 print()나 len() 밖에 쓰게 될 많은 기능도 다른 사람이 이렇게 나누어 정리해 둔 코드입니다.

코드를 파일과 폴더로 나누어 두면 ==다시 쓰기==가 쉬워지고, 남이 만든 코드도 같은 방식으로 정리되어 있습니다.

사전, 책, 도서관

남이 만든 코드를 정리하는 단위는 셋입니다. 작은 것부터 차례로 보겠습니다.

단위 실제 모습 담는 것 비유
모듈 .py 파일 하나 서로 관련 있는 함수, 변수, 클래스 사전의 낱말 풀이 여러 개
패키지 폴더 하나 서로 관련 있는 모듈들 낱말 풀이를 모은 책 한 권
라이브러리 패키지와 모듈의 묶음 남이 쓰도록 만들어 배포한 코드 책을 모은 도서관

[이미지: 1-2-0 — 낱말 풀이 카드가 모여 책 한 권이 되고, 책이 모여 도서관의 책장이 되는 흐름을 왼쪽에서 오른쪽으로 보여 주는 장면 그림] ▲ 함수를 모은 파일이 모듈, 모듈을 모은 폴더가 패키지, 그것들을 묶어 남이 쓰게 만든 것이 라이브러리입니다

==모듈==은 관련 있는 함수를 모아 둔 파일입니다. 사전에서 낱말 풀이 하나하나가 함수라면, 그 풀이가 여러 개 적힌 몇 쪽이 모듈입니다. ==패키지==는 관련 있는 모듈을 모아 둔 폴더입니다. 낱말 풀이를 엮은 책 한 권과 같습니다. ==라이브러리==는 이런 패키지와 모듈을 묶어 다른 사람이 가져다 쓰게 만든 것입니다. 책이 모여 도서관이 되듯, 여러 패키지가 모여 하나의 라이브러리가 됩니다.

파이썬의 import 문이 불러오는 대상은 모듈과 패키지 둘뿐입니다. 라이브러리는 문법의 단위가 아니라, 설치해서 쓰는 코드 묶음을 부르는 이름입니다. 그래서 라이브러리를 쓸 때도 실제로는 그 안의 패키지나 모듈을 import로 불러옵니다.

모듈은 함수를 모은 파일, 패키지는 모듈을 모은 폴더, 라이브러리는 그것들을 묶어 남이 쓰게 만든 것입니다.

더 알아보기: 언어마다 다른 라이브러리 고치기

라이브러리를 만든 쪽이 함수를 고쳐야 할 때 어떻게 하는지는 언어와 환경마다 다릅니다. C와 C++의 라이브러리는 이미 쓰고 있는 프로그램이 깨지지 않게, 고친 기능을 새 이름의 함수로 더하는 경우가 많습니다. C#이 쓰는 .NET 프레임워크의 라이브러리는 함수 이름을 그대로 두고 안쪽 코드를 고치는 경우가 많습니다. 어느 쪽이든 라이브러리를 쓰는 사람은 함수 이름으로 기능을 불러 쓴다는 점은 같습니다.

모듈 불러오기

→ 내가 만든 파일의 함수를 다른 파일에서 어떻게 쓸까요?

함수를 모은 파일 만들기

계산 함수 두 개를 모은 모듈을 만들고, 다른 파일에서 불러 써 보겠습니다.

단계: 작업 폴더 만들기

터미널에서 이 강의의 실습 폴더 mycode를 만들고 그 안으로 들어갑니다. 이 강의의 파일은 모두 이 폴더 안에 만듭니다.

mkdir mycode
cd mycode

단계: 모듈 파일 만들기

편집기로 mycode 폴더에 calc.py 파일을 만들고 아래 코드를 저장합니다. 첫 행의 주석은 파일 이름을 알려 주는 표시여서 함께 적어도 되고 빼도 됩니다.

# 파일: calc.py
def add(a, b):
    return a + b


def mul(a, b):
    return a * b

이 파일은 직접 실행하지 않습니다. 함수 add와 mul을 정의만 해 두었고, 다른 파일이 불러 쓸 것입니다. 이렇게 함수를 모아 둔 .py 파일 하나가 모듈이고, 모듈의 이름은 파일 이름에서 .py를 뺀 calc입니다.

.py 파일 하나에 함수를 모아 저장하면 그 파일이 곧 ==모듈==이 됩니다.

import로 모듈 통째로 불러오기

단계: import 문으로 불러오기

같은 mycode 폴더에 main.py를 만들고 아래 코드를 저장합니다. 실행하기 전에 네 행이 각각 무엇을 출력할지 먼저 적어 봅니다.

import calc
import calc as c

print(calc.add(2, 3))
print(calc.mul(2, 3))
print(c.add(10, 20))
print(c.mul(10, 20))

단계: 실행해 결과 확인하기

터미널에서 main.py를 실행합니다.

python main.py

5
6
30
200

import calc는 calc.py 파일을 통째로 불러와 calc라는 이름에 담습니다. 그래서 함수를 부를 때 calc.add처럼 모듈 이름 뒤에 점을 찍고 함수 이름을 씁니다. import calc as c는 같은 모듈을 c라는 짧은 이름으로 부르게 합니다. 모듈 이름이 길 때 as로 줄여 쓰면 코드가 짧아집니다.

main.py가 calc.py를 찾을 수 있었던 것은 두 파일이 같은 폴더에 있기 때문입니다. 파이썬은 모듈을 찾을 때 실행한 파일이 있는 폴더를 가장 먼저 봅니다.

⚠ 주의 내 파일 이름을 random.py나 json.py처럼 파이썬에 이미 있는 모듈 이름과 같게 지으면, 파이썬이 같은 폴더의 내 파일을 먼저 찾아 원래 모듈 대신 불러옵니다. 내 모듈에는 겹치지 않는 이름을 붙입니다.

import 모듈 꼴은 모듈을 통째로 불러오고, 함수는 모듈.함수처럼 모듈 이름을 앞에 붙여 부릅니다.

from으로 함수만 골라 오기

단계: from 문으로 바꾸기

main.py의 내용을 아래 코드로 바꿔 저장합니다.

from calc import add
from calc import mul as times

print(add(2, 3))
print(times(4, 5))

단계: 다시 실행하기

python main.py

5
20

from calc import add는 calc 모듈에서 add 함수 하나만 가져옵니다. 이렇게 가져온 함수는 모듈 이름 없이 add(2, 3)처럼 바로 부릅니다. from calc import mul as times처럼 as를 붙이면 가져온 함수를 다른 이름으로 부를 수 있습니다.

from 꼴은 모듈 이름을 앞에 붙이지 않아 짧지만, 내 파일에 같은 이름의 함수가 있으면 둘이 부딪힙니다. 여러 모듈에서 함수를 가져올 때는 어느 모듈의 함수인지 드러나는 import 모듈 꼴이 읽기 쉽습니다.

💡 참고 실행한 뒤 mycode 폴더에 __pycache__ 폴더가 생깁니다. 파이썬이 불러온 모듈을 다음에 더 빨리 읽으려고 변환해 둔 파일을 넣는 폴더입니다. 지워도 다음 실행 때 다시 만들어지니 그대로 두면 됩니다.

내 파일의 함수는 같은 폴더에 둔 뒤 import calc로 모듈째 불러오거나, from calc import add로 필요한 함수만 골라 와서 씁니다.

패키지 만들기

→ 모듈이 많아지면 어떻게 묶고 불러올까요?

모듈을 폴더로 묶기

계산 모듈 밖에 인사말을 만드는 모듈이 하나 더 생겼다고 해 보겠습니다. 관련 있는 모듈을 tools라는 폴더 하나에 모으면 패키지가 됩니다. 완성하면 mycode 폴더는 아래 모습이 됩니다.

mycode/
├── calc.py
├── main.py
├── app.py
└── tools/
    ├── __init__.py
    ├── calc.py
    └── greet.py

단계: 패키지 폴더와 init.py 만들기

mycode 안에 tools 폴더를 만들고, 그 안에 __init__.py 파일을 만듭니다. 이름 앞뒤에 밑줄이 두 개씩 들어갑니다. 내용은 비워 두어도 되고, 여기서는 설명 주석 한 행만 적습니다.

# 파일: tools/__init__.py
# 이 폴더가 tools 패키지라는 표시입니다.

__init__.py는 이 폴더가 패키지라는 것을 파이썬에 알리는 파일입니다. 패키지를 처음 불러올 때 이 파일이 먼저 실행되므로, 패키지가 준비할 코드를 넣어 둘 수도 있습니다.

단계: 패키지에 모듈 넣기

앞 장에서 만든 calc.py와 같은 내용을 tools 폴더 안에도 저장합니다. 파일을 복사해 넣어도 됩니다.

# 파일: tools/calc.py
def add(a, b):
    return a + b


def mul(a, b):
    return a * b

같은 tools 폴더에 인사말 모듈 greet.py를 만듭니다.

# 파일: tools/greet.py
def hello(name):
    return "안녕하세요, " + name + "님"

모듈 파일들을 폴더 하나에 넣고 그 폴더에 __init__.py를 두면 그 폴더가 ==패키지==가 됩니다.

패키지 안의 모듈 불러오기

단계: 점으로 경로를 적어 불러오기

mycode 폴더(tools 폴더 바깥)에 app.py를 만들고 아래 코드를 저장합니다.

from tools import calc
from tools.greet import hello
import tools.calc as tc

print(calc.add(2, 3))
print(hello("민지"))
print(tc.mul(4, 5))

단계: 실행해 결과 확인하기

python app.py

5
안녕하세요, 민지님
20

패키지 안의 모듈은 폴더와 파일 이름을 점(.)으로 이어 가리킵니다. tools.greet는 "tools 폴더 안의 greet.py"라는 뜻입니다. 세 행은 가져오는 범위가 다릅니다.

코드 가져오는 것 부르는 꼴
from tools import calc tools 패키지의 calc 모듈 calc.add(2, 3)
from tools.greet import hello tools.greet 모듈의 hello 함수 하나 hello("민지")
import tools.calc as tc tools.calc 모듈을 tc라는 이름으로 tc.mul(4, 5)

필요한 함수가 하나뿐이면 from tools.greet import hello처럼 끝까지 경로를 적어 그 함수만 가져옵니다. 모듈 안의 여러 함수를 쓸 때는 from tools import calc처럼 모듈까지만 가져와 calc.add, calc.mul로 부릅니다.

모듈이 많아지면 폴더 하나에 모아 패키지로 묶고, from 패키지.모듈 import 함수처럼 점으로 경로를 이어 필요한 것만 골라 불러옵니다.

라이브러리 들여다보기

→ 설치한 라이브러리는 어디에 있고 무엇으로 되어 있을까요?

파이썬에 들어 있는 라이브러리 열어 보기

파이썬을 설치하면 함께 들어오는 라이브러리가 있습니다. 이것을 표준 라이브러리라고 합니다. 그 가운데 JSON 데이터를 다루는 json을 열어 보겠습니다. 모듈과 패키지에는 자기 파일의 위치를 담은 __file__이 있습니다.

단계: json 패키지의 위치와 파일 확인하기

mycode 폴더에 look.py를 만들고 아래 코드를 저장합니다.

import json
import os

print(json.__file__)

folder = os.path.dirname(json.__file__)
for name in sorted(os.listdir(folder)):
    if name.endswith(".py"):
        print(name)

단계: 실행해 결과 확인하기

python look.py

(여러분 PC의 값)
__init__.py
decoder.py
encoder.py
scanner.py
tool.py

첫 행은 json의 __init__.py 파일이 있는 위치이고, 파이썬을 설치한 폴더 안의 json 폴더로 끝납니다. 그 아래 행들은 그 폴더 안의 .py 파일입니다. 여러분이 만든 tools처럼 json도 __init__.py가 있는 폴더, 곧 패키지이고, 그 안에 decoder.py, encoder.py 같은 모듈이 들어 있습니다. 파이썬 버전에 따라 파일이 한두 개 더 있을 수 있습니다.

모든 모듈이 .py 파일인 것은 아닙니다. 수학 함수를 담은 math 모듈은 빠르게 돌도록 C 언어로 작성되어 있습니다. 그 소스는 파이썬 저장소의 mathmodule.c에서 볼 수 있습니다.

파이썬에 들어 있는 라이브러리도 여러분이 만든 tools와 같이 __init__.py와 모듈 파일이 든 폴더입니다.

설치한 라이브러리의 위치 찾기

pip로 설치하는 라이브러리는 site-packages라는 폴더에 들어갑니다. pip show 이름 명령은 설치된 라이브러리의 이름, 버전, 위치를 보여 줍니다. 모든 PC에 이미 설치되어 있는 pip 자신으로 확인해 보겠습니다.

단계: pip show로 위치 확인하기

터미널에서 아래 명령을 입력합니다.

python -m pip show pip

출력에서 아래 세 항목을 찾습니다. 다른 항목도 함께 나오며, 값은 PC마다 다릅니다.

Name: pip
Version: (여러분 PC의 값)
Location: (여러분 PC의 값)

Location에 적힌 폴더가 설치한 라이브러리가 모이는 site-packages 폴더입니다. 탐색기나 Finder로 그 폴더를 열면 pip 폴더가 보이고, 그 안에 __init__.py와 여러 모듈 파일이 들어 있습니다. 나중에 다른 라이브러리를 설치하면 그 라이브러리의 폴더도 이 위치에 생깁니다. 예를 들어 pip show tensorflow처럼 이름만 바꾸면 그 라이브러리의 위치를 같은 방법으로 찾을 수 있습니다.

설치한 라이브러리는 pip show의 Location이 가리키는 site-packages 폴더에 있고, 열어 보면 여러분이 만든 것과 같은 ==패키지와 모듈==로 되어 있습니다.

📌 정리 모듈은 함수를 모은 .py 파일, 패키지는 모듈을 모으고 __init__.py를 둔 폴더, 라이브러리는 그것들을 묶어 남이 쓰게 만든 것입니다. 모듈은 import calc, import calc as c로 통째로 불러오거나 from calc import add로 함수만 골라 옵니다. 패키지 안의 것은 from tools.greet import hello처럼 점으로 경로를 잇습니다. 설치한 라이브러리도 site-packages 폴더 안의 패키지와 모듈이어서, 내 코드와 남의 코드를 같은 import로 불러 씁니다.

❓ 질문 tools 패키지에 text.py 모듈을 더하고 그 안에 shout(s) 함수를 만들었다면, app.py에서 이 함수 하나만 가져오는 import 문은 어떻게 쓸까요?

→ 다음 강의 이 과정은 이 강의로 끝납니다. 앞으로 새 라이브러리를 설치하면 pip show로 위치를 찾아 그 폴더를 열어 보고, 이 강의에서 만든 tools와 같은 모양인지 확인해 보십시오.
